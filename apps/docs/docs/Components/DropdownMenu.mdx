## Features

- ✅ Full keyboard navigation with arrow keys
- ✅ Typeahead search for quick item selection
- ✅ Nested submenu support with directional awareness
- ✅ Checkbox and radio item variants
- ✅ Controlled and uncontrolled state management
- ✅ Automatic positioning with collision detection
- ✅ Modal and non-modal modes
- ✅ Focus management and restoration
- ✅ Customizable close behavior per item type
- ✅ Polymorphic component API

### Structure

```tsx
<DropdownMenu.Root>
  <DropdownMenu.Trigger />
  <DropdownMenu.Content>
    <DropdownMenu.Label />
    <DropdownMenu.Item />
    <DropdownMenu.Group>
      <DropdownMenu.Item />
    </DropdownMenu.Group>
    <DropdownMenu.CheckboxItem />
    <DropdownMenu.RadioGroup>
      <DropdownMenu.RadioItem />
    </DropdownMenu.RadioGroup>
    <DropdownMenu.Sub>
      <DropdownMenu.SubTrigger />
      <DropdownMenu.SubContent>
        <DropdownMenu.Item />
      </DropdownMenu.SubContent>
    </DropdownMenu.Sub>
    <DropdownMenu.Separator />
  </DropdownMenu.Content>
</DropdownMenu.Root>
```

**Alternative: Tree-shakeable named imports**

```tsx
import {
  DropdownMenuRoot,
  DropdownMenuTrigger,
  DropdownMenuContent,
  DropdownMenuItem,
} from '@turkish-technology/spar';

<DropdownMenuRoot>
  <DropdownMenuTrigger />
  <DropdownMenuContent>
    <DropdownMenuItem />
  </DropdownMenuContent>
</DropdownMenuRoot>;
```

**Data Flow:**

- `DropdownMenu.Root` manages open/close state and provides context
- `DropdownMenu.Trigger` controls menu visibility and manages focus
- `DropdownMenu.Content` handles positioning, keyboard navigation, and item collection
- Menu items register themselves for keyboard navigation and typeahead
- Submenus inherit parent context and manage their own open state

## Code Examples

### Basic Dropdown Menu

A simple dropdown menu with standard items.

```tsx
function BasicMenu() {
  return (
    <DropdownMenu.Root>
      <DropdownMenu.Trigger>Actions</DropdownMenu.Trigger>
      <DropdownMenu.Content>
        <DropdownMenu.Item onSelect={() => console.log('Edit')}>Edit</DropdownMenu.Item>
        <DropdownMenu.Item onSelect={() => console.log('Duplicate')}>Duplicate</DropdownMenu.Item>
        <DropdownMenu.Separator />
        <DropdownMenu.Item onSelect={() => console.log('Delete')}>Delete</DropdownMenu.Item>
      </DropdownMenu.Content>
    </DropdownMenu.Root>
  );
}
```

### Controlled Menu State

Control the menu's open state externally.

```tsx
function ControlledMenu() {
  const [isOpen, setIsOpen] = React.useState(false);

  return (
    <>
      <p>Menu is {isOpen ? 'open' : 'closed'}</p>
      <DropdownMenu.Root open={isOpen} onOpenChange={setIsOpen}>
        <DropdownMenu.Trigger>Options</DropdownMenu.Trigger>
        <DropdownMenu.Content>
          <DropdownMenu.Item>Option 1</DropdownMenu.Item>
          <DropdownMenu.Item>Option 2</DropdownMenu.Item>
        </DropdownMenu.Content>
      </DropdownMenu.Root>
    </>
  );
}
```

## API Reference

### DropdownMenu.Root

The root container that manages the dropdown menu state and provides context to all child components.

**Props**

| Name             | Type                      | Default     | Description                                                                                     |
| ---------------- | ------------------------- | ----------- | ----------------------------------------------------------------------------------------------- |
| `open?`          | `boolean`                 | `undefined` | Controlled open state                                                                           |
| `defaultOpen?`   | `boolean`                 | `false`     | Initial open state (uncontrolled)                                                               |
| `onOpenChange?`  | `(open: boolean) => void` | `undefined` | Callback when open state changes                                                                |
| `modal?`         | `boolean`                 | `true`      | Whether menu traps focus (modal) or allows focus to leave                                       |
| `disabled?`      | `boolean`                 | `false`     | Disables all dropdown menu triggers (prevents opening)                                          |
| `dir?`           | `'ltr' \| 'rtl'`          | `'ltr'`     | Reading direction for submenu positioning                                                       |
| `closeOnSelect?` | `boolean \| 'auto'`       | `'auto'`    | Whether to close menu on item selection. 'auto' closes for items, stays open for checkbox/radio |
| `children?`      | `React.ReactNode`         | `undefined` | Menu trigger and content                                                                        |

**Events**

| Name           | Parameters        | Description               | When Triggered                                |
| -------------- | ----------------- | ------------------------- | --------------------------------------------- |
| `onOpenChange` | `(open: boolean)` | Open state change handler | User interaction or programmatic state change |

### DropdownMenu.Trigger

The button element that toggles the dropdown menu visibility. Extends all `Button` component props including polymorphic rendering via the `as` prop.

**Props**

| Name               | Type                                                                              | Default     | Description                                         |
| ------------------ | --------------------------------------------------------------------------------- | ----------- | --------------------------------------------------- |
| `as?`              | `React.ElementType`                                                               | `"button"`  | Element type to render as                           |
| `children`         | `React.ReactNode \| ((state: DropdownMenuTriggerRenderProps) => React.ReactNode)` | `undefined` | Trigger content or render props function            |
| `disabled?`        | `boolean`                                                                         | `false`     | Whether the trigger is disabled                     |
| `autoFocus?`       | `boolean`                                                                         | `false`     | Whether the button should receive focus on mount    |
| `isLoading?`       | `boolean`                                                                         | `false`     | Loading state with screen reader support            |
| `isPressed?`       | `boolean`                                                                         | `undefined` | Toggle state - creates a toggle button when defined |
| `onPressedChange?` | `(pressed: boolean) => void`                                                      | `undefined` | Callback fired when toggle state changes            |
| `ref?`             | `React.Ref<HTMLButtonElement \| null>`                                            | `undefined` | Forwarded ref to trigger element                    |
| `onClick?`         | `(event: React.MouseEvent) => void`                                               | `undefined` | Click event handler                                 |
| `onKeyDown?`       | `(event: React.KeyboardEvent) => void`                                            | `undefined` | Keyboard event handler                              |
| `...props`         | `ButtonProps`                                                                     | -           | All standard Button component attributes            |

**Render Props (DropdownMenuTriggerRenderProps)**

| Property   | Type         | Description                          |
| ---------- | ------------ | ------------------------------------ |
| `isOpen`   | `boolean`    | Whether the dropdown menu is open    |
| `disabled` | `boolean`    | Whether the trigger is disabled      |
| `open`     | `() => void` | Function to open the dropdown menu   |
| `close`    | `() => void` | Function to close the dropdown menu  |
| `toggle`   | `() => void` | Function to toggle the dropdown menu |

**Events**

| Name        | Parameters                     | Description            | When Triggered                 |
| ----------- | ------------------------------ | ---------------------- | ------------------------------ |
| `onClick`   | `(event: React.MouseEvent)`    | Mouse click handler    | User clicks trigger            |
| `onKeyDown` | `(event: React.KeyboardEvent)` | Keyboard event handler | User presses key while focused |

**HTML Attributes**

| Attribute       | Value                | Purpose                   |
| --------------- | -------------------- | ------------------------- |
| `data-state`    | `'open' \| 'closed'` | Current state for styling |
| `data-disabled` | `''`                 | Present when disabled     |

### DropdownMenu.Content

The container for menu items with positioning, keyboard navigation, and typeahead support.

**Props**

| Name                    | Type                                     | Default     | Description                                           |
| ----------------------- | ---------------------------------------- | ----------- | ----------------------------------------------------- |
| `as?`                   | `React.ElementType`                      | `'div'`     | Polymorphic element type to render                    |
| `side?`                 | `'top' \| 'right' \| 'bottom' \| 'left'` | `'bottom'`  | Preferred side for positioning                        |
| `align?`                | `'start' \| 'center' \| 'end'`           | `'start'`   | Alignment relative to trigger                         |
| `sideOffset?`           | `number`                                 | `8`         | Distance in pixels from trigger                       |
| `alignOffset?`          | `number`                                 | `0`         | Offset along alignment axis                           |
| `avoidCollisions?`      | `boolean`                                | `true`      | Automatically adjust position to avoid viewport edges |
| `collisionBoundary?`    | `Element \| Element[] \| null`           | `null`      | Boundary element(s) for collision detection           |
| `collisionPadding?`     | `number`                                 | `8`         | Padding from boundary edges in pixels                 |
| `loop?`                 | `boolean`                                | `false`     | Whether keyboard navigation loops through items       |
| `onEscapeKeyDown?`      | `(event: React.KeyboardEvent) => void`   | `undefined` | Escape key handler                                    |
| `onPointerDownOutside?` | `(event: React.PointerEvent) => void`    | `undefined` | Outside click handler                                 |
| `onFocusOutside?`       | `(event: React.FocusEvent) => void`      | `undefined` | Outside focus handler                                 |
| `onKeyDown?`            | `(event: React.KeyboardEvent) => void`   | `undefined` | Keyboard event handler                                |
| `ref?`                  | `React.Ref<HTMLElement \| null>`         | `undefined` | Forwarded ref to content element                      |
| `children?`             | `React.ReactNode`                        | `undefined` | Menu items and groups                                 |

**Events**

| Name                   | Parameters                     | Description         | When Triggered                             |
| ---------------------- | ------------------------------ | ------------------- | ------------------------------------------ |
| `onEscapeKeyDown`      | `(event: React.KeyboardEvent)` | Escape key pressed  | User presses Escape while menu is open     |
| `onPointerDownOutside` | `(event: React.PointerEvent)`  | Click outside menu  | User clicks outside menu bounds            |
| `onFocusOutside`       | `(event: React.FocusEvent)`    | Focus leaves menu   | Focus moves outside menu (non-modal mode)  |
| `onKeyDown`            | `(event: React.KeyboardEvent)` | Key pressed in menu | User presses any key while menu is focused |

**HTML Attributes**

| Attribute    | Value    | Purpose                        |
| ------------ | -------- | ------------------------------ |
| `data-state` | `'open'` | Indicates open state           |
| `data-side`  | Side     | Current placement side         |
| `data-align` | Align    | Current alignment              |
| `tabIndex`   | `-1`     | Manages focus programmatically |

**HTML Attributes**

## Keyboard Interactions

Complete keyboard behavior for the DropdownMenu component:

| Key              | Action                                   | Context               | Notes                                                                    |
| ---------------- | ---------------------------------------- | --------------------- | ------------------------------------------------------------------------ |
| `Space`          | Opens menu / Activates item              | Trigger / Menu item   | Opens menu from trigger, activates focused item                          |
| `Enter`          | Opens menu / Activates item              | Trigger / Menu item   | Opens menu from trigger, activates focused item                          |
| `ArrowDown`      | Opens menu focusing first / Next item    | Trigger / Menu        | From trigger opens and focuses first item, in menu moves to next item    |
| `ArrowUp`        | Opens menu focusing last / Previous item | Trigger / Menu        | From trigger opens and focuses last item, in menu moves to previous item |
| `ArrowRight`     | Opens submenu                            | Submenu trigger (LTR) | Opens submenu focusing first item (reversed in RTL)                      |
| `ArrowLeft`      | Closes submenu                           | Submenu (LTR)         | Closes submenu and returns focus to trigger (reversed in RTL)            |
| `Escape`         | Closes menu                              | Menu                  | Closes menu and restores focus to trigger                                |
| `Tab`            | Navigate / Close                         | Menu                  | In modal mode, moves through items; in non-modal mode, closes menu       |
| `Shift + Tab`    | Navigate backward                        | Menu (modal)          | Moves to previous item in modal mode                                     |
| `Home`           | First item                               | Menu                  | Moves focus to first item                                                |
| `End`            | Last item                                | Menu                  | Moves focus to last item                                                 |
| `Character keys` | Typeahead search                         | Menu                  | Focuses first item matching typed characters                             |

**Note**: All keyboard interactions are implemented with full accessibility support following WAI-ARIA menu design patterns.
