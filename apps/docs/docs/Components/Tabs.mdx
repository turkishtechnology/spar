# Tabs

A headless, accessible tabs component that provides complete keyboard navigation, orientation support, and ARIA compliance for tabbed interfaces.

## Features

- ✅ Controlled and uncontrolled state management
- ✅ Automatic first-tab selection in uncontrolled mode when no `value` / `defaultValue` is provided
- ✅ Horizontal and vertical orientation configuration
- ✅ Automatic and manual activation behavior
- ✅ Lazy content rendering for performance
- ✅ Force mount option for always-rendered content
- ✅ Polymorphic rendering with `as` prop
- ✅ Render props pattern for Tabs.Trigger customization
- ✅ Disabled tab support

### Data Flow

1. **Tabs.Root** manages selected value state and provides context to descendants
2. **Tabs.List** handles roving focus and keyboard-driven tab traversal
3. **Tabs.Trigger** registers itself in the tab registry and updates selection
4. **Tabs.Content** renders the matching panel and reflects active/inactive state

## Code Examples

### Controlled Tabs

Use controlled tabs when the active panel needs to stay synced with routing, saved preferences, or external UI state.

```tsx {2,5}
function ControlledTabs() {
  const [activeTab, setActiveTab] = useState('profile');

  return (
    <Tabs.Root value={activeTab} onValueChange={setActiveTab}>
      <Tabs.List>
        <Tabs.Trigger value='profile'>Profile</Tabs.Trigger>
        <Tabs.Trigger value='settings'>Settings</Tabs.Trigger>
      </Tabs.List>
      <Tabs.Content value='profile'>Profile content here</Tabs.Content>
      <Tabs.Content value='settings'>Settings content here</Tabs.Content>
    </Tabs.Root>
  );
}
```

### Vertical Orientation

Vertical tabs work well for settings pages and other layouts where labels need more room.

```tsx {3}
function VerticalTabs() {
  return (
    <Tabs.Root orientation='vertical' defaultValue='tab1'>
      <Tabs.List>
        <Tabs.Trigger value='tab1'>First Tab</Tabs.Trigger>
        <Tabs.Trigger value='tab2'>Second Tab</Tabs.Trigger>
        <Tabs.Trigger value='tab3'>Third Tab</Tabs.Trigger>
      </Tabs.List>
      <Tabs.Content value='tab1'>First content</Tabs.Content>
      <Tabs.Content value='tab2'>Second content</Tabs.Content>
      <Tabs.Content value='tab3'>Third content</Tabs.Content>
    </Tabs.Root>
  );
}
```

### Manual Activation Mode

Manual activation separates focus from selection so users can explore tab labels with the keyboard before committing.

```tsx {3}
function ManualActivationTabs() {
  return (
    <Tabs.Root activationMode='manual' defaultValue='home'>
      <Tabs.List>
        <Tabs.Trigger value='home'>Home</Tabs.Trigger>
        <Tabs.Trigger value='about'>About</Tabs.Trigger>
        <Tabs.Trigger value='contact'>Contact</Tabs.Trigger>
      </Tabs.List>
      <Tabs.Content value='home'>Home page content</Tabs.Content>
      <Tabs.Content value='about'>About page content</Tabs.Content>
      <Tabs.Content value='contact'>Contact page content</Tabs.Content>
    </Tabs.Root>
  );
}
```

### Render Props Pattern

Render props let you build richer trigger content while still reading tab selection and focus state from the component.

```tsx {6-12,15}
function RenderPropsTabs() {
  return (
    <Tabs.Root defaultValue='dashboard'>
      <Tabs.List>
        <Tabs.Trigger value='dashboard'>
          {({ isSelected, isFocused }) => (
            <span className={isSelected ? 'selected' : ''}>
              <DashboardIcon />
              Dashboard
              {isFocused && <span className='focus-indicator' />}
            </span>
          )}
        </Tabs.Trigger>
        <Tabs.Trigger value='analytics'>
          {({ isSelected }) => <span className={isSelected ? 'selected' : ''}>Analytics</span>}
        </Tabs.Trigger>
      </Tabs.List>
      <Tabs.Content value='dashboard'>Dashboard content</Tabs.Content>
      <Tabs.Content value='analytics'>Analytics content</Tabs.Content>
    </Tabs.Root>
  );
}
```

### Force Mount Content

Use `forceMount` for panels that should stay in the DOM, such as forms, media players, or stateful widgets.

```tsx {9}
function ForceMountTabs() {
  return (
    <Tabs.Root defaultValue='lazy'>
      <Tabs.List>
        <Tabs.Trigger value='lazy'>Lazy Content</Tabs.Trigger>
        <Tabs.Trigger value='eager'>Always Mounted</Tabs.Trigger>
      </Tabs.List>
      <Tabs.Content value='lazy'>This content is only rendered when active</Tabs.Content>
      <Tabs.Content value='eager' forceMount>
        This content is always in the DOM (useful for forms, videos, etc.)
      </Tabs.Content>
    </Tabs.Root>
  );
}
```

## API Reference

### Tabs / Tabs.Root

The root state container for the tabs system. `Tabs` and `Tabs.Root` are the same component - the difference is only import/notation style.

#### Props

| Name              | Type                                                | Default        | Description                                                            |
| ----------------- | --------------------------------------------------- | -------------- | ---------------------------------------------------------------------- |
| `id?`             | `string`                                            | `undefined`    | Base id used to derive trigger/panel ids (`{id}-trigger-{value}` etc.) |
| `value?`          | `string`                                            | `undefined`    | Controlled selected tab value                                          |
| `defaultValue?`   | `string`                                            | `undefined`    | Initial selected tab value for uncontrolled usage                      |
| `onValueChange?`  | `(value: string) => void`                           | `undefined`    | Called when selected value changes                                     |
| `orientation?`    | `'horizontal' \| 'vertical'`                        | `'horizontal'` | Orientation used by list/panels and keyboard rules                     |
| `dir?`            | `'ltr' \| 'rtl'`                                    | `'ltr'`        | Direction used by horizontal arrow navigation                          |
| `activationMode?` | `'automatic' \| 'manual'`                           | `'automatic'`  | `automatic`: focus activates, `manual`: Enter/Space activates          |
| `as?`             | `React.ElementType`                                 | `'div'`        | Element type to render                                                 |
| `...props`        | `ComponentPropsWithRef<'div'>` + `as` element props | —              | Forwards supported HTML attributes/events to the rendered root element |

#### Events

| Name             | Parameters      | Description                 | When Triggered                                                   |
| ---------------- | --------------- | --------------------------- | ---------------------------------------------------------------- |
| `onValueChange?` | `value: string` | Reports next selected value | Selection changes from click, keyboard activation, or `select()` |

#### HTML Attributes

| Attribute          | Value                    | Purpose                           |
| ------------------ | ------------------------ | --------------------------------- |
| `data-orientation` | `horizontal \| vertical` | Exposes configured orientation    |
| `data-dir`         | `ltr \| rtl`             | Exposes configured text direction |

### Tabs.List

#### Props

| Name       | Type                                                | Default | Description                                           |
| ---------- | --------------------------------------------------- | ------- | ----------------------------------------------------- |
| `as?`      | `React.ElementType`                                 | `'div'` | Element type to render                                |
| `...props` | `ComponentPropsWithRef<'div'>` + `as` element props | —       | Forwards supported HTML attributes/events to the list |

#### Events

| Name         | Parameters                                   | Description                   | When Triggered                                  |
| ------------ | -------------------------------------------- | ----------------------------- | ----------------------------------------------- |
| `onKeyDown?` | `event: React.KeyboardEvent<HTMLDivElement>` | Custom key handler (composed) | Called after built-in keyboard navigation logic |

#### HTML Attributes

| Attribute          | Value                    | Purpose                              |
| ------------------ | ------------------------ | ------------------------------------ |
| `role`             | `tablist`                | Identifies the element as a tab list |
| `aria-orientation` | `horizontal \| vertical` | Indicates tab list orientation       |
| `data-orientation` | `horizontal \| vertical` | Indicates tab list orientation       |

### Tabs.Trigger

Extends all `Button` component props including polymorphic rendering via the `as` prop.

#### Props

| Name               | Type                                                                      | Default     | Description                                             |
| ------------------ | ------------------------------------------------------------------------- | ----------- | ------------------------------------------------------- |
| `value`            | `string`                                                                  | —           | Unique identifier for this tab                          |
| `children?`        | `React.ReactNode \| ((state: TabsTriggerRenderProps) => React.ReactNode)` | `undefined` | Trigger content or render-prop function                 |
| `as?`              | `React.ElementType`                                                       | `'button'`  | Element type to render                                  |
| `disabled?`        | `boolean`                                                                 | `false`     | Disables trigger selection and interaction              |
| `autoFocus?`       | `boolean`                                                                 | `false`     | Focuses trigger on mount                                |
| `isLoading?`       | `boolean`                                                                 | `false`     | Inherited from `Button`; exposes loading semantics      |
| `isPressed?`       | `boolean`                                                                 | `undefined` | Inherited from `Button`; enables toggle-button behavior |
| `onPressedChange?` | `(pressed: boolean) => void`                                              | `undefined` | Inherited callback for toggle state changes             |
| `...props`         | `Button` HTML/button props + `as` element props                           | —           | Forwards supported attributes/events to the trigger     |

#### TabsTriggerRenderProps

| Property      | Type          | Description                                  |
| ------------- | ------------- | -------------------------------------------- |
| `isSelected`  | `boolean`     | Whether this tab is currently selected       |
| `select`      | `() => void`  | Function to select this tab programmatically |
| `disabled`    | `boolean`     | Whether this tab is disabled                 |
| `isFocused`   | `boolean`     | Whether this tab is currently focused        |
| `orientation` | `Orientation` | The tab's orientation                        |

#### Events

| Name       | Parameters                                   | Description | When Triggered                           |
| ---------- | -------------------------------------------- | ----------- | ---------------------------------------- |
| `onClick?` | `event: React.MouseEvent<HTMLButtonElement>` | Tab clicked | User clicks the tab trigger              |
| `onFocus?` | `event: React.FocusEvent<HTMLButtonElement>` | Tab focused | Tab receives focus via keyboard or mouse |
| `onBlur?`  | `event: React.FocusEvent<HTMLButtonElement>` | Tab blurred | Tab loses focus                          |

#### HTML Attributes

| Attribute          | Value                          | Purpose                                                        |
| ------------------ | ------------------------------ | -------------------------------------------------------------- |
| `id`               | `\${baseId}-trigger-\${value}` | Stable trigger id used by panel relationship                   |
| `role`             | `tab`                          | Identifies the element as a tab                                |
| `aria-selected`    | `true \| false`                | Indicates whether this tab is selected                         |
| `aria-controls`    | `\${baseId}-panel-\${value}`   | References controlled tab panel                                |
| `tabIndex`         | `0 \| -1`                      | Implements roving tabindex behavior                            |
| `disabled`         | `boolean`                      | Native disabled attribute when rendered as `button`            |
| `aria-disabled`    | `true` (conditional)           | Added by `Button` when disabled and rendered as non-`button`   |
| `data-state`       | `active \| inactive`           | Exposes selected state                                         |
| `data-orientation` | `horizontal \| vertical`       | Exposes current orientation                                    |
| `data-value`       | `string`                       | Stores trigger value for keyboard navigation                   |
| `data-disabled`    | `'' \| undefined`              | Inherited from `Button` when disabled                          |
| `data-loading`     | `'' \| undefined`              | Inherited from `Button` when `isLoading` is true               |
| `data-pressed`     | `'' \| undefined`              | Inherited from `Button` when toggle mode is active and pressed |
| `data-autofocus`   | `'' \| undefined`              | Inherited from `Button` when `autoFocus` is true               |

### Tabs.Content

#### Props

| Name          | Type                                                | Default | Description                                 |
| ------------- | --------------------------------------------------- | ------- | ------------------------------------------- |
| `value`       | `string`                                            | —       | Unique identifier matching a `Tabs.Trigger` |
| `forceMount?` | `boolean`                                           | `false` | Keeps panel mounted even when inactive      |
| `as?`         | `React.ElementType`                                 | `'div'` | Element type to render                      |
| `...props`    | `ComponentPropsWithRef<'div'>` + `as` element props | —       | Forwards supported HTML attributes/events   |

#### Events

No component-specific events are defined. Standard forwarded DOM events can be passed via `...props`.

#### HTML Attributes

| Attribute          | Value                          | Purpose                                         |
| ------------------ | ------------------------------ | ----------------------------------------------- |
| `id`               | `\${baseId}-panel-\${value}`   | Stable panel id for trigger relationship        |
| `role`             | `tabpanel`                     | Identifies the element as a tab panel           |
| `aria-labelledby`  | `\${baseId}-trigger-\${value}` | References controlling trigger                  |
| `tabIndex`         | `0`                            | Makes rendered panel programmatically focusable |
| `hidden`           | `true \| false`                | Marks mounted but inactive panel as hidden      |
| `data-state`       | `active \| inactive`           | Exposes panel active state                      |
| `data-orientation` | `horizontal \| vertical`       | Exposes current orientation                     |

## Keyboard Interactions

| Key                | Action                            | Context         | Notes                                                        |
| ------------------ | --------------------------------- | --------------- | ------------------------------------------------------------ |
| `Tab`              | Moves focus in document tab order | Global          | Browser-native behavior; not intercepted by `Tabs`           |
| `ArrowRight`       | Focuses next enabled tab          | Horizontal list | Uses `dir`; wraps when end is reached; skips disabled tabs   |
| `ArrowLeft`        | Focuses previous enabled tab      | Horizontal list | Uses `dir`; wraps when start is reached; skips disabled tabs |
| `ArrowDown`        | Focuses next enabled tab          | Vertical list   | Wraps when end is reached; skips disabled tabs               |
| `ArrowUp`          | Focuses previous enabled tab      | Vertical list   | Wraps when start is reached; skips disabled tabs             |
| `Home`             | Focuses first enabled tab         | List focused    | Selects it in `automatic` mode                               |
| `End`              | Focuses last enabled tab          | List focused    | Selects it in `automatic` mode                               |
| `Enter` or `Space` | Activates focused trigger         | Trigger focused | In manual mode this is the primary way to commit focused tab |

**Note:** In `automatic` mode, arrow/home/end navigation both focuses and selects. In `manual` mode, those keys only move focus; use `Enter` or `Space` to commit selection after moving focus.
