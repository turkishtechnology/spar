# Tabs

A headless, accessible tabs component that provides complete keyboard navigation, orientation support, and ARIA compliance for tabbed interfaces.

## Features

- ✅ Controlled and uncontrolled state management
- ✅ Horizontal and vertical orientation support
- ✅ Automatic and manual activation modes
- ✅ Loop navigation with arrow keys
- ✅ Lazy content rendering for performance
- ✅ Force mount option for always-rendered content
- ✅ Polymorphic rendering with `as` prop
- ✅ Render props pattern for Tabs.Trigger customization
- ✅ Disabled tab support
- ✅ RTL (right-to-left) text direction support

## Installation

```tsx
import { Tabs } from '@turkish-technology/spar';
```

### Data Flow

1. **Tabs (Root)** manages the selected value state and provides context to all child components
2. **Tabs.List** handles keyboard navigation between triggers and focus management
3. **Tabs.Trigger** components register themselves with the root and handle activation
4. **Tabs.Content** components automatically show/hide based on the selected value

## Code Examples

### Controlled Tabs

```tsx
function ControlledTabs() {
  const [activeTab, setActiveTab] = useState('profile');

  return (
    <Tabs.Root value={activeTab} onValueChange={setActiveTab}>
      <Tabs.List>
        <Tabs.Trigger value='profile'>Profile</Tabs.Trigger>
        <Tabs.Trigger value='settings'>Settings</Tabs.Trigger>
      </Tabs.List>
      <Tabs.Content value='profile'>Profile content here</Tabs.Content>
      <Tabs.Content value='settings'>Settings content here</Tabs.Content>
    </Tabs.Root>
  );
}
```

### Vertical Orientation

```tsx
function VerticalTabs() {
  return (
    <Tabs.Root orientation='vertical' defaultValue='tab1'>
      <Tabs.List>
        <Tabs.Trigger value='tab1'>First Tab</Tabs.Trigger>
        <Tabs.Trigger value='tab2'>Second Tab</Tabs.Trigger>
        <Tabs.Trigger value='tab3'>Third Tab</Tabs.Trigger>
      </Tabs.List>
      <Tabs.Content value='tab1'>First content</Tabs.Content>
      <Tabs.Content value='tab2'>Second content</Tabs.Content>
      <Tabs.Content value='tab3'>Third content</Tabs.Content>
    </Tabs.Root>
  );
}
```

### Manual Activation Mode

```tsx
function ManualActivationTabs() {
  return (
    <Tabs.Root activationMode='manual' defaultValue='home'>
      <Tabs.List>
        <Tabs.Trigger value='home'>Home</Tabs.Trigger>
        <Tabs.Trigger value='about'>About</Tabs.Trigger>
        <Tabs.Trigger value='contact'>Contact</Tabs.Trigger>
      </Tabs.List>
      <Tabs.Content value='home'>Home page content</Tabs.Content>
      <Tabs.Content value='about'>About page content</Tabs.Content>
      <Tabs.Content value='contact'>Contact page content</Tabs.Content>
    </Tabs.Root>
  );
}
```

### Render Props Pattern

```tsx
function RenderPropsTabs() {
  return (
    <Tabs.Root defaultValue='dashboard'>
      <Tabs.List>
        <Tabs.Trigger value='dashboard'>
          {({ isSelected, isFocused }) => (
            <span className={isSelected ? 'selected' : ''}>
              <DashboardIcon />
              Dashboard
              {isFocused && <span className='focus-indicator' />}
            </span>
          )}
        </Tabs.Trigger>
        <Tabs.Trigger value='analytics'>
          {({ isSelected }) => <span className={isSelected ? 'selected' : ''}>Analytics</span>}
        </Tabs.Trigger>
      </Tabs.List>
      <Tabs.Content value='dashboard'>Dashboard content</Tabs.Content>
      <Tabs.Content value='analytics'>Analytics content</Tabs.Content>
    </Tabs.Root>
  );
}
```

### Force Mount Content

```tsx
function ForceMountTabs() {
  return (
    <Tabs.Root defaultValue='lazy'>
      <Tabs.List>
        <Tabs.Trigger value='lazy'>Lazy Content</Tabs.Trigger>
        <Tabs.Trigger value='eager'>Always Mounted</Tabs.Trigger>
      </Tabs.List>
      <Tabs.Content value='lazy'>This content is only rendered when active</Tabs.Content>
      <Tabs.Content value='eager' forceMount>
        This content is always in the DOM (useful for forms, videos, etc.)
      </Tabs.Content>
    </Tabs.Root>
  );
}
```

## API Reference

### Tabs (Root)

#### Props

| Name             | Type                                   | Default        | Description                                                   |
| ---------------- | -------------------------------------- | -------------- | ------------------------------------------------------------- |
| `value`          | `string \| undefined`                  | `undefined`    | Controlled selected tab value                                 |
| `defaultValue`   | `string \| undefined`                  | `undefined`    | Uncontrolled initial tab selection                            |
| `onValueChange`  | `(value: string) => void \| undefined` | `undefined`    | Callback when tab selection changes                           |
| `orientation`    | `'horizontal' \| 'vertical'`           | `'horizontal'` | Tabs orientation affecting keyboard navigation                |
| `dir`            | `'ltr' \| 'rtl'`                       | `'ltr'`        | Text direction for arrow key navigation                       |
| `activationMode` | `'automatic' \| 'manual'`              | `'automatic'`  | Whether tabs activate on focus or require explicit activation |
| `as`             | `React.ElementType`                    | `'div'`        | Polymorphic component type                                    |

#### Events

| Name            | Parameters      | Description           | When Triggered                             |
| --------------- | --------------- | --------------------- | ------------------------------------------ |
| `onValueChange` | `value: string` | Tab selection changed | User clicks tab or navigates with keyboard |

#### ARIA

| Attribute          | Value                    | Purpose                   |
| ------------------ | ------------------------ | ------------------------- |
| `data-orientation` | `horizontal \| vertical` | Indicates tab orientation |
| `data-dir`         | `ltr \| rtl`             | Indicates text direction  |

### Tabs.List

#### Props

| Name | Type                | Default | Description                |
| ---- | ------------------- | ------- | -------------------------- |
| `as` | `React.ElementType` | `'div'` | Polymorphic component type |

#### ARIA

| Attribute          | Value                    | Purpose                              |
| ------------------ | ------------------------ | ------------------------------------ |
| `role`             | `tablist`                | Identifies the element as a tab list |
| `aria-orientation` | `horizontal \| vertical` | Indicates tab list orientation       |
| `data-orientation` | `horizontal \| vertical` | Indicates tab list orientation       |

### Tabs.Trigger

Extends all `Button` component props including polymorphic rendering via the `as` prop.

#### Props

| Name               | Type                                                                      | Default     | Description                                         |
| ------------------ | ------------------------------------------------------------------------- | ----------- | --------------------------------------------------- |
| `value`            | `string`                                                                  | —           | Unique identifier for the tab                       |
| `as?`              | `React.ElementType`                                                       | `"button"`  | Element type to render as                           |
| `disabled?`        | `boolean`                                                                 | `false`     | Disables this specific tab                          |
| `autoFocus?`       | `boolean`                                                                 | `false`     | Whether to focus this tab trigger on mount          |
| `isLoading?`       | `boolean`                                                                 | `false`     | Loading state with screen reader support            |
| `isPressed?`       | `boolean`                                                                 | `undefined` | Toggle state - creates a toggle button when defined |
| `onPressedChange?` | `(pressed: boolean) => void`                                              | `undefined` | Callback fired when toggle state changes            |
| `children`         | `React.ReactNode \| ((state: TabsTriggerRenderProps) => React.ReactNode)` | —           | Children content or render function                 |
| `...props`         | `ButtonProps`                                                             | -           | All standard Button component attributes            |

#### TabsTriggerRenderProps

| Property      | Type          | Description                                  |
| ------------- | ------------- | -------------------------------------------- |
| `isSelected`  | `boolean`     | Whether this tab is currently selected       |
| `select`      | `() => void`  | Function to select this tab programmatically |
| `disabled`    | `boolean`     | Whether this tab is disabled                 |
| `isFocused`   | `boolean`     | Whether this tab is currently focused        |
| `orientation` | `Orientation` | The tab's orientation                        |

#### Events

| Name      | Parameters                | Description | When Triggered                           |
| --------- | ------------------------- | ----------- | ---------------------------------------- |
| `onClick` | `event: React.MouseEvent` | Tab clicked | User clicks the tab trigger              |
| `onFocus` | `event: React.FocusEvent` | Tab focused | Tab receives focus via keyboard or mouse |
| `onBlur`  | `event: React.FocusEvent` | Tab blurred | Tab loses focus                          |

#### ARIA

| Attribute          | Value                    | Purpose                         |
| ------------------ | ------------------------ | ------------------------------- |
| `role`             | `tab`                    | Identifies the element as a tab |
| `aria-selected`    | `true \| false`          | Indicates if tab is selected    |
| `aria-controls`    | `string`                 | References controlled tabpanel  |
| `aria-disabled`    | `true \| false`          | Indicates if tab is disabled    |
| `tabIndex`         | `0 \| -1`                | Manages focus in tab list       |
| `data-state`       | `active \| inactive`     | Indicates tab state             |
| `data-disabled`    | `'' \| undefined`        | Indicates disabled state        |
| `data-orientation` | `horizontal \| vertical` | Indicates tab orientation       |
| `data-value`       | `string`                 | Tab's unique value              |
| `data-autofocus`   | `'' \| undefined`        | Indicates auto-focus state      |

### Tabs.Content

#### Props

| Name         | Type                | Default | Description                                     |
| ------------ | ------------------- | ------- | ----------------------------------------------- |
| `value`      | `string`            | —       | Unique identifier matching a Tabs.Trigger value |
| `forceMount` | `boolean`           | `false` | Force content to remain mounted when not active |
| `as`         | `React.ElementType` | `'div'` | Polymorphic component type                      |

#### ARIA

| Attribute          | Value                    | Purpose                               |
| ------------------ | ------------------------ | ------------------------------------- |
| `role`             | `tabpanel`               | Identifies the element as a tab panel |
| `aria-labelledby`  | `string`                 | References controlling tab            |
| `tabIndex`         | `0`                      | Makes panel focusable                 |
| `hidden`           | `true \| false`          | Hides inactive panels                 |
| `data-state`       | `active \| inactive`     | Indicates panel state                 |
| `data-orientation` | `horizontal \| vertical` | Indicates tab orientation             |

## Keyboard Interactions

| Key                | Action                                        | Context                | Notes                     |
| ------------------ | --------------------------------------------- | ---------------------- | ------------------------- |
| `Tab`              | Move focus to next/previous focusable element | Global                 | Standard browser behavior |
| `Enter` or `Space` | Activate focused tab                          | Tab trigger focused    | Changes active panel      |
| `ArrowRight`       | Focus next tab                                | Horizontal orientation | Wraps to first tab        |
| `ArrowLeft`        | Focus previous tab                            | Horizontal orientation | Wraps to last tab         |
| `ArrowDown`        | Focus next tab                                | Vertical orientation   | Wraps to first tab        |
| `ArrowUp`          | Focus previous tab                            | Vertical orientation   | Wraps to last tab         |
| `Home`             | Focus first tab                               | Tab list focused       | Always moves to first tab |
| `End`              | Focus last tab                                | Tab list focused       | Always moves to last tab  |

**Note**: In `automatic` activation mode, arrow keys both focus and activate tabs. In `manual` mode, arrow keys only move focus - you must press Enter or Space to activate.
