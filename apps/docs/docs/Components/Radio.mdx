## Features

- ✅ Mutually exclusive selection within radio groups
- ✅ Controlled and uncontrolled state management
- ✅ Roving tabindex for optimal keyboard navigation
- ✅ Form integration with hidden inputs
- ✅ Individual item disable functionality
- ✅ Horizontal and vertical orientation support
- ✅ Polymorphic component API with custom element support
- ✅ Focus management with visual indicators

```tsx
<Radio.Group>
  <Radio.Item />
  <Radio.Item />
  <Radio.Item />
</Radio.Group>
```

**Alternative: Tree-shakeable named imports**

```tsx
import { RadioGroup, RadioItem } from '@turkish-technology/spar';

<RadioGroup>
  <RadioItem />
  <RadioItem />
  <RadioItem />
</RadioGroup>;
```

**Data Flow:**

- `Radio.Group` manages selection state and provides context
- `Radio.Item` components register with the group and handle individual interactions
- Focus management ensures only one radio is tabbable at a time
- Hidden inputs provide form integration and accessibility

## Code Examples

### Basic Controlled Radio Group

```tsx
function ControlledRadio() {
  const [selectedValue, setSelectedValue] = React.useState('medium');

  return (
    <Radio.Group value={selectedValue} onValueChange={setSelectedValue} aria-label='Size selection'>
      <Radio.Item value='small'>Small</Radio.Item>
      <Radio.Item value='medium'>Medium</Radio.Item>
      <Radio.Item value='large'>Large</Radio.Item>
    </Radio.Group>
  );
}
```

### Uncontrolled Radio Group with Default Value

```tsx
function UncontrolledRadio() {
  const handleValueChange = (value: string) => {

  return (

      <Radio.Item value='gold'>Gold Membership</Radio.Item>
```

### Form Integration

```tsx
function FormRadio() {
  const [paymentMethod, setPaymentMethod] = React.useState('credit');

  const handleSubmit = (event: React.FormEvent) => {
    event.preventDefault();
    const formData = new FormData(event.target as HTMLFormElement);
    console.log('Payment method:', formData.get('payment'));
  };

  return (
    <form onSubmit={handleSubmit}>
      <Radio.Group
        value={paymentMethod}
        onValueChange={setPaymentMethod}
        name='payment'
        required
        aria-label='Payment method'
      >
        <Radio.Item value='credit'>Credit Card</Radio.Item>
        <Radio.Item value='debit'>Debit Card</Radio.Item>
        <Radio.Item value='paypal'>PayPal</Radio.Item>
        <Radio.Item value='bank'>Bank Transfer</Radio.Item>
      </Radio.Group>
      <button type='submit'>Continue</button>
    </form>
  );
}
```

## API Reference

### Radio.Group

The root container that manages the radio group state and provides keyboard navigation.

**Props**

| Name                | Type                         | Default      | Description                                        |
| ------------------- | ---------------------------- | ------------ | -------------------------------------------------- |
| `value?`            | `string`                     | `undefined`  | Controlled selected value                          |
| `defaultValue?`     | `string`                     | `undefined`  | Uncontrolled initial value                         |
| `onValueChange?`    | `(value: string) => void`    | `undefined`  | Selection change handler                           |
| `name?`             | `string`                     | `undefined`  | HTML name for form submission                      |
| `disabled?`         | `boolean`                    | `false`      | Disables entire radio group                        |
| `required?`         | `boolean`                    | `false`      | Marks group as required for forms                  |
| `orientation?`      | `'horizontal' \| 'vertical'` | `'vertical'` | Layout direction for keyboard navigation           |
| `isInToolbar?`      | `boolean`                    | `false`      | Changes keyboard behavior per WAI-ARIA guidelines  |
| `shouldAutoFocus?`  | `boolean`                    | `false`      | Whether to focus the first focusable item on mount |
| `aria-label?`       | `string`                     | `undefined`  | Accessible name for the group                      |
| `aria-labelledby?`  | `string`                     | `undefined`  | References element that labels the group           |
| `aria-describedby?` | `string`                     | `undefined`  | References element that describes the group        |
| `as?`               | `ElementType`              | `'div'`      | Polymorphic root element                           |
| `children?`         | `React.ReactNode`            | `undefined`  | Radio.Item components                              |

**Events**

| Name            | Parameters               | Description             | When Triggered                    |
| --------------- | ------------------------ | ----------------------- | --------------------------------- |
| `onValueChange` | `(value: string)`        | Selection state changes | User selects different radio item |
| `onKeyDown`     | `(event: KeyboardEvent)` | Key pressed on group    | Keyboard navigation occurs        |

**HTML Attributes**

| Attribute          | Value                        | Purpose                     |
| ------------------ | ---------------------------- | --------------------------- |
| `data-orientation` | `"horizontal" \| "vertical"` | Indicates layout direction  |
| `data-disabled`    | `""`                         | Present when group disabled |

### Radio.Item

Individual radio option within a Radio.Group that handles selection and accessibility.

**Props**

| Name                | Type                                                                    | Default     | Description                                 |
| ------------------- | ----------------------------------------------------------------------- | ----------- | ------------------------------------------- |
| `value`             | `string`                                                                | -           | Unique identifier for this radio option     |
| `disabled?`         | `boolean`                                                               | `false`     | Disables this specific radio item           |
| `aria-label?`       | `string`                                                                | `undefined` | Accessible name when children insufficient  |
| `aria-describedby?` | `string`                                                                | `undefined` | References element that describes this item |
| `as?`               | `ElementType`                                                         | `'label'`   | Polymorphic root element                    |
| `children?`         | `React.ReactNode \| ((state: RadioItemRenderProps) => React.ReactNode)` | `undefined` | Label content or render props function      |

**Render Props (RadioItemRenderProps)**

| Property    | Type         | Description                                         |
| ----------- | ------------ | --------------------------------------------------- |
| `isChecked` | `boolean`    | Whether this radio item is currently selected       |
| `disabled`  | `boolean`    | Whether this radio item is disabled                 |
| `isFocused` | `boolean`    | Whether this radio item currently has focus         |
| `select`    | `() => void` | Function to programmatically select this radio item |

**Events**

| Name        | Parameters               | Description         | When Triggered            |
| ----------- | ------------------------ | ------------------- | ------------------------- |
| `onClick`   | `(event: MouseEvent)`    | Item clicked        | Mouse click on radio item |
| `onKeyDown` | `(event: KeyboardEvent)` | Key pressed on item | Keyboard interaction      |
| `onFocus`   | `(event: FocusEvent)`    | Item receives focus | Focus management          |

**HTML Attributes**

| Attribute       | Value                      | Purpose                            |
| --------------- | -------------------------- | ---------------------------------- |
| `data-state`    | `"checked" \| "unchecked"` | Indicates selection state          |
| `data-disabled` | `""`                       | Present when item disabled         |
| `data-focused`  | `""`                       | Present when item has focus        |
| `tabIndex`      | `0 \| -1`                  | Manages focus with roving tabindex |

## Keyboard Interactions

Complete keyboard behavior for the Radio component. Behavior changes based on the `isInToolbar` prop:

| Key            | Standard Mode                                       | Toolbar Mode                                       |
| -------------- | --------------------------------------------------- | -------------------------------------------------- |
| `Tab`          | Focus to selected radio or first radio              | Focus to selected radio or first radio             |
| `Shift + Tab`  | Focus away from radio group                         | Focus away from radio group                        |
| `ArrowDown` ↓  | **Move focus + select** next radio (wraps)          | **Move focus only** to next radio (wraps)          |
| `ArrowUp` ↑    | **Move focus + select** previous radio (wraps)      | **Move focus only** to previous radio (wraps)      |
| `ArrowRight` → | **Move focus + select** next radio (horizontal)     | **Move focus only** to next radio (horizontal)     |
| `ArrowLeft` ←  | **Move focus + select** previous radio (horizontal) | **Move focus only** to previous radio (horizontal) |
| `Space`        | Select focused radio (optional)                     | **Select focused radio** (required)                |
| `Enter`        | Select focused radio (optional)                     | **Select focused radio** (required)                |
| `Home`         | **Move + select** first radio                       | **Move focus only** to first radio                 |
| `End`          | **Move + select** last radio                        | **Move focus only** to last radio                  |

### Mode Configuration

- **Standard Mode**: `isInToolbar={false}` (default)
- **Toolbar Mode**: `isInToolbar={true}`

### Behavior Summary

- **Standard Mode**: Arrow keys automatically move focus and select the radio (traditional radio group behavior)
- **Toolbar Mode**: Arrow keys only move focus, Space/Enter required for selection (WAI-ARIA toolbar pattern)
- **Focus Management**: Only one radio receives Tab focus at a time (roving tabindex)
- **Disabled Items**: Automatically skipped during keyboard navigation
- **Wrapping**: Arrow navigation wraps from last to first and vice versa
