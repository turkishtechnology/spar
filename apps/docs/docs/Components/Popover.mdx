### Structure

```jsx
<PopoverRoot>
  <PopoverTrigger>...</PopoverTrigger>
  <PopoverContent>
    <PopoverClose>...</PopoverClose>
  </PopoverContent>
</PopoverRoot>;

{
  /* With optional parts */
}
<PopoverRoot>
  <PopoverAnchor>...</PopoverAnchor>
  <PopoverTrigger>...</PopoverTrigger>
  <PopoverPortal>
    <PopoverContent>
      <PopoverArrow />
      ...
    </PopoverContent>
  </PopoverPortal>
</PopoverRoot>;
```

**Data Flow:**

- `PopoverRoot` manages the open/closed state and provides context to all child components
- `PopoverTrigger` toggles the popover visibility and maintains ARIA relationship with content
- `PopoverContent` positions itself intelligently relative to the trigger with collision detection
- `PopoverClose` provides a way to programmatically close the popover from within the content
- Optional `PopoverAnchor` allows positioning relative to a different element than the trigger
- Optional `PopoverPortal` controls where the content is rendered in the DOM
- Optional `PopoverArrow` adds a decorative visual pointer to the trigger element

- `PopoverRoot`: Root context provider managing popover state
- `PopoverTrigger`: Button that toggles popover visibility
- `PopoverContent`: Floating panel with content
- `PopoverClose`: Optional button to close the popover
- `PopoverArrow`: Optional decorative arrow element
- `PopoverAnchor`: Optional custom positioning reference
- `PopoverPortal`: Optional portal container for custom rendering

## Code Examples

### Basic Popover

Simple popover with trigger and content:

```tsx
export function BasicPopover() {
  return (
    <PopoverRoot>
      <PopoverTrigger>Show Info</PopoverTrigger>
      <PopoverContent>
        <p>This is popover content</p>
      </PopoverContent>
    </PopoverRoot>
  );
}
```

### Controlled Popover

Popover with external state control:

```tsx
export function ControlledPopover() {
  const [open, setOpen] = React.useState(false);

  return (
    <div>
      <button onClick={() => setIsOpen(!isOpen)}>External Toggle</button>

      <PopoverRoot open={open} onOpenChange={setOpen}>
        <PopoverTrigger>Open Popover</PopoverTrigger>
        <PopoverContent>
          <p>Controlled content</p>
        </PopoverContent>
      </PopoverRoot>
    </div>
  );
}
```

### Modal Popover with Focus Trap

Modal popover that traps focus within the content:

```tsx
export function ModalPopover() {
  return (
    <PopoverRoot modal={true}>
      <PopoverTrigger>Open Modal Popover</PopoverTrigger>
      <PopoverContent trapFocus={true}>
        <h2>Modal Popover</h2>
        <p>Focus is trapped within this popover</p>
        <button>First Focusable</button>
        <button>Second Focusable</button>
        <PopoverClose>Close</PopoverClose>
      </PopoverContent>
    </PopoverRoot>
  );
}
```

```tsx
export function PositionedPopover() {
```


### With Focus Management Callbacks

Popover with custom focus management logic:

```tsx
export function PopoverWithFocusCallbacks() {
  const handleOpenAutoFocus = (event: Event) => {
    console.log('Popover opened, focus moved inside');
    // Optionally prevent default focus behavior
    // event.preventDefault();
  };

  const handleCloseAutoFocus = (event: Event) => {
    console.log('Popover closed, focus returned to trigger');
  };

  return (
    <PopoverRoot>
      <PopoverTrigger>Open Popover</PopoverTrigger>
      <PopoverContent onOpenAutoFocus={handleOpenAutoFocus} onCloseAutoFocus={handleCloseAutoFocus}>
        <input placeholder='Auto-focused input' />
        <PopoverClose>Close</PopoverClose>
      </PopoverContent>
    </PopoverRoot>
  );
}
```

### With Outside Interaction Handling

Popover with custom outside interaction logic:

```tsx
export function PopoverWithOutsideHandlers() {
  const handlePointerDownOutside = (event: PointerEvent) => {
    console.log('Clicked outside popover');
    // Optionally prevent default close behavior
    // event.preventDefault();
  };

  const handleEscapeKeyDown = (event: KeyboardEvent) => {
    console.log('Escape key pressed');
  };

  return (
    <PopoverRoot>
      <PopoverTrigger>Open Popover</PopoverTrigger>
      <PopoverContent
        onPointerDownOutside={handlePointerDownOutside}
        onEscapeKeyDown={handleEscapeKeyDown}
      >
        <p>Try clicking outside or pressing Escape</p>
      </PopoverContent>
    </PopoverRoot>
  );
}
```

### Custom Portal Container

Popover rendered in a specific container element:

```tsx
export function PopoverWithCustomPortal() {

          </PopoverContent>
        </PopoverPortal>

  );
}
```

## API Reference

### PopoverRoot

The root container that provides context and manages state for all popover components within it.

**Props**

| Name            | Type                                     | Default     | Description                                      |
| --------------- | ---------------------------------------- | ----------- | ------------------------------------------------ |
| `open?`         | `boolean`                                | `undefined` | Controlled state for popover visibility          |
| `onOpenChange?` | `(open: boolean) => void`                | `undefined` | Callback when popover open state changes         |
| `defaultOpen?`  | `boolean`                                | `false`     | Initial open state for uncontrolled mode         |
| `modal?`        | `boolean`                                | `false`     | Whether popover should behave modally            |
| `disabled?`     | `boolean`                                | `false`     | Disables all popover triggers (prevents opening) |
| `side?`         | `"top" \| "bottom" \| "left" \| "right"` | `"bottom"`  | Preferred side for popover positioning           |
| `align?`        | `"start" \| "center" \| "end"`           | `"center"`  | Preferred alignment relative to trigger          |
| `sideOffset?`   | `number`                                 | `8`         | Distance in pixels between trigger and popover   |
| `children`      | `ReactNode`                              | -           | PopoverTrigger and PopoverContent components     |

**Events**

| Name           | Parameters        | Description                      | When Triggered                          |
| -------------- | ----------------- | -------------------------------- | --------------------------------------- |
| `onOpenChange` | `(open: boolean)` | State changes when opened/closed | User interaction or programmatic change |

**HTML Attributes**

| Attribute    | Value                | Purpose                 |
| ------------ | -------------------- | ----------------------- |
| `data-state` | `"open" \| "closed"` | Indicates popover state |

### PopoverTrigger

Button element that toggles the popover visibility. Extends all `Button` component props including polymorphic rendering via the `as` prop.

**Props**

| Name               | Type                                                             | Default     | Description                                         |
| ------------------ | ---------------------------------------------------------------- | ----------- | --------------------------------------------------- |
| `as?`              | `ElementType`                                                    | `"button"`  | Element type to render as                           |
| `children`         | `ReactNode \| ((state: PopoverTriggerRenderProps) => ReactNode)` | -           | Trigger content or render props function            |
| `disabled?`        | `boolean`                                                        | `false`     | Whether trigger is disabled                         |
| `autoFocus?` | `boolean`                                                        | `false`     | Whether the button should receive focus on mount    |
| `isLoading?`       | `boolean`                                                        | `false`     | Loading state with screen reader support            |
| `isPressed?`       | `boolean`                                                        | `undefined` | Toggle state - creates a toggle button when defined |
| `onPressedChange?` | `(pressed: boolean) => void`                                     | `undefined` | Callback fired when toggle state changes            |
| `onClick?`         | `(event: React.MouseEvent<HTMLButtonElement>) => void`           | `undefined` | Custom click handler                                |
| `onKeyDown?`       | `(event: React.KeyboardEvent<HTMLButtonElement>) => void`        | `undefined` | Custom keydown handler                              |
| `ref?`             | `React.Ref<HTMLButtonElement>`                                   | `undefined` | Ref to the trigger element                          |
| `...props`         | `ButtonProps`                                                    | -           | All standard Button component attributes            |

**Render Props (PopoverTriggerRenderProps)**

| Property   | Type         | Description                                     |
| ---------- | ------------ | ----------------------------------------------- |
| `isOpen`   | `boolean`    | Whether the popover is currently visible        |
| `disabled` | `boolean`    | Whether the trigger is disabled                 |
| `open`     | `() => void` | Function to programmatically open the popover   |
| `close`    | `() => void` | Function to programmatically close the popover  |
| `toggle`   | `() => void` | Function to programmatically toggle the popover |

**Events**

| Name        | Parameters                                        | Description            | When Triggered         |
| ----------- | ------------------------------------------------- | ---------------------- | ---------------------- |
| `onClick`   | `(event: React.MouseEvent<HTMLButtonElement>)`    | Trigger clicked        | Mouse click on trigger |
| `onKeyDown` | `(event: React.KeyboardEvent<HTMLButtonElement>)` | Key pressed on trigger | Keyboard interaction   |

**HTML Attributes**

| Attribute       | Value                | Purpose                   |
| --------------- | -------------------- | ------------------------- |
| `data-state`    | `"open" \| "closed"` | Indicates popover state   |
| `data-disabled` | `string`             | Indicates disabled state  |
| `disabled`      | `boolean`            | Native disabled attribute |

### PopoverContent

Floating panel container that holds the popover content.

**Props**

| Name                    | Type                                                   | Default     | Description                                             |
| ----------------------- | ------------------------------------------------------ | ----------- | ------------------------------------------------------- |
| `side?`                 | `"top" \| "bottom" \| "left" \| "right"`               | `"bottom"`  | Side of trigger to position against                     |
| `align?`                | `"start" \| "center" \| "end"`                         | `"center"`  | Alignment relative to trigger                           |
| `sideOffset?`           | `number`                                               | `8`         | Distance from trigger in pixels                         |
| `alignOffset?`          | `number`                                               | `0`         | Offset along alignment axis                             |
| `avoidCollisions?`      | `boolean`                                              | `true`      | Whether to adjust position to avoid viewport collisions |
| `collisionBoundary?`    | `Element \| Element[]`                                 | `undefined` | Boundary elements for collision detection               |
| `hideWhenDetached?`     | `boolean`                                              | `false`     | Whether to hide when trigger is occluded                |
| `onOpenAutoFocus?`      | `(event: Event) => void`                               | `undefined` | Called when popover opens and focus moves inside        |
| `onCloseAutoFocus?`     | `(event: Event) => void`                               | `undefined` | Called when popover closes and focus returns to trigger |
| `onEscapeKeyDown?`      | `(event: KeyboardEvent) => void`                       | `undefined` | Called when escape is pressed                           |
| `onPointerDownOutside?` | `(event: PointerEvent) => void`                        | `undefined` | Called when pointer down occurs outside content         |
| `onFocusOutside?`       | `(event: FocusEvent) => void`                          | `undefined` | Called when focus moves outside content                 |
| `onInteractOutside?`    | `(event: PointerEvent \| FocusEvent) => void`          | `undefined` | Called when interaction occurs outside content          |
| `trapFocus?`            | `boolean`                                              | `false`     | Whether to trap focus within content                    |
| `style?`                | `React.CSSProperties`                                  | `undefined` | Custom styles for content                               |
| `onKeyDown?`            | `(event: React.KeyboardEvent<HTMLDivElement>) => void` | `undefined` | Custom keydown handler                                  |
| `ref?`                  | `React.Ref<HTMLDivElement>`                            | `undefined` | Ref to the content element                              |
| `children`              | `ReactNode`                                            | -           | Content to display in popover                           |

**Events**

| Name                   | Parameters                                     | Description                       | When Triggered                      |
| ---------------------- | ---------------------------------------------- | --------------------------------- | ----------------------------------- |
| `onOpenAutoFocus`      | `(event: Event)`                               | Focus moves inside on open        | Popover opens                       |
| `onCloseAutoFocus`     | `(event: Event)`                               | Focus returns to trigger on close | Popover closes                      |
| `onEscapeKeyDown`      | `(event: KeyboardEvent)`                       | Escape key pressed                | User presses Escape                 |
| `onPointerDownOutside` | `(event: PointerEvent)`                        | Pointer down outside content      | Click/touch outside popover         |
| `onFocusOutside`       | `(event: FocusEvent)`                          | Focus moves outside content       | Focus leaves popover                |
| `onInteractOutside`    | `(event: PointerEvent \| FocusEvent)`          | Any interaction outside content   | Click, touch, or focus outside      |
| `onKeyDown`            | `(event: React.KeyboardEvent<HTMLDivElement>)` | Key pressed within content        | Keyboard interaction inside popover |

**HTML Attributes**

| Attribute    | Value                                    | Purpose                   |
| ------------ | ---------------------------------------- | ------------------------- |
| `id`         | `string`                                 | Unique identifier         |
| `tabIndex`   | `-1`                                     | Allows programmatic focus |
| `data-state` | `"open"`                                 | Always open when rendered |
| `data-side`  | `"top" \| "bottom" \| "left" \| "right"` | Actual positioned side    |
| `data-align` | `"start" \| "center" \| "end"`           | Actual alignment          |

| `Tab`         | Navigate             | Always                          | Moves focus through interactive elements in DOM order |
| `Shift + Tab` | Navigate backward    | Always                          | Moves focus backward through interactive elements     |
| `Enter`       | Toggle popover       | Focused trigger                 | Opens or closes the popover                           |
| `Space`       | Toggle popover       | Focused trigger                 | Alternative activation method for trigger             |
| `ArrowDown`   | Open popover         | Focused trigger                 | Opens popover if closed                               |
| `Escape`      | Close popover        | Popover open                    | Closes popover and returns focus to trigger           |
| `Home`        | First focusable      | Inside popover                  | Moves focus to first focusable element in popover     |
| `End`         | Last focusable       | Inside popover                  | Moves focus to last focusable element in popover      |
| `Tab`         | Cycle focus forward  | Inside popover (trapFocus=true) | Cycles through popover content, wraps at end          |
| `Shift + Tab` | Cycle focus backward | Inside popover (trapFocus=true) | Cycles through popover content, wraps at start        |
