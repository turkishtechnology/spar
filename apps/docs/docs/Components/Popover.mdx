## Features

- ✅ Controlled and uncontrolled open state (`open`, `defaultOpen`, `onOpenChange`)
- ✅ Floating positioning with preferred `side` and `align`
- ✅ Automatic collision handling (flip/shift/hide middleware)
- ✅ Portaled content rendering (`document.body` by default, custom `container` supported)
- ✅ Dismiss behavior for pointer and focus interactions outside content
- ✅ Optional modal mode and optional focus trap
- ✅ Polymorphic rendering support via `as` prop on Trigger, Content, Arrow, and Close

### Structure

```tsx
<Popover.Root>
  <Popover.Trigger>...</Popover.Trigger>
  <Popover.Content>
    <Popover.Arrow />
    <Popover.Close>...</Popover.Close>
    ...
  </Popover.Content>
</Popover.Root>
```

**Data Flow:**

- `Popover.Root` owns shared state (`isOpen`, refs, ids, options) and exposes it through context.
- `Popover.Trigger` reads context and toggles/open state while applying trigger ARIA attributes.
- `Popover.Content` reads context, handles focus/dismiss behavior, computes placement, and portals the panel.
- `Popover.Close` calls shared close logic from inside content.
- `Popover.Arrow` reads computed placement from content context and syncs arrow positioning.

## Code Examples

### Basic Popover

Simple popover with trigger and content:

```tsx
export function BasicPopover() {
  return (
    <Popover.Root>
      <Popover.Trigger>Show Info</Popover.Trigger>
      <Popover.Content>
        <p>This is popover content.</p>
      </Popover.Content>
    </Popover.Root>
  );
}
```

### Controlled Popover

Popover with external state control:

```tsx
export function ControlledPopover() {
  const [open, setOpen] = React.useState(false);

  return (
    <div>
      <button onClick={() => setOpen((value) => !value)}>External Toggle</button>

      <Popover.Root open={open} onOpenChange={setOpen}>
        <Popover.Trigger>Open Popover</Popover.Trigger>
        <Popover.Content>
          <p>Controlled content</p>
        </Popover.Content>
      </Popover.Root>
    </div>
  );
}
```

### Modal Popover with Focus Trap

Modal popover. In modal mode, content is rendered with `role="dialog"` and focus is trapped while open:

```tsx
export function ModalPopover() {
  return (
    <Popover.Root modal>
      <Popover.Trigger>Open Modal Popover</Popover.Trigger>
      <Popover.Content>
        <h2>Modal Popover</h2>
        <p>Focus is trapped within this popover</p>
        <button>First Focusable</button>
        <button>Second Focusable</button>
        <Popover.Close>Close</Popover.Close>
      </Popover.Content>
    </Popover.Root>
  );
}
```

    // Notification callback only (no preventDefault behavior on open)

    console.log('Popover closed, focus returned to trigger');

## API Reference

### Popover.Root

The root container that provides context and manages state for all popover components within it.

**Props**

| Name            | Type                      | Default     | Description                                                              |
| --------------- | ------------------------- | ----------- | ------------------------------------------------------------------------ |
| `id?`           | `string`                  | `undefined` | Custom base ID for ARIA relationships (`${id}-content`)                  |
| `open?`         | `boolean`                 | `undefined` | Controlled open state                                                    |
| `onOpenChange?` | `(open: boolean) => void` | `undefined` | Called when open state changes                                           |
| `defaultOpen?`  | `boolean`                 | `false`     | Initial open state in uncontrolled mode                                  |
| `modal?`        | `boolean`                 | `false`     | Enables modal behavior for content                                       |
| `disabled?`     | `boolean`                 | `false`     | Disables trigger-driven opening/toggling                                 |
| `children?`     | `React.ReactNode`         | `undefined` | Compound parts (`Popover.Trigger`, `Popover.Content`, optional children) |

**Events**

| Name           | Parameters        | Description                      | When Triggered                          |
| -------------- | ----------------- | -------------------------------- | --------------------------------------- |
| `onOpenChange` | `(open: boolean)` | State changes when opened/closed | User interaction or programmatic change |

**HTML Attributes**

| Attribute    | Value                | Purpose                 |
| ------------ | -------------------- | ----------------------- |
| `data-state` | `"open" \| "closed"` | Indicates popover state |

### Popover.Trigger

Button element that toggles the popover visibility. Extends all `Button` component props including polymorphic rendering via the `as` prop.

**Props**

| Name               | Type                                                                         | Default     | Description                                                                  |
| ------------------ | ---------------------------------------------------------------------------- | ----------- | ---------------------------------------------------------------------------- |
| `as?`              | `React.ElementType`                                                          | `"button"`  | Polymorphic element type                                                     |
| `children?`        | `React.ReactNode \| ((state: PopoverTriggerRenderProps) => React.ReactNode)` | `undefined` | Trigger content or render function                                           |
| `disabled?`        | `boolean`                                                                    | `false`     | Disables trigger interaction (also respects `Popover.Root disabled`)         |
| `isLoading?`       | `boolean`                                                                    | `false`     | Inherited from `Button`; blocks interactive activation                       |
| `isPressed?`       | `boolean`                                                                    | `undefined` | Inherited toggle state from `Button`                                         |
| `onPressedChange?` | `(pressed: boolean) => void`                                                 | `undefined` | Inherited toggle callback from `Button`                                      |
| `...props`         | `PopoverTriggerProps<T>`                                                     | `undefined` | Inherits polymorphic button props (including native HTML and event handlers) |

**Render Props (PopoverTriggerRenderProps)**

| Property   | Type         | Description                                     |
| ---------- | ------------ | ----------------------------------------------- |
| `isOpen`   | `boolean`    | Whether the popover is currently visible        |
| `disabled` | `boolean`    | Whether the trigger is disabled                 |
| `open`     | `() => void` | Function to programmatically open the popover   |
| `close`    | `() => void` | Function to programmatically close the popover  |
| `toggle`   | `() => void` | Function to programmatically toggle the popover |

**Events**

| Name        | Parameters                                        | Description            | When Triggered         |
| ----------- | ------------------------------------------------- | ---------------------- | ---------------------- |
| `onClick`   | `(event: React.MouseEvent<HTMLButtonElement>)`    | Trigger clicked        | Mouse click on trigger |
| `onKeyDown` | `(event: React.KeyboardEvent<HTMLButtonElement>)` | Key pressed on trigger | Keyboard interaction   |

**HTML Attributes**

| Attribute       | Value                | Purpose                                                                            |
| --------------- | -------------------- | ---------------------------------------------------------------------------------- |
| `aria-expanded` | `boolean`            | Reflects open state                                                                |
| `aria-controls` | `string`             | Points to content ID from root context                                             |
| `aria-haspopup` | `"dialog"`           | Announces popup type                                                               |
| `data-state`    | `"open" \| "closed"` | Styling/state hook                                                                 |
| `data-disabled` | `""`                 | Present when disabled (inherited from `Button`)                                    |
| `disabled`      | `boolean`            | Native disabled attribute when rendered as a native `<button>`                     |
| `aria-disabled` | `true`               | Applied when disabled and rendered as non-button element (inherited from `Button`) |

### Popover.Content

Floating panel container that holds the popover content.

**Props**

| Name                    | Type                                          | Default         | Description                                                                          |
| ----------------------- | --------------------------------------------- | --------------- | ------------------------------------------------------------------------------------ |
| `as?`                   | `React.ElementType`                           | `"div"`         | Polymorphic element type                                                             |
| `side?`                 | `"top" \| "bottom" \| "left" \| "right"`      | `"bottom"`      | Preferred side                                                                       |
| `align?`                | `"start" \| "center" \| "end"`                | `"center"`      | Preferred alignment                                                                  |
| `container?`            | `HTMLElement \| null`                         | `document.body` | Portal container                                                                     |
| `onOpenAutoFocus?`      | `(event: Event) => void`                      | `undefined`     | Called after open-time focus move into content                                       |
| `onCloseAutoFocus?`     | `(event: Event) => void`                      | `undefined`     | Called during close; `event.preventDefault()` prevents restoring focus to trigger    |
| `onEscapeKeyDown?`      | `(event: KeyboardEvent) => void`              | `undefined`     | Called on `Escape`; `event.preventDefault()` prevents close                          |
| `onPointerDownOutside?` | `(event: PointerEvent) => void`               | `undefined`     | Called on pointer-down outside; `event.preventDefault()` prevents close              |
| `onFocusOutside?`       | `(event: FocusEvent) => void`                 | `undefined`     | Called on focus moving outside; `event.preventDefault()` prevents close              |
| `onInteractOutside?`    | `(event: PointerEvent \| FocusEvent) => void` | `undefined`     | Called for both outside pointer and outside focus interactions                       |
| `trapFocus?`            | `boolean`                                     | `false`         | Enables focus trap while open (modal also enables focus trap)                        |
| `children?`             | `React.ReactNode`                             | `undefined`     | Popover panel content                                                                |
| `...props`              | `PopoverContentProps<T>`                      | `undefined`     | Inherits polymorphic element props (including `style`, `onKeyDown`, HTML attributes) |

**Events**

| Name                   | Parameters                                     | Description                             | When Triggered                      |
| ---------------------- | ---------------------------------------------- | --------------------------------------- | ----------------------------------- |
| `onOpenAutoFocus`      | `(event: Event)`                               | Open-time focus notification            | Content opens                       |
| `onCloseAutoFocus`     | `(event: Event)`                               | Close-time focus restore hook           | Content closes                      |
| `onEscapeKeyDown`      | `(event: KeyboardEvent)`                       | Escape key hook                         | `Escape` is pressed while open      |
| `onPointerDownOutside` | `(event: PointerEvent)`                        | Pointer outside hook                    | Pointer down occurs outside content |
| `onFocusOutside`       | `(event: FocusEvent)`                          | Focus outside hook                      | Focus moves outside content         |
| `onInteractOutside`    | `(event: PointerEvent \| FocusEvent)`          | Combined outside interaction hook       | Outside pointer/focus interactions  |
| `onKeyDown`            | `(event: React.KeyboardEvent<HTMLDivElement>)` | Element keydown handler from HTML props | Keydown on the content element      |

**HTML Attributes**

| Attribute    | Value                                    | Purpose                     |
| ------------ | ---------------------------------------- | --------------------------- |
| `id`         | `string`                                 | Unique identifier           |
| `tabIndex`   | `-1`                                     | Allows programmatic focus   |
| `data-state` | `"open"`                                 | Always open when rendered   |
| `data-side`  | `"top" \| "bottom" \| "left" \| "right"` | Actual positioned side      |
| `data-align` | `"start" \| "center" \| "end"`           | Actual alignment            |
| `role`       | `"dialog"`                               | Applied when `modal={true}` |
| `aria-modal` | `"true"`                                 | Applied when `modal={true}` |

### Popover.Arrow

Optional decorative arrow element that points to the trigger. Headless: renders a plain element with no visual opinions — user provides all styling.

Supports polymorphic rendering via the `as` prop. When rendered as the default `svg`, sensible SVG defaults (`width`, `height`, `viewBox`, and a triangle `polygon`) are applied automatically. When rendered as another element (e.g., `as="div"`), SVG-specific attributes and default children are omitted.

**Props**

| Name        | Type                   | Default     | Description                                                                         |
| ----------- | ---------------------- | ----------- | ----------------------------------------------------------------------------------- |
| `as?`       | `React.ElementType`    | `"svg"`     | Polymorphic element type                                                            |
| `children?` | `React.ReactNode`      | `undefined` | Custom arrow content; when omitted and `as="svg"`, a default triangle is rendered   |
| `...props`  | `PopoverArrowProps<T>` | `undefined` | Inherits polymorphic element props (including `style`, `className`, SVG attributes) |

**Events**

| Name | Parameters | Description                | When Triggered |
| ---- | ---------- | -------------------------- | -------------- |
| None | -          | Arrow is purely decorative | -              |

**HTML Attributes**

| Attribute        | Value                                                                                                                                                                | Purpose                                |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------- |
| `aria-hidden`    | `"true"`                                                                                                                                                             | Hidden from assistive technology       |
| `data-placement` | `"top" \| "top-start" \| "top-end" \| "right" \| "right-start" \| "right-end" \| "bottom" \| "bottom-start" \| "bottom-end" \| "left" \| "left-start" \| "left-end"` | Computed from content `side` + `align` |
| `width`          | `10`                                                                                                                                                                 | Default SVG width (`as="svg"`)         |
| `height`         | `5`                                                                                                                                                                  | Default SVG height (`as="svg"`)        |
| `viewBox`        | `"0 0 10 5"`                                                                                                                                                         | Default SVG viewBox (`as="svg"`)       |

## Keyboard Interactions

Complete keyboard behavior for the popover component:

| Key           | Action                | Context                                    | Notes                                                           |
| ------------- | --------------------- | ------------------------------------------ | --------------------------------------------------------------- |
| `Enter`       | Toggle popover        | Focused `Popover.Trigger`                  | Trigger inherits `Button` keyboard activation                   |
| `Space`       | Toggle popover        | Focused `Popover.Trigger`                  | Same activation path as `Enter`                                 |
| `ArrowDown`   | Open popover          | Focused `Popover.Trigger`                  | Opens only if currently closed (does not toggle closed)         |
| `Escape`      | Close popover         | While popover is open                      | Can be prevented with `onEscapeKeyDown(event.preventDefault())` |
| `Home`        | Focus first item      | Focus is inside `Popover.Content`          | Moves focus to first focusable element in content               |
| `End`         | Focus last item       | Focus is inside `Popover.Content`          | Moves focus to last focusable element in content                |
| `Tab`         | Wrap to first element | Focus trap active (`modal` or `trapFocus`) | Wrap occurs only when focus is on the last focusable element    |
| `Shift + Tab` | Wrap to last element  | Focus trap active (`modal` or `trapFocus`) | Wrap occurs only when focus is on the first focusable element   |
