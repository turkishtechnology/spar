# Button Component

Button component'i modern headless UI kütüphanemizin temel bileşenlerinden biridir.

## Temel Kullanım

<LiveCode 
  code={`function ButtonExample() {
  const [count, setCount] = React.useState(0);
  
  return (
    <div style={{ 
      display: 'flex', 
      flexDirection: 'column', 
      alignItems: 'center', 
      gap: '1rem',
      padding: '2rem',
      borderRadius: '8px',
      background: 'rgba(201, 0, 25, 0.1)',
      border: '1px solid rgba(201, 0, 25, 0.2)'
    }}>
      <button
        onClick={() => setCount(count + 1)}
        style={{
          background: '#c90019',
          color: 'white',
          border: 'none',
          padding: '12px 24px',
          borderRadius: '8px',
          fontSize: '16px',
          cursor: 'pointer',
          fontWeight: '600',
          transition: 'all 0.2s ease',
          transform: 'scale(1)',
        }}
        onMouseEnter={(e) => {
          e.target.style.transform = 'scale(1.05)';
          e.target.style.boxShadow = '0 4px 12px rgba(201, 0, 25, 0.3)';
        }}
        onMouseLeave={(e) => {
          e.target.style.transform = 'scale(1)';
          e.target.style.boxShadow = 'none';
        }}
      >
        Tıkladınız: {count} kez
      </button>
      
      <button
        onClick={() => setCount(0)}
        style={{
          background: 'transparent',
          color: '#c90019',
          border: '2px solid #c90019',
          padding: '10px 20px',
          borderRadius: '8px',
          fontSize: '14px',
          cursor: 'pointer',
          fontWeight: '500',
        }}
      >
        Sıfırla
      </button>
    </div>
  );
}`}
/>
