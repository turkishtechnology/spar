# Select

A headless, fully accessible dropdown component that allows users to choose a single value from a list of options with complete WAI-ARIA Listbox pattern implementation.

## Features

- ✅ Single value selection from dropdown list
- ✅ Controlled and uncontrolled state management
- ✅ Type-ahead search with character navigation
- ✅ Advanced positioning with Floating UI integration
- ✅ Automatic collision detection and viewport boundary awareness
- ✅ Flexible placement options (12 standard placements)
- ✅ Smart flipping and shifting to stay in view
- ✅ Automatic size constraints based on available space
- ✅ Form integration with native HTML support
- ✅ Portal rendering for z-index control

- ✅ Optional visual arrow indicator with automatic positioning
- ✅ Disabled state for items and entire select
- ✅ RTL (right-to-left) language support

### Structure

```tsx
<Select.Root>
  <Select.Trigger>
    <Select.Value />
    <Select.Icon />
  </Select.Trigger>

  <Select.Portal>
    <Select.Content>
      <Select.Viewport>
        <Select.Group>
          <Select.Label />
          <Select.Item>
            <Select.ItemText />
            <Select.ItemIndicator />
          </Select.Item>
        </Select.Group>

        <Select.Separator />
        <Select.Arrow />
      </Select.Viewport>
    </Select.Content>
  </Select.Portal>
</Select.Root>
```

**Data Flow:**
- `Select.Root` manages state (open/value) and provides context to all child components
- `Select.Trigger` toggles dropdown open/closed state and displays current selection
- `Select.Value` displays the selected item's text or placeholder when nothing is selected
- `Select.Icon` provides visual feedback for the dropdown state (optional)
- `Select.Portal` renders content outside DOM hierarchy for proper z-index stacking
- `Select.Content` uses Floating UI for intelligent positioning relative to trigger
- `Select.Viewport` provides scrollable container when items exceed available space
- `Select.Group` organizes related items and associates them with labels
- `Select.Label` provides semantic grouping labels for screen readers
- `Select.Item` registers with root context and handles selection on click/keyboard
- `Select.ItemText` provides the text value for type-ahead search and display
- `Select.ItemIndicator` shows selected state visually (checkmark, icon, etc.)
- `Select.Separator` provides visual separation between groups or items
- `Select.Arrow` points to trigger when using Floating UI arrow middleware (optional)

## API Reference

### Select.Root

The main container that manages all select state and behavior.

**Props**

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `value?` | `string` | `undefined` | Controlled selected value |
| `defaultValue?` | `string` | `undefined` | Uncontrolled initial value |
| `onValueChange?` | `(value: string) => void` | `undefined` | Callback when selection changes |
| `open?` | `boolean` | `undefined` | Controlled open state |
| `defaultOpen?` | `boolean` | `false` | Uncontrolled initial open state |
| `onOpenChange?` | `(open: boolean) => void` | `undefined` | Callback when open state changes |
| `isDisabled?` | `boolean` | `false` | Disables the entire select |
| `required?` | `boolean` | `false` | Makes the select required for forms |
| `name?` | `string` | `undefined` | Form field name |
| `dir?` | `'ltr' \| 'rtl'` | `'ltr'` | Reading direction |
| `as?` | `ElementType` | `undefined` | Polymorphic component type |
| `children` | `ReactNode` | - | Select component children |

**Events**

| Name | Parameters | Description | When Triggered |
|------|------------|-------------|----------------|
| `onValueChange` | `(value: string)` | Selection changes | User selects an item or programmatic change |
| `onOpenChange` | `(open: boolean)` | Open state changes | User toggles dropdown or programmatic change |

**ARIA Attributes**

No visual rendering - context provider only.

### Select.Trigger

The button that toggles the dropdown open and closed.

**Props**

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `as?` | `ElementType` | `'button'` | Polymorphic component type |
| `ref?` | `RefObject` | `undefined` | Forward ref support |
| `children` | `ReactNode` | - | Trigger content |

**Events**

| Name | Parameters | Description | When Triggered |
|------|------------|-------------|----------------|
| `onClick` | `(event: MouseEvent)` | Trigger clicked | Mouse click on trigger |
| `onKeyDown` | `(event: KeyboardEvent)` | Key pressed on trigger | Space, Enter, or Arrow keys |
| `onFocus` | `(event: FocusEvent)` | Trigger receives focus | Tab navigation or programmatic focus |
| `onBlur` | `(event: FocusEvent)` | Trigger loses focus | Focus moves away |

**ARIA Attributes**

| Attribute | Value | Purpose | Applied To |
|-----------|-------|---------|------------|
| `role` | `"combobox"` | Identifies interactive dropdown trigger | Trigger element |
| `aria-haspopup` | `"listbox"` | Indicates trigger opens a listbox | Trigger element |
| `aria-expanded` | `boolean` | Current open/closed state | Trigger element |
| `aria-controls` | `string` | References content element ID | Trigger element |
| `aria-disabled` | `boolean` | Disabled state | Trigger element (when disabled) |

**Data Attributes**

- `data-state`: `"open" | "closed"` - Dropdown open state
- `data-disabled`: Present when `isDisabled={true}`
- `data-placeholder`: Present when no value selected

No specific events.

**ARIA Attributes**

| Attribute | Value | Purpose | Applied To |

### Select.Portal

Portal container for rendering dropdown outside DOM hierarchy.

**Props**

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `container?` | `HTMLElement \| null` | `document.body` | Portal target element |
| `forceMount?` | `boolean` | `false` | Force mount for animation control |
| `children` | `ReactNode` | - | Portal content |

**Events**

No specific events.

**ARIA Attributes**

No ARIA attributes - rendering mechanism only.

### Select.Content

The dropdown container that appears when select is open. Uses Floating UI for intelligent positioning.

**Props**

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `placement?` | `Placement` | `'bottom-start'` | Placement relative to trigger. Supports 12 positions: `'top'`, `'top-start'`, `'top-end'`, `'right'`, `'right-start'`, `'right-end'`, `'bottom'`, `'bottom-start'`, `'bottom-end'`, `'left'`, `'left-start'`, `'left-end'` |
| `strategy?` | `'absolute' \| 'fixed'` | `'absolute'` | CSS positioning strategy |
| `middleware?` | `Middleware[]` | `undefined` | Custom Floating UI middleware array for advanced positioning control |
| `offset?` | `number` | `5` | Distance from trigger in pixels |
| `shift?` | `boolean` | `true` | Whether to shift the content to stay in viewport |
| `shiftPadding?` | `number` | `5` | Padding for shift calculations |
| `flip?` | `boolean` | `true` | Whether to flip to opposite side when no space |
| `hide?` | `boolean` | `false` | Whether to hide when trigger is fully scrolled out of view |
| `size?` | `boolean` | `true` | Whether to constrain size to available space |
| `arrowRef?` | `RefObject<HTMLElement \| SVGSVGElement>` | `undefined` | Arrow element ref for arrow positioning |
| `as?` | `ElementType` | `'div'` | Polymorphic component type |
| `ref?` | `RefObject` | `undefined` | Forward ref support |
| `children` | `ReactNode` | - | Content children |

**Events**

| Name | Parameters | Description | When Triggered |
|------|------------|-------------|----------------|
| `onEscapeKeyDown` | `(event: KeyboardEvent)` | Escape key pressed | User presses Escape while dropdown is open |
| `onPointerDownOutside` | `(event: PointerEvent)` | Click outside content | User clicks outside the dropdown |
| `onCloseAutoFocus` | `(event: FocusEvent)` | Focus returns on close | Dropdown closes and focus restoration occurs |

**ARIA Attributes**

| Attribute | Value | Purpose | Applied To |
|-----------|-------|---------|------------|
| `role` | `"listbox"` | Identifies as selectable list | Content element |
| `id` | `string` | Unique content identifier | Content element |
| `aria-labelledby` | `string` | References trigger for accessible name | Content element |

**Data Attributes**

- `data-state`: `"open" | "closed"` - Dropdown open state
- `data-placement`: Floating UI computed placement (e.g., `"bottom-start"`, `"top-end"`)

**Positioning**

SelectContent uses Floating UI for advanced positioning. The component automatically:
- Positions relative to the trigger using the specified `placement`
- Applies `offset` distance from the trigger
- Shifts content to stay within the viewport when `shift={true}`
- Flips to the opposite side when there's no space and `flip={true}`
- Constrains content height to available space when `size={true}`
- Updates position automatically on scroll, resize, and layout changes
- Matches trigger width as minimum width

For arrow positioning, pass an `arrowRef` to both `SelectContent` and `SelectArrow` components.

**Arrow Positioning**

To enable automatic arrow positioning with Floating UI:

1. Create a ref for the arrow: `const arrowRef = React.useRef<SVGSVGElement>(null)`
2. Pass the ref to SelectArrow: `<Select.Arrow ref={arrowRef} />`
3. Pass the same ref to SelectContent: `<Select.Content arrowRef={arrowRef}>`

The arrow will automatically position itself to point at the trigger, accounting for the content's placement.

## Keyboard Interactions

Complete keyboard behavior for the Select component following WAI-ARIA Listbox pattern:

| Key | Action | Context | Notes |
|-----|--------|---------|-------|
| `Space` | Open dropdown / Select item | Trigger focused / Item focused | Opens to selected or first item |
| `Enter` | Open dropdown / Select item | Trigger focused / Item focused | Opens to selected or first item |
| `ArrowDown` | Open dropdown / Navigate down | Trigger focused / Dropdown open | Opens or moves to next item |
| `ArrowUp` | Open dropdown / Navigate up | Trigger focused / Dropdown open | Opens or moves to previous item |
| `Home` | Focus first item | Dropdown open | Moves to first non-disabled item |
| `End` | Focus last item | Dropdown open | Moves to last non-disabled item |
| `PageUp` | Focus first item | Dropdown open | Same as Home |
| `PageDown` | Focus last item | Dropdown open | Same as End |
| `Escape` | Close dropdown | Dropdown open | Returns focus to trigger, no selection |
| `Tab` | Close dropdown, move focus | Dropdown open | Moves to next tabbable element |
| `Shift + Tab` | Close dropdown, move focus backward | Dropdown open | Moves to previous tabbable element |
| `A-Z` / `a-z` | Type-ahead search | Dropdown open | Finds and focuses matching item (1000ms timeout) |

**Type-ahead Behavior:**
- Single character search focuses next matching item
- Multiple characters within 1000ms builds search string
- Search wraps around to beginning if no match found
- Timer resets to 1000ms after each character input
- Disabled items are skipped during search
