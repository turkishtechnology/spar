# Select

Headless accessible single-select dropdown component with typeahead search, keyboard navigation, and form participation.

## Features

- ✅ Controlled & uncontrolled value management
- ✅ Customizable typeahead search with filter function
- ✅ Hidden input for native form participation
- ✅ Portal rendering for overlay content
- ✅ Imperative API via ref (open/close/focus/select)
- ✅ Selection follows focus mode
- ✅ Grouped items with labels
- ✅ Scroll into view for highlighted items
- ✅ External disabled values support

### Custom Typeahead Filter

Implement custom search logic for typeahead functionality.

```tsx
function CustomFilterSelect() {
  // Case-insensitive contains search
  const customFilter = React.useCallback((text: string, typed: string) => {
    return text.toLowerCase().includes(typed.toLowerCase());
  }, []);

  return (
    <SelectRoot filter={customFilter}>
      <SelectTrigger aria-label="Search cities">
        <SelectValue placeholder="Type to search..." />
        <SelectIcon>▾</SelectIcon>
      </SelectTrigger>
      <SelectPortal>
        <SelectContent>
          <SelectViewport>
```

### Imperative Control

Control the Select programmatically using ref methods.

```tsx
function ImperativeSelect() {
  const selectRef = React.useRef<SelectImperativeHandle>(null);

  return (
    <>
      <SelectRoot ref={selectRef} defaultValue="">
        <SelectTrigger aria-label="Select option">
          <SelectValue placeholder="Select..." />
          <SelectIcon>▾</SelectIcon>
        </SelectTrigger>
        <SelectPortal>
          <SelectContent>
            <SelectViewport>
              <SelectItem value="option1">
                <SelectItemText>Option 1</SelectItemText>
              </SelectItem>
              <SelectItem value="option2">
                <SelectItemText>Option 2</SelectItemText>
              </SelectItem>
            </SelectViewport>
          </SelectContent>
        </SelectPortal>
      </SelectRoot>

      <button onClick={() => selectRef.current?.open()}>
        Open Select
      </button>
      <button onClick={() => selectRef.current?.select('option1')}>
        Select Option 1
      </button>
      <button onClick={() => selectRef.current?.focus()}>
        Focus Select
      </button>
    </>
  );
}
```

## API Reference

### SelectRoot

The root component that provides context and state management for all child components.

**Props**

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `value?` | `string` | `undefined` | Controlled selected value |
| `defaultValue?` | `string` | `undefined` | Uncontrolled initial value |
| `onValueChange?` | `(value: string) => void` | `undefined` | Callback when value changes |
| `open?` | `boolean` | `undefined` | Controlled open state |
| `defaultOpen?` | `boolean` | `false` | Initial open state when uncontrolled |
| `onOpenChange?` | `(open: boolean) => void` | `undefined` | Callback when open state changes |
| `disabled?` | `boolean` | `false` | Disables all select interactions |
| `required?` | `boolean` | `false` | Makes the select required in forms |
| `name?` | `string` | `undefined` | Name for hidden form input |
| `id?` | `string` | `undefined` | Base ID for sub-components |
| `loop?` | `boolean` | `true` | Enable wrap-around keyboard navigation |
| `typeaheadDebounce?` | `number` | `350` | Milliseconds before typeahead resets |
| `autoFocus?` | `boolean` | `false` | Focus trigger on mount |
| `dir?` | `'ltr' \| 'rtl'` | `'ltr'` | Text direction |
| `selectionFollowsFocus?` | `boolean` | `false` | Update selection when highlight moves |
| `positioning?` | `SelectPositioningOptions` | `{ side: 'bottom', align: 'start' }` | Advisory positioning preferences |
| `focusStrategy?` | `'active-descendant'` | `'active-descendant'` | Focus management strategy |
| `scrollAlignment?` | `'nearest' \| 'center' \| 'start' \| 'end'` | `'nearest'` | How to align highlighted item when scrolling |
| `onHighlightChange?` | `(value: string \| null) => void` | `undefined` | Callback when highlight changes |
| `filter?` | `(optionText: string, typed: string) => boolean` | `prefix match` | Custom typeahead filter function |
| `disabledValues?` | `string[]` | `[]` | Additional values to disable |
| `children` | `ReactNode` | - | Child components |

**Events**

| Name | Parameters | Description | When Triggered |
|------|------------|-------------|----------------|
| `onValueChange` | `(value: string)` | Value changed | Item selected |
| `onOpenChange` | `(open: boolean)` | Open state changed | Opened or closed |
| `onHighlightChange` | `(value: string \| null)` | Highlight moved | Navigation or typeahead |

**ARIA Attributes**

| Attribute | Value | Purpose | Applied To |
|-----------|-------|---------|------------|
| `data-select-root` | - | Component identifier | Root element |
| `data-state` | `'open' \| 'closed'` | Current state | Root element |

## Keyboard Interactions

| Key | Action | Context | Notes |
|-----|--------|---------|-------|
| `Tab` | Move focus forward | Always | Standard focus navigation |
| `Shift + Tab` | Move focus backward | Always | Reverse focus navigation |
| `Enter` | Open dropdown / Select item | Trigger / Item | Commits selection and closes |
| `Space` | Open dropdown / Select item | Trigger / Item | Same as Enter |
| `Escape` | Close dropdown | Open | Returns focus to trigger |
| `ArrowDown` | Open / Next item | Trigger / Open | Opens if closed, navigates if open |
| `ArrowUp` | Open / Previous item | Trigger / Open | Opens if closed, navigates if open |
| `Home` | First item | Open | Jumps to first enabled item |
| `End` | Last item | Open | Jumps to last enabled item |
| `a-z, 0-9` | Typeahead search | Trigger / Open | Highlights matching item |
