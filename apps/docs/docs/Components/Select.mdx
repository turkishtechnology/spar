# Select

A headless, fully accessible dropdown component that allows users to choose a single value from a list of options with complete WAI-ARIA Listbox pattern implementation.

`Select` does not include dedicated trigger-icon or selected-indicator primitives. Add any chevron, caret, or selected marker directly inside `Select.Trigger` and `Select.Item` so the visual layer stays fully application-owned.

## Features

- ✅ Tekli değer seçimi (`value: string`)
- ✅ Controlled ve uncontrolled kullanım (`value/defaultValue`, `open/defaultOpen`)
- ✅ Dahili type-ahead arama (varsayılan 700ms buffer)
- ✅ `useFloating` ile konumlandırma (offset, flip, shift, hide)
- ✅ Form entegrasyonu (`name` verildiğinde hidden input üretimi)
- ✅ Portal ile içerik render etme (`container` veya `document.body`)
- ✅ Grup, etiket ve ayırıcı ile listeleri bölümleme
- ✅ Root veya Item bazında devre dışı bırakma
- ✅ Root/Trigger/Content/Item tabanlı compound yapı

### Structure

```tsx
<Select.Root>
  <Select.Trigger>
    <Select.Value />
  </Select.Trigger>

  <Select.Content>
    <Select.Group>
      <Select.Label />
      <Select.Item>
        <Select.ItemText />
      </Select.Item>
    </Select.Group>

    <Select.Separator />
    <Select.Arrow />
  </Select.Content>
</Select.Root>
```

**Data Flow:**

- `Select.Root`, açık/kapalı ve seçili değer state'ini yönetir, context sağlar.
- `Select.Trigger`, Root state'ini aç/kapatır; yön tuşlarında Content için odak stratejisi belirler.
- `Select.Value`, seçili `Item` metnini (veya `placeholder`) gösterir.
- `Select.Content`, açıkken portal içine render edilir; highlight ve klavye navigasyonunu yönetir.
- `Select.Item`, seçimi günceller; tıklama veya klavye akışıyla Root değerini değiştirir.
- `Select.ItemText`, type-ahead için metin değerini kaydeder.
- `Select.Group` + `Select.Label`, semantik grup yapısını kurar.
- `Select.Separator`, ayırıcı rolü sağlar.
- `Select.Arrow`, Content yerleşimine göre konumlanan opsiyonel ok öğesidir.

**Alternative: Tree-shakeable named imports**

```tsx
import { SelectRoot, SelectTrigger, SelectValue } from '@turkish-technology/spar';

<SelectRoot>
  <SelectTrigger>
    <SelectValue />
  </SelectTrigger>
  {/* ... */}
</SelectRoot>;
```

## Code Examples

### Basic Controlled Select

Açık state ve seçili değeri parent component'te yönetilen temel örnek:

```tsx
function ControlledSelect() {
  const [selectedFruit, setSelectedFruit] = React.useState('');
  const [open, setOpen] = React.useState(false);

  return (
    <Select.Root
      value={selectedFruit}
      onValueChange={setSelectedFruit}
      open={open}
      onOpenChange={setOpen}
    >
      <Select.Trigger>
        <Select.Value placeholder='Choose a fruit' />
      </Select.Trigger>

      <Select.Content>
        <Select.Item value='apple'>
          <Select.ItemText>Apple</Select.ItemText>
        </Select.Item>
        <Select.Item value='banana'>
          <Select.ItemText>Banana</Select.ItemText>
        </Select.Item>
        <Select.Item value='orange'>
          <Select.ItemText>Orange</Select.ItemText>
        </Select.Item>
      </Select.Content>
    </Select.Root>
  );
}
```

### Form Integration

`name` verildiğinde Root, seçili değer için hidden input üretir.

```tsx
function SelectInForm() {
  const [category, setCategory] = React.useState('');

  const handleSubmit = (event: React.FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    const formData = new FormData(event.currentTarget);
    console.log('Category:', formData.get('category'));
  };

  return (
    <form onSubmit={handleSubmit}>
      <label htmlFor='category-select'>Product Category</label>
      <Select.Root name='category' value={category} onValueChange={setCategory} required>
        <Select.Trigger id='category-select'>
          <Select.Value placeholder='Select category' />
        </Select.Trigger>

        <Select.Content>
          <Select.Item value='electronics'>
            <Select.ItemText>Electronics</Select.ItemText>
          </Select.Item>
          <Select.Item value='clothing'>
            <Select.ItemText>Clothing</Select.ItemText>
          </Select.Item>
          <Select.Item value='books'>
            <Select.ItemText>Books</Select.ItemText>
          </Select.Item>
        </Select.Content>
      </Select.Root>
      <button type='submit'>Submit</button>
    </form>
  );
}
```

## API Reference

### Select.Root

Root state ve context sağlayıcısıdır.

**Props**

| Name             | Type                      | Default     | Description                                             |
| ---------------- | ------------------------- | ----------- | ------------------------------------------------------- |
| `id?`            | `string`                  | `undefined` | ARIA ilişki ID'leri için base id                        |
| `value?`         | `string`                  | `undefined` | Controlled seçili değer                                 |
| `defaultValue?`  | `string`                  | `undefined` | Uncontrolled başlangıç değeri                           |
| `onValueChange?` | `(value: string) => void` | `undefined` | Değer değişim callback'i                                |
| `open?`          | `boolean`                 | `undefined` | Controlled açık/kapalı state                            |
| `defaultOpen?`   | `boolean`                 | `false`     | Uncontrolled başlangıç açık state                       |
| `onOpenChange?`  | `(open: boolean) => void` | `undefined` | Açık/kapalı değişim callback'i                          |
| `disabled?`      | `boolean`                 | `false`     | Tüm Select'i devre dışı bırakır                         |
| `required?`      | `boolean`                 | `false`     | Form için zorunlu alan yapar                            |
| `name?`          | `string`                  | `undefined` | Form alan adı; `value` tanımlıysa hidden input üretilir |
| `dir?`           | `'ltr' \| 'rtl'`          | `'ltr'`     | Yazım yönü                                              |
| `autoFocus?`     | `boolean`                 | `false`     | Trigger'a mount sırasında odak verir                    |
| `as?`            | `React.ElementType`       | `'div'`     | Root için polymorphic element                           |
| `children?`      | `React.ReactNode`         | `undefined` | Root içeriği                                            |

**Events**

| Name            | Parameters        | Description               | When Triggered                                                  |
| --------------- | ----------------- | ------------------------- | --------------------------------------------------------------- |
| `onValueChange` | `(value: string)` | Seçili değer değişir      | Item seçildiğinde veya controlled akışta state güncellendiğinde |
| `onOpenChange`  | `(open: boolean)` | Açık/kapalı state değişir | Trigger etkileşimi veya programatik aç/kapat çağrılarında       |

**HTML Attributes**

| Attribute        | Value | Purpose                            |
| ---------------- | ----- | ---------------------------------- |
| `data-disabled`  | `""`  | Root disabled olduğunda eklenir    |
| `data-autofocus` | `""`  | `autoFocus` true olduğunda eklenir |

Root state'ini açıp kapatan trigger parçasıdır.

**Props**

| Name               | Type                                                                        | Default                 | Description                                         |
| ------------------ | --------------------------------------------------------------------------- | ----------------------- | --------------------------------------------------- |
| `children?`        | `React.ReactNode \| ((state: SelectTriggerRenderProps) => React.ReactNode)` | `undefined`             | Normal içerik veya render-props fonksiyonu          |
| `as?`              | `React.ElementType`                                                         | `'button'`              | Trigger için polymorphic element                    |
| `disabled?`        | `boolean`                                                                   | Root `disabled` değeri  | Trigger disabled değeri; verilmezse Root'tan alınır |
| `autoFocus?`       | `boolean`                                                                   | Root `autoFocus` değeri | Button seviyesinde autofocus                        |
| `isLoading?`       | `boolean`                                                                   | `false`                 | Button loading state (`ButtonOwnProps`)             |
| `isPressed?`       | `boolean`                                                                   | `undefined`             | Button toggle state (`ButtonOwnProps`)              |
| `onPressedChange?` | `(pressed: boolean) => void`                                                | `undefined`             | Button toggle değişim callback'i                    |
| `ref?`             | `React.Ref<HTMLElement>`                                                    | `undefined`             | Forwarded ref                                       |
| `...props`         | `ButtonProps`                                                               | -                       | Button'dan gelen diğer HTML/ARIA props              |

| Property   | Type                  | Description                                      |

**Events**

| Name        | Parameters                                  | Description                       | When Triggered                                     |

| `onFocus`   | `(event: React.FocusEvent<HTMLElement>)`    | Button focus callback             | Trigger odak aldığında                             |
| `onBlur`    | `(event: React.FocusEvent<HTMLElement>)`    | Button blur callback              | Trigger odak kaybettiğinde                         |

## Keyboard Interactions

Gerçek implementasyondaki klavye davranışı:

| Key                | Action                                             | Context        | Notes                                               |
| ------------------ | -------------------------------------------------- | -------------- | --------------------------------------------------- |
| `Enter` / `Space`  | Toggle open/close                                  | Trigger odakta | `Button` activation akışı üzerinden çalışır         |
| `ArrowDown`        | Aç ve selected/first item'e odak stratejisi ata    | Trigger odakta | Sadece kapalıysa açar                               |
| `ArrowUp`          | Aç ve selected/first item'e odak stratejisi ata    | Trigger odakta | Sadece kapalıysa açar                               |
| `Escape`           | Kapat ve Trigger'a odak geri ver                   | Content odakta | `onEscapeKeyDown` içinde `preventDefault` edilmezse |
| `Enter` / `Space`  | Highlighted item'i seç, kapat, Trigger'a odak ver  | Content odakta | Highlighted item yoksa seçim yapılmaz               |
| `ArrowDown`        | Sonraki enabled item'i highlight et                | Content odakta | Listenin sonundan başa sarar                        |
| `ArrowUp`          | Önceki enabled item'i highlight et                 | Content odakta | Listenin başından sona sarar                        |
| `Home` / `PageUp`  | İlk enabled item'i highlight et                    | Content odakta | -                                                   |
| `End` / `PageDown` | Son enabled item'i highlight et                    | Content odakta | -                                                   |
| `Tab`              | Content'i kapat                                    | Content odakta | `event.preventDefault()` çağrılır                   |
| `A-Z` / `a-z`      | Type-ahead ile eşleşen enabled item'i highlight et | Content odakta | Varsayılan timeout `700ms`                          |
