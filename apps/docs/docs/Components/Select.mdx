# Select

A headless, fully accessible dropdown component that allows users to choose a single value from a list of options with complete WAI-ARIA Listbox pattern implementation.

`Select` does not include dedicated trigger-icon or selected-indicator primitives. Add any chevron, caret, or selected marker directly inside `Select.Trigger` and `Select.Item` so the visual layer stays fully application-owned.

Pair it with the [Field](./Field.mdx) primitive to get label, description, and error-message wiring with coordinated ARIA IDs — `Select` reads the enclosing `Field`'s `invalid`, `disabled`, `required`, and `readOnly` state automatically.

The live demo shows the recommended pattern: a `Field` wrapper supplying label, helper text, and error message wiring around the `Select` primitive — with a custom chevron in the trigger and a checkmark inside each item to illustrate how visual indicators are composed manually.

## Features

- ✅ Single-value selection (`value: string`)
- ✅ Controlled and uncontrolled usage (`value/defaultValue`, `open/defaultOpen`)
- ✅ Reads validation, disabled, required, and read-only state from a parent `Field` automatically (direct props still override)
- ✅ Built-in typeahead search (default 700ms buffer)
- ✅ Positioning with `useFloating` (offset, flip, shift, hide)
- ✅ Form integration (generates a hidden input when `name` is provided)
- ✅ Portal-based content rendering (`container` or `document.body`)
- ✅ Grouping lists with groups, labels, and separators
- ✅ Disabling at the Root or Item level
- ✅ Compound structure built around Root/Trigger/Content/Item

## Import

```tsx
import { Field, Select } from '@turkish-technology/spar';

`Select` and `Select.Root` refer to the same component — the difference is only notation style. Label, description, and error message are owned by the [`Field`](./Field.mdx) primitive when you need them:

```

### Structure

```tsx
<Select.Root>
  <Select.Trigger placeholder='Choose...' />

  <Select.Content>
    <Select.Group>
      <Select.Label />
      <Select.Item value='...' textValue='...'>...</Select.Item>
    </Select.Group>

    <Select.Separator />
    <Select.Arrow />
  </Select.Content>
</Select.Root>
```

**Data Flow:**

- `Select.Root` manages open/closed state and the selected value, and provides context.
- `Select.Trigger` toggles the Root state, displays the selected item's `textValue` or the `placeholder`, and sets the focus strategy for Content on arrow-key input.
- `Select.Content` renders into a portal when open and manages highlight state and keyboard navigation.
- `Select.Item` updates the selection and changes the Root value through click or keyboard interaction. The `textValue` prop registers text used for typeahead and for display in the Trigger.
- `Select.Group` + `Select.Label` establish the semantic group structure.
- `Select.Separator` provides a separator role.
- `Select.Arrow` is an optional arrow positioned relative to the Content placement.

**Alternative: Tree-shakeable named imports**

```tsx
import { SelectRoot, SelectTrigger } from '@turkish-technology/spar';

<SelectRoot>
  <SelectTrigger placeholder='Choose...' />
  {/* ... */}
</SelectRoot>;
```

### With Field (label, description, error)

Wrap `Select` with `Field` to attach a label, helper text, and an error message. The trigger's `aria-labelledby` and `aria-describedby` are wired automatically through Field context, and `invalid` / `disabled` / `required` / `readOnly` propagate down to the trigger and the hidden form input.

```tsx {1,4-6,8-19}
function FieldSelect() {
  const [plan, setPlan] = React.useState('');

  return (
    <Field.Root invalid={plan === ''} required>
      <Field.Label>Plan</Field.Label>
      <Select.Root value={plan} onChange={setPlan} name='plan'>
        <Select.Trigger placeholder='Choose a plan' />
        <Select.Content>
          <Select.Item value='basic' textValue='Basic'>
            Basic
          </Select.Item>
          <Select.Item value='premium' textValue='Premium'>
            Premium
          </Select.Item>
        </Select.Content>
      </Select.Root>
      <Field.Description>Choose the tier you want to subscribe to.</Field.Description>
      <Field.ErrorMessage>Plan is required.</Field.ErrorMessage>
    </Field.Root>
  );
}
```

When the enclosing `Field` is `invalid`, the trigger receives `aria-invalid="true"` and its `aria-describedby` points to the rendered `Field.ErrorMessage` instead of `Field.Description`.

### Disabled and Read-only via Field

`disabled` and `readOnly` propagate from Field. A read-only Select can still be opened and inspected, but its value cannot change.

```tsx {1,5-7}
function ReadOnlyField() {
  return (
    <Field.Root readOnly>
      <Field.Label>Region</Field.Label>
      <Select.Root defaultValue='eu-west-1'>
        <Select.Trigger />
        <Select.Content>
          <Select.Item value='eu-west-1' textValue='EU (Ireland)'>
            EU (Ireland)
          </Select.Item>
          <Select.Item value='us-east-1' textValue='US (N. Virginia)'>
            US (N. Virginia)
          </Select.Item>
        </Select.Content>
      </Select.Root>
      <Field.Description>Locked to your billing region.</Field.Description>
    </Field.Root>
  );
}
```

## API Reference

### Select / Select.Root

Provides the root state and context. `Select` and `Select.Root` are the same component - the difference is only import/notation style.

**Props**

| Name             | Type                      | Default     | Description                                                       |
| ---------------- | ------------------------- | ----------- | ----------------------------------------------------------------- |
| `id?`            | `string`                  | `undefined` | Base id for ARIA relationship ids                                 |
| `value?`         | `string`                  | `undefined` | Controlled selected value                                         |
| `defaultValue?`  | `string`                  | `undefined` | Initial uncontrolled value                                        |
| `onChange?` | `(value: string) => void` | `undefined` | Value change callback                                             |
| `open?`          | `boolean`                 | `undefined` | Controlled open/closed state                                      |
| `defaultOpen?`   | `boolean`                 | `false`     | Initial uncontrolled open state                                   |
| `onOpenChange?`  | `(open: boolean) => void` | `undefined` | Open/closed change callback                                       |
| `invalid?`       | `boolean`                 | `false`     | Validation state; inherited from a parent `Field` when present    |
| `disabled?`      | `boolean`                 | `false`     | Disables the entire Select; inherited from `Field` when present   |
| `required?`      | `boolean`                 | `false`     | Marks the field as required; inherited from `Field` when present  |
| `readOnly?`      | `boolean`                 | `false`     | Read-only state; inherited from `Field` when present              |
| `name?`          | `string`                  | `undefined` | Form field name; generates a hidden input when `value` is defined |
| `dir?`           | `'ltr' \| 'rtl'`          | `'ltr'`     | Writing direction                                                 |
| `autoFocus?`     | `boolean`                 | `false`     | Focuses the trigger on mount                                      |
| `as?`            | `React.ElementType`       | `'div'`     | Polymorphic element for Root                                      |
| `children?`      | `React.ReactNode`         | `undefined` | Root content                                                      |

**Events**

| Name            | Parameters        | Description               | When Triggered                                          |
| --------------- | ----------------- | ------------------------- | ------------------------------------------------------- |
| `onChange` | `(value: string)` | Selected value changes    | When an item is selected or controlled state is updated |
| `onOpenChange`  | `(open: boolean)` | Open/closed state changes | On trigger interaction or programmatic open/close calls |

**HTML Attributes**

| Attribute        | Value | Purpose                                                         |
| ---------------- | ----- | --------------------------------------------------------------- |
| `data-invalid`   | `""`  | Added when Root (or the enclosing Field) is in an invalid state |
| `data-disabled`  | `""`  | Added when Root (or the enclosing Field) is disabled            |
| `data-required`  | `""`  | Added when Root (or the enclosing Field) is required            |
| `data-readonly`  | `""`  | Added when Root (or the enclosing Field) is read-only           |
| `data-autofocus` | `""`  | Added when `autoFocus` is true                                  |

### Select.Trigger

Trigger part that opens and closes the root state.

**Props**

| Name               | Type                                                                        | Default                | Description                                           |
| ------------------ | --------------------------------------------------------------------------- | ---------------------- | ----------------------------------------------------- |
| `placeholder?`     | `string`                                                                    | `undefined`            | Text shown when no value is selected                  |
| `children?`        | `React.ReactNode \| ((state: SelectTriggerRenderProps) => React.ReactNode)` | `undefined`            | Normal content or a render-props function             |
| `as?`              | `React.ElementType`                                                         | `'button'`             | Polymorphic element for Trigger                       |
| `disabled?`        | `boolean`                                                                   | Root `disabled` value  | Trigger disabled value; falls back to Root if omitted |
| `autoFocus?`       | `boolean`                                                                   | Root `autoFocus` value | Autofocus at the button level                         |
| `isLoading?`       | `boolean`                                                                   | `false`                | Button loading state (`ButtonOwnProps`)               |
| `isPressed?`       | `boolean`                                                                   | `undefined`            | Button toggle state (`ButtonOwnProps`)                |
| `onPressedChange?` | `(pressed: boolean) => void`                                                | `undefined`            | Button toggle change callback                         |
| `ref?`             | `React.Ref<HTMLElement>`                                                    | `undefined`            | Forwarded ref                                         |
| `...props`         | `ButtonProps`                                                               | -                      | Other HTML/ARIA props inherited from Button           |

| Property    | Type                  | Description                                      |
| ----------- | --------------------- | ------------------------------------------------ |
| `isOpen`    | `boolean`             | Whether the dropdown is currently visible        |
| `value`     | `string \| undefined` | The currently selected value                     |
| `textValue` | `string \| undefined` | The display text of the currently selected item  |
| `disabled`  | `boolean`             | Whether the trigger is disabled                  |
| `open`      | `() => void`          | Function to programmatically open the dropdown   |
| `close`     | `() => void`          | Function to programmatically close the dropdown  |
| `toggle`    | `() => void`          | Function to programmatically toggle the dropdown |

**Events**

| Name        | Parameters                                  | Description                       | When Triggered                                   |
| ----------- | ------------------------------------------- | --------------------------------- | ------------------------------------------------ |
| `onClick`   | `(event: React.MouseEvent<HTMLElement>)`    | Trigger click/activation callback | After mouse click or Button activation           |
| `onKeyDown` | `(event: React.KeyboardEvent<HTMLElement>)` | Trigger keydown callback          | On every keydown event, before internal handling |
| `onFocus`   | `(event: React.FocusEvent<HTMLElement>)`    | Button focus callback             | When the trigger receives focus                  |
| `onBlur`    | `(event: React.FocusEvent<HTMLElement>)`    | Button blur callback              | When the trigger loses focus                     |

| Attribute          | Value                | Purpose                                                                                                 |
| ------------------ | -------------------- | ------------------------------------------------------------------------------------------------------- |
| `role`             | `"combobox"`         | Trigger semantic role                                                                                   |
| `aria-haspopup`    | `"listbox"`          | Type of panel that opens                                                                                |

| `aria-controls`    | `string`             | Id of the content element                                                                               |

| `aria-readonly`    | `true`               | Added when Root (or the enclosing Field) is read-only                                                   |
| `id`               | `string`             | Equals the Field's `fieldId` when wrapped in a `Field`, so `Field.Label` `htmlFor` lands on the trigger |
| `data-state`       | `"open" \| "closed"` | Open/closed state                                                                                       |
| `data-invalid`     | `""`                 | Added when invalid (own prop or inherited from Field)                                                   |
| `data-required`    | `""`                 | Added when required (own prop or inherited from Field)                                                  |
| `data-readonly`    | `""`                 | Added when read-only (own prop or inherited from Field)                                                 |
| `data-placeholder` | `""`                 | Added when there is no selected value                                                                   |
| `data-disabled`    | `""`                 | Button disabled state                                                                                   |
| `data-loading`     | `""`                 | Button loading state                                                                                    |
| `data-pressed`     | `""`                 | Button toggle pressed state                                                                             |

| Attribute         | Value                                    | Purpose                                |

**Positioning Notes**

- `useFloating` middleware: `offset(8)`, `flip()`, `shift({ padding: 8 })`, `hide()`
- `minWidth` is matched to the trigger width

## Keyboard Interactions

Keyboard behavior in the current implementation:

| Key                | Action                                                 | Context         | Notes                                                |
| ------------------ | ------------------------------------------------------ | --------------- | ---------------------------------------------------- |
| `Enter` / `Space`  | Toggle open/close                                      | Trigger focused | Works through the `Button` activation flow           |
| `ArrowDown`        | Open and set focus strategy to the selected/first item | Trigger focused | Only opens when currently closed                     |
| `ArrowUp`          | Open and set focus strategy to the selected/first item | Trigger focused | Only opens when currently closed                     |
| `Escape`           | Close and return focus to Trigger                      | Content focused | Unless `preventDefault` is used in `onEscapeKeyDown` |
| `Enter` / `Space`  | Select the highlighted item, close, and focus Trigger  | Content focused | No selection happens if nothing is highlighted       |
| `ArrowDown`        | Highlight the next enabled item                        | Content focused | Wraps from the end of the list to the start          |
| `ArrowUp`          | Highlight the previous enabled item                    | Content focused | Wraps from the start of the list to the end          |
| `Home` / `PageUp`  | Highlight the first enabled item                       | Content focused | -                                                    |
| `End` / `PageDown` | Highlight the last enabled item                        | Content focused | -                                                    |
| `Tab`              | Close the Content                                      | Content focused | Calls `event.preventDefault()`                       |
| `A-Z` / `a-z`      | Highlight the matching enabled item via typeahead      | Content focused | Default timeout is `700ms`                           |
