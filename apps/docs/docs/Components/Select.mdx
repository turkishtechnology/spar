# Select

A headless, fully accessible dropdown component that allows users to choose a single value from a list of options with complete WAI-ARIA Listbox pattern implementation.

`Select` does not include dedicated trigger-icon or selected-indicator primitives. Add any chevron, caret, or selected marker directly inside `Select.Trigger` and `Select.Item` so the visual layer stays fully application-owned.

## Features

- ✅ Single value selection from dropdown list
- ✅ Controlled and uncontrolled state management
- ✅ Type-ahead search with character navigation
- ✅ Smart positioning with custom useFloating hook
- ✅ Automatic collision detection and flipping
- ✅ Form integration with native HTML support
- ✅ Automatic portal rendering to document.body
- ✅ Grouped items with labels and separators
- ✅ Custom trigger and item visuals via normal React composition
- ✅ Optional visual arrow indicator with automatic positioning
- ✅ Disabled state for items and entire select
- ✅ RTL (right-to-left) language support
- ✅ SSR safe with deterministic IDs

### Structure

```tsx
<Select.Root>
  <Select.Trigger>
    <Select.Value />
  </Select.Trigger>

  <Select.Content>
    <Select.Group>
      <Select.Label />
      <Select.Item>
        <Select.ItemText />
      </Select.Item>
    </Select.Group>

    <Select.Separator />
    <Select.Arrow />
  </Select.Content>
</Select.Root>
```

**Data Flow:**

- `Select.Root` manages state (open/value) and provides context to all child components
- `Select.Trigger` toggles dropdown open/closed state and displays current selection
- `Select.Value` displays the selected item's text or placeholder when nothing is selected
- `Select.Content` portals to `document.body` by default and uses custom `useFloating` hook for intelligent positioning relative to trigger
- `Select.Group` organizes related items and associates them with labels
- `Select.Label` provides semantic grouping labels for screen readers
- `Select.Item` registers with root context and handles selection on click/keyboard
- `Select.ItemText` provides the text value for type-ahead search and display
- `Select.Separator` provides visual separation between groups or items
- `Select.Arrow` points to trigger with automatic positioning (optional)

**Alternative: Tree-shakeable named imports**

```tsx
import { SelectRoot, SelectTrigger, SelectValue } from '@turkish-technology/spar';

<SelectRoot>
  <SelectTrigger>
    <SelectValue />
  </SelectTrigger>
  {/* ... */}
</SelectRoot>;
```

## API Reference

### Select.Root

The main container that manages all select state and behavior.

**Props**

| Name             | Type                      | Default     | Description                           |
| ---------------- | ------------------------- | ----------- | ------------------------------------- |
| `value?`         | `string`                  | `undefined` | Controlled selected value             |
| `defaultValue?`  | `string`                  | `undefined` | Uncontrolled initial value            |
| `onValueChange?` | `(value: string) => void` | `undefined` | Callback when selection changes       |
| `open?`          | `boolean`                 | `undefined` | Controlled open state                 |
| `defaultOpen?`   | `boolean`                 | `false`     | Uncontrolled initial open state       |
| `onOpenChange?`  | `(open: boolean) => void` | `undefined` | Callback when open state changes      |
| `disabled?`      | `boolean`                 | `false`     | Disables the entire select            |
| `required?`      | `boolean`                 | `false`     | Makes the select required for forms   |
| `name?`          | `string`                  | `undefined` | Form field name                       |
| `dir?`           | `'ltr' \| 'rtl'`          | `'ltr'`     | Reading direction                     |
| `autoFocus?`     | `boolean`                 | `false`     | Whether to focus the trigger on mount |
| `as?`            | `React.ElementType`       | `undefined` | Polymorphic component type            |
| `children`       | `React.ReactNode`         | -           | Select component children             |

**Events**

| Name            | Parameters        | Description        | When Triggered                               |
| --------------- | ----------------- | ------------------ | -------------------------------------------- |
| `onValueChange` | `(value: string)` | Selection changes  | User selects an item or programmatic change  |
| `onOpenChange`  | `(open: boolean)` | Open state changes | User toggles dropdown or programmatic change |

**HTML Attributes**

| Attribute        | Value     | Purpose                        |
| ---------------- | --------- | ------------------------------ |
| `data-autofocus` | `boolean` | Marks auto-focus configuration |

### Select.Trigger

The button that toggles the dropdown open and closed. Extends all `Button` component props including polymorphic rendering via the `as` prop. Any trigger chevron or adornment should be rendered as a normal child inside this component.

**Props**

| Name               | Type                                                                        | Default     | Description                                         |
| ------------------ | --------------------------------------------------------------------------- | ----------- | --------------------------------------------------- |
| `as?`              | `React.ElementType`                                                         | `"button"`  | Element type to render as                           |
| `children`         | `React.ReactNode \| ((state: SelectTriggerRenderProps) => React.ReactNode)` | -           | Trigger content or render props function            |
| `disabled?`        | `boolean`                                                                   | `false`     | Whether trigger is disabled                         |
| `autoFocus?`       | `boolean`                                                                   | `false`     | Whether the button should receive focus on mount    |
| `isLoading?`       | `boolean`                                                                   | `false`     | Loading state with screen reader support            |
| `isPressed?`       | `boolean`                                                                   | `undefined` | Toggle state - creates a toggle button when defined |
| `onPressedChange?` | `(pressed: boolean) => void`                                                | `undefined` | Callback fired when toggle state changes            |
| `ref?`             | `React.RefObject`                                                           | `undefined` | Forward ref support                                 |
| `...props`         | `ButtonProps`                                                               | -           | All standard Button component attributes            |

**Render Props (SelectTriggerRenderProps)**

| Property   | Type                  | Description                                      |
| ---------- | --------------------- | ------------------------------------------------ |
| `isOpen`   | `boolean`             | Whether the dropdown is currently visible        |
| `value`    | `string \| undefined` | The currently selected value                     |
| `disabled` | `boolean`             | Whether the trigger is disabled                  |
| `open`     | `() => void`          | Function to programmatically open the dropdown   |
| `close`    | `() => void`          | Function to programmatically close the dropdown  |
| `toggle`   | `() => void`          | Function to programmatically toggle the dropdown |

**Events**

| Name        | Parameters                     | Description            | When Triggered                       |
| ----------- | ------------------------------ | ---------------------- | ------------------------------------ |
| `onClick`   | `(event: React.MouseEvent)`    | Trigger clicked        | Mouse click on trigger               |
| `onKeyDown` | `(event: React.KeyboardEvent)` | Key pressed on trigger | Space, Enter, or Arrow keys          |
| `onFocus`   | `(event: React.FocusEvent)`    | Trigger receives focus | Tab navigation or programmatic focus |
| `onBlur`    | `(event: React.FocusEvent)`    | Trigger loses focus    | Focus moves away                     |

**Data Attributes**

- `data-state`: `"open" | "closed"` - Dropdown open state
- `data-disabled`: Present when `disabled={true}`
- `data-placeholder`: Present when no value selected

### Select.Value

Displays the currently selected value or placeholder text.

**Props**

| Name           | Type                | Default     | Description                            |
| -------------- | ------------------- | ----------- | -------------------------------------- |
| `placeholder?` | `React.ReactNode`   | `undefined` | Text shown when no value selected      |
| `as?`          | `React.ElementType` | `'span'`    | Polymorphic component type             |
| `children?`    | `React.ReactNode`   | `undefined` | Optional children (usually not needed) |

**Events**

No specific events.

### Select.Content

The dropdown container that appears when select is open. Uses Floating UI for intelligent positioning.

**Props**

| Name                    | Type                                     | Default         | Description                     |
| ----------------------- | ---------------------------------------- | --------------- | ------------------------------- |
| `side?`                 | `'top' \| 'right' \| 'bottom' \| 'left'` | `'bottom'`      | Preferred placement side        |
| `align?`                | `'start' \| 'center' \| 'end'`           | `'start'`       | Alignment relative to trigger   |
| `as?`                   | `React.ElementType`                      | `'div'`         | Polymorphic component type      |
| `ref?`                  | `React.RefObject`                        | `undefined`     | Forward ref support             |
| `children`              | `React.ReactNode`                        | -               | Content children                |
| `container?`            | `HTMLElement \| null`                    | `document.body` | Custom portal container element |
| `onEscapeKeyDown?`      | `(event: React.KeyboardEvent)`           | `undefined`     | Escape key handler              |
| `onPointerDownOutside?` | `(event: React.PointerEvent)`            | `undefined`     | Outside click handler           |
| `onCloseAutoFocus?`     | `(event: React.FocusEvent)`              | `undefined`     | Focus handler on close          |

**Events**

| Name                   | Parameters                     | Description            | When Triggered                               |
| ---------------------- | ------------------------------ | ---------------------- | -------------------------------------------- |
| `onEscapeKeyDown`      | `(event: React.KeyboardEvent)` | Escape key pressed     | User presses Escape while dropdown is open   |
| `onPointerDownOutside` | `(event: React.PointerEvent)`  | Click outside content  | User clicks outside the dropdown             |
| `onCloseAutoFocus`     | `(event: React.FocusEvent)`    | Focus returns on close | Dropdown closes and focus restoration occurs |

**Data Attributes**

- `data-state`: `"open" | "closed"` - Dropdown open state
- `data-side`: `"top" | "right" | "bottom" | "left"` - Actual placement side
- `data-align`: `"start" | "center" | "end"` - Actual alignment

**Positioning**

Select.Content uses custom `useFloating` hook for positioning. The component automatically:

- Positions relative to the trigger using `side` and `align`
- Applies internal 8px offset from trigger
- Shifts content to stay within the viewport (always enabled)
- Flips to the opposite side when there's no space (always enabled)
- Updates position automatically on scroll, resize, and layout changes
- Matches trigger width as minimum width

For arrow positioning, render `<Select.Arrow />` inside `<Select.Content>`. The arrow ref is automatically managed through context.

### Select.Item

Individual selectable option within the dropdown. Selected-state visuals should be composed inside the item itself by using regular elements plus `data-state="checked"` or the render props API.

**Props**

| Name         | Type                                                                     | Default     | Description                                         |
| ------------ | ------------------------------------------------------------------------ | ----------- | --------------------------------------------------- |
| `value`      | `string`                                                                 | -           | Option value (required)                             |
| `disabled?`  | `boolean`                                                                | `false`     | Disables the option                                 |
| `textValue?` | `string`                                                                 | `undefined` | Text for type-ahead (auto-detected if not provided) |
| `as?`        | `React.ElementType`                                                      | `'div'`     | Polymorphic component type                          |
| `ref?`       | `React.RefObject`                                                        | `undefined` | Forward ref support                                 |
| `children`   | `React.ReactNode \| ((state: SelectItemRenderProps) => React.ReactNode)` | -           | Item content or render props function               |

**Render Props (SelectItemRenderProps)**

| Property        | Type         | Description                                   |
| --------------- | ------------ | --------------------------------------------- |
| `isSelected`    | `boolean`    | Whether this item is currently selected       |
| `isHighlighted` | `boolean`    | Whether this item is currently highlighted    |
| `disabled`      | `boolean`    | Whether this item is disabled                 |
| `select`        | `() => void` | Function to programmatically select this item |

**Events**

| Name            | Parameters                    | Description             | When Triggered                   |
| --------------- | ----------------------------- | ----------------------- | -------------------------------- |
| `onClick`       | `(event: React.MouseEvent)`   | Item clicked            | Mouse click on item              |
| `onPointerMove` | `(event: React.PointerEvent)` | Pointer moves over item | Mouse/pointer enters item        |
| `onFocus`       | `(event: React.FocusEvent)`   | Item receives focus     | Keyboard navigation focuses item |

**Data Attributes**

### Select.Arrow

Optional decorative arrow element pointing to the trigger. Headless: renders a plain element with no visual opinions and is separate from any custom trigger chevron or selected-item marker you place yourself. Arrow ref is automatically managed via context.

Supports polymorphic rendering via the `as` prop. When rendered as the default `svg`, sensible SVG defaults (`width`, `height`, `viewBox`, and a triangle `polygon`) are applied automatically. When rendered as another element (e.g., `as="div"`), SVG-specific attributes and default children are omitted.

**Props**

| Name         | Type                  | Default     | Description                                                                       |
| ------------ | --------------------- | ----------- | --------------------------------------------------------------------------------- |
| `as?`        | `React.ElementType`   | `'svg'`     | Polymorphic element type to render                                                |
| `ref?`       | `React.Ref<Element>`  | `undefined` | Forward ref support                                                               |
| `children?`  | `React.ReactNode`     | `undefined` | Custom arrow content. When `as="svg"` (default), falls back to a triangle polygon |
| `className?` | `string`              | `undefined` | CSS class names for styling                                                       |
| `style?`     | `React.CSSProperties` | `undefined` | Custom styles for arrow                                                           |

**Events**

No specific events.

**HTML Attributes**

| Attribute        | Value                                                          | Purpose                          |
| ---------------- | -------------------------------------------------------------- | -------------------------------- |
| `aria-hidden`    | `"true"`                                                       | Hidden from assistive technology |
| `data-placement` | `"top" \| "bottom" \| "left" \| "right"` (with optional align) | Indicates arrow placement        |

**Arrow Positioning**

The arrow ref is automatically managed through context. Simply render `<Select.Arrow />` inside `<Select.Content>` and the arrow middleware will handle positioning.

## Keyboard Interactions

Complete keyboard behavior for the Select component following WAI-ARIA Listbox pattern:

| Key           | Action                              | Context                         | Notes                                            |
| ------------- | ----------------------------------- | ------------------------------- | ------------------------------------------------ |
| `Space`       | Open dropdown / Select item         | Trigger focused / Item focused  | Opens to selected or first item                  |
| `Enter`       | Open dropdown / Select item         | Trigger focused / Item focused  | Opens to selected or first item                  |
| `ArrowDown`   | Open dropdown / Navigate down       | Trigger focused / Dropdown open | Opens or moves to next item                      |
| `ArrowUp`     | Open dropdown / Navigate up         | Trigger focused / Dropdown open | Opens or moves to previous item                  |
| `Home`        | Focus first item                    | Dropdown open                   | Moves to first non-disabled item                 |
| `End`         | Focus last item                     | Dropdown open                   | Moves to last non-disabled item                  |
| `PageUp`      | Focus first item                    | Dropdown open                   | Same as Home                                     |
| `PageDown`    | Focus last item                     | Dropdown open                   | Same as End                                      |
| `Escape`      | Close dropdown                      | Dropdown open                   | Returns focus to trigger, no selection           |
| `Tab`         | Close dropdown, move focus          | Dropdown open                   | Moves to next tabbable element                   |
| `Shift + Tab` | Close dropdown, move focus backward | Dropdown open                   | Moves to previous tabbable element               |
| `A-Z` / `a-z` | Type-ahead search                   | Dropdown open                   | Finds and focuses matching item (1000ms timeout) |

**Type-ahead Behavior:**

- Single character search focuses next matching item
- Multiple characters within 1000ms builds search string
- Search wraps around to beginning if no match found
- Timer resets to 1000ms after each character input
- Disabled items are skipped during search
