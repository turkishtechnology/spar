# Tooltip

A popup that displays information related to an element when the element receives keyboard focus or the mouse hovers over it.

## Features

- ✅ Unified pointer events for mouse and touch support with optimized delay timing
- ✅ Smart positioning with automatic collision detection via Floating UI
- ✅ Hoverable content for interactive tooltips (WCAG 1.4.13)
- ✅ Controlled and uncontrolled state management
- ✅ Optional tooltip provider for shared configuration
- ✅ Automatic portal rendering to document.body
- ✅ Optional arrow pointing to trigger element
- ✅ Native touch and mobile device support via Pointer Events API
- ✅ Escape key support to dismiss tooltip
- ✅ Skip delay for quick navigation between tooltips
- ✅ Can act as label or description for accessibility

### Structure

```tsx
<Tooltip.Provider>
  <Tooltip.Root>
    <Tooltip.Trigger>...</Tooltip.Trigger>
    <Tooltip.Content>
      ...
      <Tooltip.Arrow />
    </Tooltip.Content>
  </Tooltip.Root>
</Tooltip.Provider>
```

**Data Flow:**

- `Tooltip.Provider`: Optional provider for sharing configuration across multiple tooltips
- `Tooltip.Root`: Manages tooltip state and provides context to child components
- `Tooltip.Trigger`: Element that shows/hides tooltip on hover or focus
- `Tooltip.Content`: The actual tooltip popup with smart positioning via Floating UI, automatically portaled to `document.body`
- `Tooltip.Arrow`: Optional arrow element pointing to the trigger

## Code Examples

### Basic Tooltip

Simplest tooltip with default configuration:

```tsx {3-13}
export function BasicTooltip() {
  return (
    <Tooltip.Provider>
      <Tooltip.Root>
        <Tooltip.Trigger>
          <button>Hover me</button>
        </Tooltip.Trigger>
        <Tooltip.Content>Helpful information</Tooltip.Content>
      </Tooltip.Root>
    </Tooltip.Provider>
  );
}
```

### Tooltip with Custom Positioning

Control tooltip placement and alignment:

```tsx {6-9}
<Tooltip.Root>
  <Tooltip.Trigger>
    <button>Right aligned tooltip</button>
  </Tooltip.Trigger>
  <Tooltip.Content side='right' align='start' sideOffset={12} alignOffset={4}>
    Appears on the right side
  </Tooltip.Content>
</Tooltip.Root>
```

### Tooltip with Arrow

Add an arrow pointing to the trigger element:

```tsx {8}
<Tooltip.Root>
  <Tooltip.Trigger>
    <button>Tooltip with arrow</button>
  </Tooltip.Trigger>
  <Tooltip.Content>
    Content with arrow
    <Tooltip.Arrow />
  </Tooltip.Content>
</Tooltip.Root>
```

### Controlled Tooltip State

Manage tooltip visibility programmatically:

```tsx {2,5}
function ControlledTooltip() {
  const [open, setOpen] = React.useState(false);

  return (
    <Tooltip.Root isOpen={open} onOpenChange={setOpen}>
      <Tooltip.Trigger>
        <button>Controlled tooltip</button>
      </Tooltip.Trigger>
      <Tooltip.Content>Controlled by external state</Tooltip.Content>
    </Tooltip.Root>
  );
}
```

### Tooltip as Label

Use tooltip to provide primary label instead of description:

```tsx {3,8}
<Tooltip.Root>
  <Tooltip.Trigger>
    <button aria-label='Close'>✕</button>
  </Tooltip.Trigger>
  <Tooltip.Content asLabel={true}>Close dialog</Tooltip.Content>
</Tooltip.Root>
```

### Multiple Tooltips with Shared Provider

Share configuration across multiple tooltips:

```tsx {1}
<Tooltip.Provider delayDuration={500} skipDelayDuration={200}>
  <Tooltip.Root>
    <Tooltip.Trigger>
      <button>First tooltip</button>
    </Tooltip.Trigger>
    <Tooltip.Content>First tooltip content</Tooltip.Content>
  </Tooltip.Root>

  <Tooltip.Root>
    <Tooltip.Trigger>
      <button>Second tooltip</button>
    </Tooltip.Trigger>
    <Tooltip.Content>Second tooltip content</Tooltip.Content>
  </Tooltip.Root>
</Tooltip.Provider>
```

### Tooltip with Custom Delays

Override default delay timing for specific tooltip:

```tsx {1}
<Tooltip.Root delay={300} hideDelay={100}>
  <Tooltip.Trigger>
    <button>Quick tooltip</button>
  </Tooltip.Trigger>
  <Tooltip.Content>Shows quickly with custom timing</Tooltip.Content>
</Tooltip.Root>
```

### Disabled Tooltip

Conditionally disable tooltip:

```tsx {2,5}
function DisabledExample() {
  const [disabled, setDisabled] = React.useState(false);

  return (
    <Tooltip.Root disabled={disabled}>
      <Tooltip.Trigger>
        <button>Toggle disabled: {disabled ? 'Yes' : 'No'}</button>
      </Tooltip.Trigger>
      <Tooltip.Content>This tooltip can be disabled</Tooltip.Content>
    </Tooltip.Root>
  );
}
```

Configure collision detection and boundaries:

  </Tooltip.Trigger>

### Tooltip with Custom Container

Render tooltip in custom portal container:

```tsx {2,12}
function CustomContainerTooltip() {
  const containerRef = React.useRef<HTMLDivElement>(null);

  return (
    <div>
      <div ref={containerRef} />

      <Tooltip.Root>
        <Tooltip.Trigger>
          <button>Custom container</button>
        </Tooltip.Trigger>
        <Tooltip.Content container={containerRef.current || undefined}>
          Rendered in custom container
        </Tooltip.Content>
      </Tooltip.Root>
    </div>
  );
}
```

### Hoverable Tooltip Content

Interactive tooltip that remains visible when hovering over the content (WCAG 1.4.13 compliant):

```tsx {3-4}
function HoverableTooltip() {
  return (
    <Tooltip.Provider disableHoverableContent={false}>
      <Tooltip.Root hideDelay={300}>
        <Tooltip.Trigger>
          <button>Hover to see interactive content</button>
        </Tooltip.Trigger>
        <Tooltip.Content>
          <div>
            <p>You can move your pointer to this content.</p>
            <p>It stays visible while hovering!</p>
          </div>
        </Tooltip.Content>
      </Tooltip.Root>
    </Tooltip.Provider>
  );
}
```

## API Reference

### Tooltip.Provider

Optional provider for sharing configuration across multiple tooltip instances.

**Props**

| Name                       | Type              | Default | Description                                     |
| -------------------------- | ----------------- | ------- | ----------------------------------------------- |
| `children`                 | `React.ReactNode` | -       | Tooltip components to share provider context    |
| `delayDuration?`           | `number`          | `700`   | Global delay duration for all tooltips (ms)     |
| `skipDelayDuration?`       | `number`          | `300`   | Duration to skip delay when moving between (ms) |
| `disableHoverableContent?` | `boolean`         | `false` | Disable hoverable content globally              |

**Events**

| Name | Parameters | Description                      | When Triggered |
| ---- | ---------- | -------------------------------- | -------------- |
| None | -          | Provider manages internal timers | -              |

### Tooltip.Root

Root component that manages tooltip state and provides context to child components.

**Props**

| Name            | Type                      | Default | Description                              |
| --------------- | ------------------------- | ------- | ---------------------------------------- |
| `children`      | `React.ReactNode`         | -       | Tooltip trigger and content components   |
| `open?`         | `boolean`                 | -       | Controlled state for tooltip visibility  |
| `defaultOpen?`  | `boolean`                 | `false` | Default open state for uncontrolled mode |
| `onOpenChange?` | `(open: boolean) => void` | -       | Callback when tooltip open state changes |
| `delay?`        | `number`                  | `700`   | Override provider delay for this tooltip |
| `hideDelay?`    | `number`                  | `0`     | Override provider hide delay             |
| `disabled?`     | `boolean`                 | `false` | Whether tooltip is disabled              |

**Events**

| Name           | Parameters        | Description                | When Triggered              |
| -------------- | ----------------- | -------------------------- | --------------------------- |
| `onOpenChange` | `(open: boolean)` | Tooltip visibility changes | User interaction or control |

### Tooltip.Trigger

The trigger element that shows/hides the tooltip on hover or focus. Extends all `Button` component props including polymorphic rendering via the `as` prop.

**Props**

| Name               | Type                                                                         | Default     | Description                                         |
| ------------------ | ---------------------------------------------------------------------------- | ----------- | --------------------------------------------------- |
| `as?`              | `React.ElementType`                                                          | `"button"`  | Element type to render as                           |
| `children`         | `React.ReactNode \| ((state: TooltipTriggerRenderProps) => React.ReactNode)` | -           | Trigger content or render props function            |
| `disabled?`        | `boolean`                                                                    | `false`     | Disables the trigger                                |
| `autoFocus?`       | `boolean`                                                                    | `false`     | Whether the button should receive focus on mount    |
| `isLoading?`       | `boolean`                                                                    | `false`     | Loading state with screen reader support            |
| `isPressed?`       | `boolean`                                                                    | `undefined` | Toggle state - creates a toggle button when defined |
| `onPressedChange?` | `(pressed: boolean) => void`                                                 | `undefined` | Callback fired when toggle state changes            |
| `...props`         | `ButtonProps`                                                                | -           | All standard Button component attributes            |

**Render Props (TooltipTriggerRenderProps)**

| Property    | Type         | Description                                   |
| ----------- | ------------ | --------------------------------------------- |
| `isOpen`    | `boolean`    | Whether the tooltip is currently visible      |
| `disabled`  | `boolean`    | Whether the trigger is disabled               |
| `placement` | `Placement`  | Current placement of the tooltip              |
| `show`      | `() => void` | Function to programmatically show the tooltip |
| `hide`      | `() => void` | Function to programmatically hide the tooltip |

**Events**

| Name             | Parameters                     | Description            | When Triggered             |
| ---------------- | ------------------------------ | ---------------------- | -------------------------- |
| `onPointerEnter` | `(event: React.PointerEvent)`  | Pointer enters trigger | Mouse hover or touch start |
| `onPointerLeave` | `(event: React.PointerEvent)`  | Pointer leaves trigger | Mouse exit or touch end    |
| `onFocus`        | `(event: React.FocusEvent)`    | Trigger receives focus | Keyboard focus             |
| `onBlur`         | `(event: React.FocusEvent)`    | Trigger loses focus    | Focus removed              |
| `onKeyDown`      | `(event: React.KeyboardEvent)` | Key pressed on trigger | Keyboard interaction       |

**HTML Attributes**

| Attribute        | Value                | Purpose                     |
| ---------------- | -------------------- | --------------------------- |
| `id`             | `string`             | Unique identifier           |
| `data-state`     | `"open" \| "closed"` | Indicates tooltip state     |
| `data-placement` | `Side`               | Indicates tooltip placement |
| `data-disabled`  | `boolean`            | Indicates disabled state    |

### Tooltip.Content

The content that displays in the tooltip popup with smart positioning.

**Props**

| Name                    | Type                                      | Default         | Description                                     |
| ----------------------- | ----------------------------------------- | --------------- | ----------------------------------------------- |
| `children`              | `React.ReactNode`                         | -               | Content to display in tooltip                   |
| `as?`                   | `React.ElementType`                       | `"div"`         | Element type for tooltip content container      |
| `asLabel?`              | `boolean`                                 | `false`         | Whether tooltip is primary label vs description |
| `side?`                 | `"top" \| "bottom" \| "left" \| "right"`  | `"top"`         | Preferred placement relative to trigger         |
| `sideOffset?`           | `number`                                  | `8`             | Distance in pixels from the trigger             |
| `align?`                | `"start" \| "center" \| "end"`            | `"center"`      | Alignment relative to trigger                   |
| `alignOffset?`          | `number`                                  | `0`             | Offset for alignment                            |
| `avoidCollisions?`      | `boolean`                                 | `true`          | Whether to avoid viewport collisions            |
| `collisionBoundary?`    | `Element \| Element[]`                    | -               | Collision boundary elements                     |
| `collisionPadding?`     | `number \| Partial<Record<Side, number>>` | `8`             | Padding for collision detection                 |
| `sticky?`               | `"partial" \| "always"`                   | `"partial"`     | Sticky behavior during scroll                   |
| `hideWhenDetached?`     | `boolean`                                 | `false`         | Hide when trigger becomes detached              |
| `onEscapeKeyDown?`      | `(event: React.KeyboardEvent) => void`    | -               | Escape key handler                              |
| `onPointerDownOutside?` | `(event: React.PointerEvent) => void`     | -               | Outside pointer down handler                    |
| `onOpenAutoFocus?`      | `(event: Event) => void`                  | -               | Called when auto-focusing on open               |
| `onCloseAutoFocus?`     | `(event: Event) => void`                  | -               | Called when auto-focusing on close              |
| `container?`            | `HTMLElement \| null`                     | `document.body` | Custom portal container element                 |

**Events**

| Name                   | Parameters                     | Description                  | When Triggered                  |
| ---------------------- | ------------------------------ | ---------------------------- | ------------------------------- |
| `onEscapeKeyDown`      | `(event: React.KeyboardEvent)` | Escape key pressed           | User presses Escape             |
| `onPointerDownOutside` | `(event: React.PointerEvent)`  | Pointer down outside tooltip | Click/touch outside content     |
| `onPointerEnter`       | `(event: React.PointerEvent)`  | Pointer enters content       | Mouse hover or touch on tooltip |
| `onPointerLeave`       | `(event: React.PointerEvent)`  | Pointer leaves content       | Mouse exit or touch end         |
| `onKeyDown`            | `(event: React.KeyboardEvent)` | Key pressed in content       | Keyboard interaction            |

**HTML Attributes**

| Attribute        | Value                | Purpose                        |
| ---------------- | -------------------- | ------------------------------ |
| `id`             | `string`             | Unique identifier for content  |
| `data-state`     | `"open" \| "closed"` | Indicates visibility state     |
| `data-placement` | `Placement`          | Indicates actual placement     |
| `data-as-label`  | `boolean`            | Indicates label vs description |

### Tooltip.Arrow

Optional decorative arrow pointing to the trigger element. Headless: renders a plain element with no visual opinions — user provides all styling.

**Props**

| Name         | Type                  | Default | Description                       |
| ------------ | --------------------- | ------- | --------------------------------- |
| `as?`        | `React.ElementType`   | `"div"` | Polymorphic element type to render |
| `ref?`       | `React.Ref<Element>`  | -       | Forward ref support               |
| `className?` | `string`              | -       | CSS class names for styling       |
| `style?`     | `React.CSSProperties` | -       | Inline styles                     |

**Events**

| Name | Parameters | Description            | When Triggered |
| ---- | ---------- | ---------------------- | -------------- |
| None | -          | Arrow is purely visual | -              |

**HTML Attributes**

| Attribute        | Value  | Purpose                  |
| ---------------- | ------ | ------------------------ |
| `data-placement` | `Side` | Indicates placement side |

## Keyboard Interactions

Complete keyboard behavior for the tooltip component:

| Key             | Action        | Context         | Notes                                       |
| --------------- | ------------- | --------------- | ------------------------------------------- |
| `Tab`           | Focus trigger | Any context     | Shows tooltip immediately on focus          |
| `Escape`        | Close tooltip | Focused trigger | Closes tooltip and keeps focus on trigger   |
| `Escape`        | Close tooltip | Focused content | Closes tooltip and returns focus to trigger |
| `Pointer hover` | Show tooltip  | Trigger         | Shows tooltip after delay duration          |
| `Pointer leave` | Hide tooltip  | Trigger         | Hides tooltip after hide delay              |

## Accessibility Features

The Tooltip component is designed with accessibility as a priority:

- **WCAG 2.2 AA Compliant**: Follows all relevant success criteria
- **Screen Reader Support**: Proper ARIA attributes for assistive technologies
- **Keyboard Navigation**: Full keyboard support with Escape key handling
- **Focus Management**: Proper focus handling on show/hide
- **Hoverable Content**: Content remains visible when pointer moves to it (WCAG 1.4.13)
- **Unified Input Support**: Pointer Events API provides consistent behavior across mouse, touch, and pen inputs
- **High Contrast**: Works with high contrast modes
- **Reduced Motion**: Respects `prefers-reduced-motion` preference

### Best Practices

1. **Keep Content Brief**: Tooltips should provide concise, helpful information
2. **Use for Supplementary Info**: Don't hide critical information in tooltips
3. **Avoid Interactive Content**: Tooltips are not for complex interactions
4. **Label vs Description**: Use `asLabel={true}` only when tooltip provides the primary label
5. **Cross-Device Compatibility**: Pointer Events API ensures consistent behavior on desktop, mobile, and tablet devices
6. **Timing**: Default delays work well; adjust only if needed for specific UX
7. **Positioning**: Use `side` and `align` props to ensure tooltip doesn't cover important content
