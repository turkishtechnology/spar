# Tooltip

A popup that displays information related to an element when the element receives keyboard focus or the mouse hovers over it.

## Features

- ✅ Controlled and uncontrolled open state (`open`, `defaultOpen`, `onOpenChange`)
- ✅ Per-tooltip delay control (`delay`, `hideDelay`)
- ✅ Shared timing configuration across multiple tooltips via `Tooltip.Provider`
- ✅ Skip-delay behavior between sequential tooltips (`skipDelayDuration`)
- ✅ Portal rendering with optional custom container (`container`)
- ✅ Floating-based positioning with `side` and `align`
- ✅ Optional arrow part (`Tooltip.Arrow`)

### Structure

```tsx
<Tooltip.Provider>
  <Tooltip.Root>
    <Tooltip.Trigger>...</Tooltip.Trigger>
    <Tooltip.Content>
      ...
      <Tooltip.Arrow />
    </Tooltip.Content>
  </Tooltip.Root>
</Tooltip.Provider>
```

**Data Flow:**

- `Tooltip.Provider`: Optional provider for sharing configuration across multiple tooltips
- `Tooltip.Root`: Manages tooltip state and provides context to child components
- `Tooltip.Trigger`: Element that shows/hides tooltip on hover or focus
- `Tooltip.Content`: The actual tooltip popup with smart positioning via Floating UI, automatically portaled to `document.body`
- `Tooltip.Arrow`: Optional arrow element pointing to the trigger

## Code Examples

### Basic Tooltip

Simplest tooltip with default configuration:

```tsx {3-11}
export function BasicTooltip() {
  return (
    <Tooltip.Provider>
      <Tooltip.Root>
        <Tooltip.Trigger>{'Hover me'}</Tooltip.Trigger>
        <Tooltip.Content>Helpful information</Tooltip.Content>
      </Tooltip.Root>
    </Tooltip.Provider>
  );
}
```

### Tooltip with Custom Positioning

Control tooltip placement and alignment:

```tsx {6-9}
<Tooltip.Root>
  <Tooltip.Trigger>{'Right aligned tooltip'}</Tooltip.Trigger>
  <Tooltip.Content side='right' align='start'>
    Appears on the right side
  </Tooltip.Content>
</Tooltip.Root>
```

### Tooltip with Arrow

Add an arrow pointing to the trigger element:

```tsx {8}
<Tooltip.Root>
  <Tooltip.Trigger>{'Tooltip with arrow'}</Tooltip.Trigger>
  <Tooltip.Content>
    Content with arrow
    <Tooltip.Arrow />
  </Tooltip.Content>
</Tooltip.Root>
```

### Controlled Tooltip State

Manage tooltip visibility programmatically:

```tsx {2,5}
function ControlledTooltip() {
  const [open, setOpen] = React.useState(false);

  return (
    <Tooltip.Root open={open} onOpenChange={setOpen}>
      <Tooltip.Trigger>{'Controlled tooltip'}</Tooltip.Trigger>
      <Tooltip.Content>Controlled by external state</Tooltip.Content>
    </Tooltip.Root>
  );
}
```

### Multiple Tooltips with Shared Provider

Share configuration across multiple tooltips:

```tsx {1}
<Tooltip.Provider delayDuration={500} skipDelayDuration={200}>
  <Tooltip.Root>
    <Tooltip.Trigger>{'First tooltip'}</Tooltip.Trigger>
    <Tooltip.Content>First tooltip content</Tooltip.Content>
  </Tooltip.Root>

  <Tooltip.Root>
    <Tooltip.Trigger>{'Second tooltip'}</Tooltip.Trigger>
    <Tooltip.Content>Second tooltip content</Tooltip.Content>
  </Tooltip.Root>
</Tooltip.Provider>
```

### Tooltip with Custom Delays

Override default delay timing for specific tooltip:

```tsx {1}
<Tooltip.Root delay={300} hideDelay={100}>
  <Tooltip.Trigger>{'Quick tooltip'}</Tooltip.Trigger>
  <Tooltip.Content>Shows quickly with custom timing</Tooltip.Content>
</Tooltip.Root>
```

### Disabled Tooltip

Conditionally disable tooltip:

```tsx {2,5}
function DisabledExample() {
  const [disabled, setDisabled] = React.useState(false);

  return (
    <Tooltip.Root disabled={disabled}>
      <Tooltip.Trigger>{`Toggle disabled: ${disabled ? 'Yes' : 'No'}`}</Tooltip.Trigger>
      <Tooltip.Content>This tooltip can be disabled</Tooltip.Content>
    </Tooltip.Root>
  );
}
```

### Tooltip with Custom Container

Render tooltip in custom portal container:

```tsx {2,12}
function CustomContainerTooltip() {
  const containerRef = React.useRef<HTMLDivElement>(null);

  return (
    <div>
      <div ref={containerRef} />

      <Tooltip.Root>
        <Tooltip.Trigger>{'Custom container'}</Tooltip.Trigger>
        <Tooltip.Content container={containerRef.current || undefined}>
          Rendered in custom container
        </Tooltip.Content>
      </Tooltip.Root>
    </div>
  );
}
```

### Hoverable Tooltip Content

Interactive tooltip that remains visible when hovering over the content (WCAG 1.4.13 compliant):

```tsx {3-4}
function HoverableTooltip() {
  return (
    <Tooltip.Provider disableHoverableContent={false}>
      <Tooltip.Root hideDelay={300}>
        <Tooltip.Trigger>{'Hover to see interactive content'}</Tooltip.Trigger>
        <Tooltip.Content>
          <div>
            <p>You can move your pointer to this content.</p>
            <p>It stays visible while hovering!</p>
          </div>
        </Tooltip.Content>
      </Tooltip.Root>
    </Tooltip.Provider>
  );
}
```

## API Reference

### Tooltip.Provider

Optional provider for sharing configuration across multiple tooltip instances.

**Props**

| Name                       | Type              | Default | Description                                     |
| -------------------------- | ----------------- | ------- | ----------------------------------------------- |
| `children?`                | `React.ReactNode` | `undefined` | Tooltip components to share provider context |
| `delayDuration?`           | `number`          | `700`   | Global delay duration for all tooltips (ms)     |
| `skipDelayDuration?`       | `number`          | `300`   | Duration to skip delay when moving between (ms) |
| `disableHoverableContent?` | `boolean`         | `false` | Disable hoverable content globally              |

**Events**

| Name | Parameters | Description                      | When Triggered |
| ---- | ---------- | -------------------------------- | -------------- |
| None | -          | Provider manages internal timers | -              |

**HTML Attributes**

| Attribute | Value | Purpose |
| --------- | ----- | ------- |
| None      | -     | Provider does not render a DOM element |

### Tooltip.Root

Root component that manages tooltip state and provides context to child components.

**Props**

| Name            | Type                      | Default     | Description                                                      |
| --------------- | ------------------------- | ----------- | ---------------------------------------------------------------- |
| `id?`           | `string`                  | `useId()`   | Base id used to derive trigger/content ids (`${id}-trigger`, `${id}-content`) |
| `children?`     | `React.ReactNode`         | `undefined` | Tooltip trigger/content tree                                     |
| `open?`         | `boolean`                 | `undefined` | Controlled open state                                            |
| `defaultOpen?`  | `boolean`                 | `false`     | Initial state in uncontrolled mode                               |
| `onOpenChange?` | `(open: boolean) => void` | `undefined` | Called when open state changes                                   |
| `delay?`        | `number`                  | `700`*      | Show delay for this tooltip (`*` uses provider `delayDuration` when present) |
| `hideDelay?`    | `number`                  | `0`         | Hide delay for this tooltip                                      |
| `disabled?`     | `boolean`                 | `false`     | Disables open/close state updates                                |

**Events**

| Name           | Parameters        | Description                | When Triggered              |
| -------------- | ----------------- | -------------------------- | --------------------------- |
| `onOpenChange` | `(open: boolean)` | Tooltip visibility changes | User interaction or control |

**HTML Attributes**

| Attribute | Value | Purpose |
| --------- | ----- | ------- |
| None      | -     | Root does not render a DOM element |

### Tooltip.Trigger

The trigger element that shows/hides the tooltip on hover or focus. Extends all `Button` component props including polymorphic rendering via the `as` prop.

**Props**

| Name       | Type                                                                          | Default       | Description                                                                 |
| ---------- | ----------------------------------------------------------------------------- | ------------- | --------------------------------------------------------------------------- |
| `as?`      | `React.ElementType`                                                           | `"button"`    | Polymorphic trigger element                                                 |
| `children?`| `React.ReactNode \| ((state: TooltipTriggerRenderProps) => React.ReactNode)` | `undefined`   | Static children or render-props function                                   |
| `...props` | `TooltipTriggerOwnProps & React.ComponentPropsWithoutRef<T>`                 | `undefined`   | Inherited `ButtonOwnProps` and native element props                         |

**Render Props (TooltipTriggerRenderProps)**

| Property   | Type         | Description                                   |
| ---------- | ------------ | --------------------------------------------- |
| `isOpen`   | `boolean`    | Whether the tooltip is currently visible      |
| `disabled` | `boolean`    | Whether the tooltip is disabled               |
| `show`     | `() => void` | Opens immediately                             |
| `hide`     | `() => void` | Closes immediately                            |

**Events**

| Name             | Parameters                     | Description            | When Triggered             |
| ---------------- | ------------------------------ | ---------------------- | -------------------------- |
| `onPointerEnter` | `(event: React.PointerEvent)`  | Pointer enters trigger | Mouse hover or touch start |
| `onPointerLeave` | `(event: React.PointerEvent)`  | Pointer leaves trigger | Mouse exit or touch end    |
| `onFocus`        | `(event: React.FocusEvent)`    | Trigger receives focus | Keyboard focus             |
| `onBlur`         | `(event: React.FocusEvent)`    | Trigger loses focus    | Focus removed              |
| `onKeyDown`      | `(event: React.KeyboardEvent)` | Key pressed on trigger | Keyboard interaction       |

**HTML Attributes**

| Attribute       | Value                | Purpose                  |
| --------------- | -------------------- | ------------------------ |
| `id`            | `string`             | Unique identifier        |
| `disabled`      | `boolean`            | Disabled state from `Tooltip.Root` |
| `aria-describedby` | `string \| undefined` | Set to content id when open and enabled |
| `data-state`    | `"open" \| "closed"` | Current tooltip state    |

### Tooltip.Content

The content that displays in the tooltip popup with smart positioning.

**Props**

| Name                    | Type                                     | Default         | Description                                                                 |
| ----------------------- | ---------------------------------------- | --------------- | --------------------------------------------------------------------------- |
| `as?`                   | `React.ElementType`                      | `"div"`         | Polymorphic content element                                                 |
| `side?`                 | `"top" \| "bottom" \| "left" \| "right"` | `"top"`         | Preferred side                                                              |
| `align?`                | `"start" \| "center" \| "end"`           | `"center"`      | Preferred alignment                                                         |
| `container?`            | `HTMLElement \| null`                    | `document.body` | Portal container (`null` also falls back to `document.body`)               |
| `onEscapeKeyDown?`      | `(event: KeyboardEvent) => void`         | `undefined`     | Called on `Escape` before internal close                                   |
| `onPointerDownOutside?` | `(event: PointerEvent) => void`          | `undefined`     | Type-level prop; current implementation does not bind dedicated outside handler |
| `onOpenAutoFocus?`      | `(event: Event) => void`                 | `undefined`     | Type-level prop; current implementation does not run open auto-focus logic |
| `onCloseAutoFocus?`     | `(event: Event) => void`                 | `undefined`     | Type-level prop; current implementation does not run close auto-focus logic |
| `...props`              | `React.ComponentPropsWithoutRef<T>`      | `undefined`     | Native props forwarded to rendered content element                          |

**Events**

| Name              | Parameters                     | Description            | When Triggered                  |
| ----------------- | ------------------------------ | ---------------------- | ------------------------------- |
| `onEscapeKeyDown` | `(event: KeyboardEvent)`       | Escape key pressed     | User presses Escape in content  |
| `onKeyDown`       | `(event: React.KeyboardEvent)` | Key pressed in content | Keyboard interaction            |
| `onMouseEnter`    | `(event: React.MouseEvent)`    | Pointer enters content | Keeps content open when hoverable content is enabled |
| `onMouseLeave`    | `(event: React.MouseEvent)`    | Pointer leaves content | Closes content when hoverable content is enabled |

**HTML Attributes**

| Attribute        | Value                                       | Purpose                          |
| ---------------- | ------------------------------------------- | -------------------------------- |
| `id`             | `string`                                    | Unique identifier                |
| `role`           | `"tooltip"`                                 | Tooltip semantic role            |
| `data-state`     | `"open" \| "closed"`                        | Visibility state                 |
| `data-placement` | `"top" \| "bottom" \| "left" \| "right"` + optional `-start/-center/-end` | Computed placement from floating logic |

### Tooltip.Arrow

Optional decorative arrow pointing to the trigger element. Headless: renders a plain element with no visual opinions — user provides all styling.

Supports polymorphic rendering via the `as` prop. When rendered as the default `svg`, sensible SVG defaults (`width`, `height`, `viewBox`, and a triangle `polygon`) are applied automatically. When rendered as another element (e.g., `as="div"`), SVG-specific attributes and default children are omitted.

**Props**

| Name       | Type                             | Default     | Description                                                                       |
| ---------- | -------------------------------- | ----------- | --------------------------------------------------------------------------------- |
| `as?`      | `React.ElementType`              | `"svg"`     | Polymorphic element type                                                          |
| `children?`| `React.ReactNode`                | `undefined` | Custom arrow content; default SVG polygon when omitted                            |
| `...props` | `React.ComponentPropsWithoutRef<T>` | `undefined` | Native props for rendered element                                                 |

**Events**

| Name | Parameters | Description            | When Triggered |
| ---- | ---------- | ---------------------- | -------------- |
| None | -          | Arrow is purely visual | -              |

**HTML Attributes**

| Attribute        | Value                                                          | Purpose                          |
| ---------------- | -------------------------------------------------------------- | -------------------------------- |
| `aria-hidden`    | `"true"`                                                       | Hidden from assistive technology |
| `data-placement` | `"top" \| "bottom" \| "left" \| "right"` + optional `-start/-center/-end` | Placement metadata               |
| `width`          | `10` (only when `as="svg"`)                                   | Default SVG size                 |
| `height`         | `5` (only when `as="svg"`)                                    | Default SVG size                 |
| `viewBox`        | `"0 0 10 5"` (only when `as="svg"`)                           | Default SVG viewport             |

## Keyboard Interactions

Implemented keyboard behavior:

| Key             | Action        | Context         | Notes                                       |
| --------------- | ------------- | --------------- | ------------------------------------------- |
| `Tab`           | Focus trigger | Any context     | Shows tooltip immediately on focus          |
| `Escape`        | Close tooltip | Focused trigger | Closes tooltip and keeps focus on trigger   |
| `Escape`        | Close tooltip | Focused content | Closes tooltip and returns focus to trigger |
