# Tooltip

A popup that displays information related to an element when the element receives keyboard focus or the mouse hovers over it.

![Accessibility Badge](https://img.shields.io/badge/Accessibility-WCAG%202.2%20AA-green) ![Tree-shakeable Badge](https://img.shields.io/badge/Tree--shakeable-Yes-blue) ![TypeScript Badge](https://img.shields.io/badge/TypeScript-Strict-blue)

## Features

- ✅ Keyboard and mouse support with optimized delay timing
- ✅ Smart positioning with automatic collision detection via Floating UI
- ✅ Hoverable content for interactive tooltips (WCAG 1.4.13)
- ✅ Controlled and uncontrolled state management
- ✅ Optional tooltip provider for shared configuration
- ✅ Portal rendering to avoid z-index issues
- ✅ Optional arrow pointing to trigger element
- ✅ Touch device detection with appropriate behavior
- ✅ Escape key support to dismiss tooltip
- ✅ Skip delay for quick navigation between tooltips
- ✅ Can act as label or description for accessibility

### Structure

```tsx
<TooltipProvider>
  <TooltipRoot>
    <TooltipTrigger>...</TooltipTrigger>
    <TooltipPortal>
      <TooltipContent>
        ...
        <TooltipArrow />
      </TooltipContent>
    </TooltipPortal>
  </TooltipRoot>
</TooltipProvider>
```

**Data Flow:**
- `TooltipProvider`: Optional provider for sharing configuration across multiple tooltips
- `TooltipRoot`: Manages tooltip state and provides context to child components
- `TooltipTrigger`: Element that shows/hides tooltip on hover or focus
- `TooltipPortal`: Renders tooltip content outside normal DOM tree to avoid z-index issues
- `TooltipContent`: The actual tooltip popup with smart positioning via Floating UI
- `TooltipArrow`: Optional arrow element pointing to the trigger

## Code Examples

### Basic Tooltip

Simplest tooltip with default configuration:

```tsx
export function BasicTooltip() {
  return (
    <TooltipProvider>
      <TooltipRoot>
        <TooltipTrigger>
          <button>Hover me</button>
        </TooltipTrigger>
        <TooltipPortal>
          <TooltipContent>
            Helpful information
          </TooltipContent>
        </TooltipPortal>
      </TooltipRoot>
    </TooltipProvider>
  );
}
```

### Tooltip with Custom Positioning

Control tooltip placement and alignment:

```tsx
<TooltipRoot>
  <TooltipTrigger>
    <button>Right aligned tooltip</button>
  </TooltipTrigger>
  <TooltipPortal>
    <TooltipContent
      side="right"
      align="start"
      sideOffset={12}
      alignOffset={4}
    >
      Appears on the right side
    </TooltipContent>
  </TooltipPortal>
</TooltipRoot>
```

### Tooltip with Arrow

Add an arrow pointing to the trigger element:

```tsx
<TooltipRoot>
  <TooltipTrigger>
    <button>Tooltip with arrow</button>
  </TooltipTrigger>
  <TooltipPortal>
    <TooltipContent>
      Content with arrow
      <TooltipArrow width={12} height={6} />
    </TooltipContent>
  </TooltipPortal>
</TooltipRoot>
```

### Controlled Tooltip State

Manage tooltip visibility programmatically:

```tsx
function ControlledTooltip() {
  const [open, setOpen] = React.useState(false);

  return (
    <TooltipRoot isOpen={open} onOpenChange={setOpen}>
      <TooltipTrigger>
        <button>Controlled tooltip</button>
      </TooltipTrigger>
      <TooltipPortal>
        <TooltipContent>
          Controlled by external state
        </TooltipContent>
      </TooltipPortal>
    </TooltipRoot>
  );
}
```

### Tooltip as Label

Use tooltip to provide primary label instead of description:

```tsx
<TooltipRoot>
  <TooltipTrigger>
    <button aria-label="Close">
      ✕
    </button>
  </TooltipTrigger>
  <TooltipPortal>
    <TooltipContent asLabel={true}>
      Close dialog
    </TooltipContent>
  </TooltipPortal>
</TooltipRoot>
```

### Multiple Tooltips with Shared Provider

Share configuration across multiple tooltips:

```tsx
<TooltipProvider delayDuration={500} skipDelayDuration={200}>
  <TooltipRoot>
    <TooltipTrigger>
      <button>First tooltip</button>
    </TooltipTrigger>
    <TooltipPortal>
      <TooltipContent>First tooltip content</TooltipContent>
    </TooltipPortal>
  </TooltipRoot>

  <TooltipRoot>
    <TooltipTrigger>
      <button>Second tooltip</button>
    </TooltipTrigger>
    <TooltipPortal>
      <TooltipContent>Second tooltip content</TooltipContent>
    </TooltipPortal>
  </TooltipRoot>
</TooltipProvider>
```

### Tooltip with Custom Delays

Override default delay timing for specific tooltip:

```tsx
  </TooltipTrigger>

```

### Disabled Tooltip

Conditionally disable tooltip:

```tsx
function DisabledExample() {
  const [disabled, setDisabled] = React.useState(false);

  return (
    <TooltipRoot isDisabled={disabled}>
      <TooltipTrigger>
        <button>Toggle disabled: {disabled ? 'Yes' : 'No'}</button>
      </TooltipTrigger>
      <TooltipPortal>
        <TooltipContent>
          This tooltip can be disabled
        </TooltipContent>
      </TooltipPortal>
    </TooltipRoot>
  );

```

### Tooltip with Collision Handling

Configure collision detection and boundaries:

```tsx
<TooltipRoot>
  <TooltipTrigger>
    <button>Smart positioning</button>
  </TooltipTrigger>
  <TooltipPortal>
    <TooltipContent
```

### Tooltip with Custom Container

Render tooltip in custom portal container:

```tsx
function CustomContainerTooltip() {
  const containerRef = React.useRef<HTMLDivElement>(null);

  return (
    <div>
      <div ref={containerRef} style={{ position: 'relative' }} />
      
      <TooltipRoot>
        <TooltipTrigger>
          <button>Custom container</button>
        </TooltipTrigger>
        <TooltipPortal container={containerRef.current || undefined}>
          <TooltipContent>
            Rendered in custom container
          </TooltipContent>
        </TooltipPortal>
      </TooltipRoot>
    </div>
  );
}
```

## API Reference

### TooltipProvider

Optional provider for sharing configuration across multiple tooltip instances.

**Props**

| Name                       | Type              | Default | Description                                        |
| -------------------------- | ----------------- | ------- | -------------------------------------------------- |
| `children`                 | `React.ReactNode` | -       | Tooltip components to share provider context       |
| `delayDuration?`           | `number`          | `700`   | Global delay duration for all tooltips (ms)        |
| `skipDelayDuration?`       | `number`          | `300`   | Duration to skip delay when moving between (ms)    |
| `disableHoverableContent?` | `boolean`         | `false` | Disable hoverable content globally                 |

**Events**

| Name | Parameters | Description                      | When Triggered |
| ---- | ---------- | -------------------------------- | -------------- |
| None | -          | Provider manages internal timers | -              |

**ARIA Attributes**

| Attribute            | Value     | Purpose                       | Applied To            |
| -------------------- | --------- | ----------------------------- | --------------------- |
| `data-tooltip-provider` | `""`    | Identifies provider wrapper   | Provider container    |
| `data-skip-delay`    | `boolean` | Indicates skip delay mode     | Provider container    |

### TooltipRoot

Root component that manages tooltip state and provides context to child components.

**Props**

| Name              | Type                      | Default | Description                                |
| ----------------- | ------------------------- | ------- | ------------------------------------------ |
| `children`        | `React.ReactNode`         | -       | Tooltip trigger and content components     |
| `isOpen?`         | `boolean`                 | -       | Controlled state for tooltip visibility    |
| `defaultOpen?`    | `boolean`                 | `false` | Default open state for uncontrolled mode   |
| `onOpenChange?`   | `(open: boolean) => void` | -       | Callback when tooltip open state changes   |
| `delay?`          | `number`                  | `700`   | Override provider delay for this tooltip   |
| `hideDelay?`      | `number`                  | `0`     | Override provider hide delay               |
| `isDisabled?`     | `boolean`                 | `false` | Whether tooltip is disabled                |

**Events**

| Name           | Parameters         | Description                 | When Triggered              |
| -------------- | ------------------ | --------------------------- | --------------------------- |
| `onOpenChange` | `(open: boolean)`  | Tooltip visibility changes  | User interaction or control |

**ARIA Attributes**

| Attribute | Value | Purpose                       | Applied To    |
| --------- | ----- | ----------------------------- | ------------- |
| None      | -     | Root manages context only     | Context only  |

### TooltipTrigger

The trigger element that shows/hides the tooltip on hover or focus.

**Props**

| Name       | Type                  | Default    | Description                                      |
| ---------- | --------------------- | ---------- | ------------------------------------------------ |
| `children` | `React.ReactElement`  | -          | The trigger element (must be single element)     |
| `asChild?` | `boolean`             | `false`    | Compose with child element instead of button     |
| `as?`      | `React.ElementType`   | `"button"` | Element type when not using asChild              |

**Events**

| Name           | Parameters                     | Description                 | When Triggered             |
| -------------- | ------------------------------ | --------------------------- | -------------------------- |
| `onMouseEnter` | -                              | Mouse enters trigger        | Mouse hover                |
| `onMouseLeave` | -                              | Mouse leaves trigger        | Mouse exit                 |
| `onFocus`      | -                              | Trigger receives focus      | Keyboard focus             |
| `onBlur`       | -                              | Trigger loses focus         | Focus removed              |
| `onKeyDown`    | `(event: React.KeyboardEvent)` | Key pressed on trigger      | Keyboard interaction       |

**ARIA Attributes**

| Attribute          | Value                | Purpose                           | Applied To       |
| ------------------ | -------------------- | --------------------------------- | ---------------- |
| `id`               | `string`             | Unique identifier for trigger     | Trigger element  |
| `aria-describedby` | `string`             | References tooltip content ID     | When not label   |
| `aria-labelledby`  | `string`             | References tooltip as label       | When asLabel     |
| `data-state`       | `"open" \| "closed"` | Indicates tooltip state           | Trigger element  |
| `data-placement`   | `Side`               | Indicates tooltip placement       | Trigger element  |
| `data-disabled`    | `boolean`            | Indicates disabled state          | Trigger element  |

### TooltipPortal

Portal component for rendering tooltip outside normal DOM tree.

**Props**

| Name          | Type              | Default         | Description                                |
| ------------- | ----------------- | --------------- | ------------------------------------------ |
| `children`    | `React.ReactNode` | -               | Content to render in portal                |
| `container?`  | `HTMLElement`     | `document.body` | Portal container element                   |
| `forceMount?` | `boolean`         | `false`         | Force mount regardless of open state       |

**Events**

| Name | Parameters | Description                    | When Triggered |
| ---- | ---------- | ------------------------------ | -------------- |
| None | -          | Portal manages rendering only  | -              |

**ARIA Attributes**

| Attribute | Value | Purpose                       | Applied To    |
| --------- | ----- | ----------------------------- | ------------- |
| None      | -     | Portal is transparent wrapper | Container     |

### TooltipContent

The content that displays in the tooltip popup with smart positioning.

**Props**

| Name                     | Type                                           | Default    | Description                                         |
| ------------------------ | ---------------------------------------------- | ---------- | --------------------------------------------------- |
| `children`               | `React.ReactNode`                              | -          | Content to display in tooltip                       |
| `as?`                    | `React.ElementType`                            | `"div"`    | Element type for tooltip content container          |
| `asLabel?`               | `boolean`                                      | `false`    | Whether tooltip is primary label vs description     |
| `side?`                  | `"top" \| "bottom" \| "left" \| "right"`       | `"top"`    | Preferred placement relative to trigger             |
| `sideOffset?`            | `number`                                       | `8`        | Distance in pixels from the trigger                 |
| `align?`                 | `"start" \| "center" \| "end"`                 | `"center"` | Alignment relative to trigger                       |
| `alignOffset?`           | `number`                                       | `0`        | Offset for alignment                                |
| `avoidCollisions?`       | `boolean`                                      | `true`     | Whether to avoid viewport collisions                |
| `collisionBoundary?`     | `Element \| Element[]`                         | -          | Collision boundary elements                         |
| `collisionPadding?`      | `number \| Partial<Record<Side, number>>`      | `10`       | Padding for collision detection                     |
| `sticky?`                | `"partial" \| "always"`                        | `"partial"`| Sticky behavior during scroll                       |
| `hideWhenDetached?`      | `boolean`                                      | `false`    | Hide when trigger becomes detached                  |
| `onEscapeKeyDown?`       | `(event: KeyboardEvent) => void`               | -          | Escape key handler                                  |
| `onPointerDownOutside?`  | `(event: PointerEvent) => void`                | -          | Outside pointer down handler                        |
| `onOpenAutoFocus?`       | `(event: Event) => void`                       | -          | Called when auto-focusing on open                   |
| `onCloseAutoFocus?`      | `(event: Event) => void`                       | -          | Called when auto-focusing on close                  |

**Events**

| Name                    | Parameters             | Description                     | When Triggered              |
| ----------------------- | ---------------------- | ------------------------------- | --------------------------- |
| `onEscapeKeyDown`       | `(event: KeyboardEvent)` | Escape key pressed            | User presses Escape         |
| `onPointerDownOutside`  | `(event: PointerEvent)`  | Click outside tooltip         | Click outside content       |
| `onMouseEnter`          | -                      | Mouse enters content            | Mouse hover on tooltip      |
| `onMouseLeave`          | -                      | Mouse leaves content            | Mouse exits tooltip         |
| `onKeyDown`             | `(event: React.KeyboardEvent)` | Key pressed in content  | Keyboard interaction        |

**ARIA Attributes**

| Attribute        | Value      | Purpose                           | Applied To       |
| ---------------- | ---------- | --------------------------------- | ---------------- |
| `id`             | `string`   | Unique identifier for content     | Content element  |
| `role`           | `"tooltip"`| Identifies as tooltip             | Content element  |
| `data-state`     | `"open" \| "closed"` | Indicates visibility state | Content element  |
| `data-placement` | `Placement`| Indicates actual placement        | Content element  |
| `data-as-label`  | `boolean`  | Indicates label vs description    | Content element  |

### TooltipArrow

Optional arrow pointing to the trigger element.

**Props**

| Name        | Type                  | Default | Description                       |
| ----------- | --------------------- | ------- | --------------------------------- |

**Events**

| Name | Parameters | Description               | When Triggered |
| ---- | ---------- | ------------------------- | -------------- |

**ARIA Attributes**

| Attribute        | Value | Purpose                   | Applied To    |
| ---------------- | ----- | ------------------------- | ------------- |

## Keyboard Interactions

Complete keyboard behavior for the tooltip component:

| Key           | Action                | Context          | Notes                                              |
| ------------- | --------------------- | ---------------- | -------------------------------------------------- |
| `Tab`         | Focus trigger         | Any context      | Shows tooltip immediately on focus                 |
| `Escape`      | Close tooltip         | Focused trigger  | Closes tooltip and keeps focus on trigger          |
| `Escape`      | Close tooltip         | Focused content  | Closes tooltip and returns focus to trigger        |
| `Mouse hover` | Show tooltip          | Trigger          | Shows tooltip after delay duration                 |
| `Mouse leave` | Hide tooltip          | Trigger          | Hides tooltip after hide delay                     |

## Accessibility Features

The Tooltip component is designed with accessibility as a priority:

- **WCAG 2.2 AA Compliant**: Follows all relevant success criteria
- **Screen Reader Support**: Proper ARIA attributes for assistive technologies
- **Keyboard Navigation**: Full keyboard support with Escape key handling
- **Focus Management**: Proper focus handling on show/hide
- **Hoverable Content**: Content remains visible when mouse moves to it (WCAG 1.4.13)
- **Touch Support**: Appropriate behavior on touch devices
- **High Contrast**: Works with high contrast modes
- **Reduced Motion**: Respects `prefers-reduced-motion` preference

### Best Practices

1. **Keep Content Brief**: Tooltips should provide concise, helpful information
2. **Use for Supplementary Info**: Don't hide critical information in tooltips
3. **Avoid Interactive Content**: Tooltips are not for complex interactions
4. **Label vs Description**: Use `asLabel={true}` only when tooltip provides the primary label
5. **Touch Considerations**: Consider alternative patterns for touch-only devices
6. **Timing**: Default delays work well; adjust only if needed for specific UX
7. **Positioning**: Use `side` and `align` props to ensure tooltip doesn't cover important content
