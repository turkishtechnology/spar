## Features

- ✅ Single or multiple panel expansion modes
- ✅ Controlled and uncontrolled state management
- ✅ Optional collapsible behavior for single mode
- ✅ Disabled state support for individual items or entire accordion
- ✅ Semantic heading structure with configurable heading levels
- ✅ Horizontal and vertical orientation support
- ✅ Polymorphic component support with `as` prop
- ✅ Force mount option for content preservation

### Structure

```tsx
<Accordion.Root>
  <Accordion.Item value='item-1'>
    <Accordion.Header>
      <Accordion.Trigger>...</Accordion.Trigger>
    </Accordion.Header>
    <Accordion.Content>...</Accordion.Content>
  </Accordion.Item>
</Accordion.Root>
```

**Data Flow:**

- `Accordion`: Root context provider that manages state
- `Accordion.Item`: Represents a single collapsible section
- `Accordion.Header`: Semantic heading wrapper for proper document structure
- `Accordion.Trigger`: Button to toggle the item
- `Accordion.Content`: Panel revealed when open

## Code Examples

### Basic Single Panel Accordion

Basic accordion that allows only one panel to be expanded at a time:

```tsx
export function BasicAccordion() {
  return (
    <Accordion.Root>
      <Accordion.Item value='a'>
        <Accordion.Header>
          <Accordion.Trigger>Toggle A</Accordion.Trigger>
        </Accordion.Header>
        <Accordion.Content>Panel A</Accordion.Content>
      </Accordion.Item>
      <Accordion.Item value='b'>
        <Accordion.Header>
          <Accordion.Trigger>Toggle B</Accordion.Trigger>
        </Accordion.Header>
        <Accordion.Content>Panel B</Accordion.Content>
      </Accordion.Item>
    </Accordion.Root>
  );
}
```

### Multiple Panel Expansion

Accordion that allows multiple panels to be expanded simultaneously:

```tsx {1}
<Accordion.Root selectionMode='multiple' defaultValue={['a']}>
  <Accordion.Item value='a'>
    <Accordion.Header>
      <Accordion.Trigger>Section A</Accordion.Trigger>
    </Accordion.Header>
    <Accordion.Content>...</Accordion.Content>
  </Accordion.Item>
  <Accordion.Item value='b'>
    <Accordion.Header>
      <Accordion.Trigger>Section B</Accordion.Trigger>
    </Accordion.Header>
    <Accordion.Content>...</Accordion.Content>
  </Accordion.Item>
</Accordion.Root>
```

### Controlled State Management

Accordion with external state control and change handling:

```tsx {1,3}
const [openItems, setOpenItems] = React.useState<string[]>(['a']);

<Accordion.Root selectionMode='multiple' value={openItems} onValueChange={setOpenItems}>
  {/* ...items */}
</Accordion.Root>;
```

## API Reference

### Accordion / Accordion.Root

The root container that provides context and manages the state for all accordion items within it. `Accordion` and `Accordion.Root` are the same component - the difference is only import/notation style.

**Props**

| Name             | Type                                  | Default      | Description                                                     |
| ---------------- | ------------------------------------- | ------------ | --------------------------------------------------------------- |
| `selectionMode?` | `"single" \| "multiple"`              | `"single"`   | Whether single or multiple panels can be expanded               |
| `isCollapsible?` | `boolean`                             | `false`      | Whether panels can be collapsed (only for `single` mode)        |
| `value?`         | `string \| string[]`                  | `undefined`  | Controlled state - single value or array for multiple  |
| `defaultValue?`  | `string \| string[]`                  | `undefined`  | Uncontrolled initial state                             |
| `onValueChange?` | `(value: string \| string[]) => void` | `undefined`  | Callback when state changes                            |
| `disabled?`      | `boolean`                             | `false`      | Disables all accordion items                           |
| `orientation?`   | `"vertical" \| "horizontal"`          | `"vertical"` | Orientation for keyboard navigation                    |
| `as?`            | `React.ElementType`                   | `"div"`      | Polymorphic component type                             |
| `children`       | `React.ReactNode`                     | -            | Accordion.Item components                              |

**Events**

| Name            | Parameters                    | Description                               | When Triggered                          |
| --------------- | ----------------------------- | ----------------------------------------- | --------------------------------------- |
| `onValueChange` | `(value: string \| string[])` | State changes when panels expand/collapse | User interaction or programmatic change |

**HTML Attributes**

| Attribute             | Value                        | Purpose                          |
| --------------------- | ---------------------------- | -------------------------------- |
| `data-orientation`    | `"vertical" \| "horizontal"` | Indicates navigation orientation |
| `data-selection-mode` | `"single" \| "multiple"`     | Indicates the expansion mode     |

### Accordion.Item

Individual accordion item that contains a header and content panel.

**Props**

| Name        | Type                | Default     | Description                                                            |
| ----------- | ------------------- | ----------- | ---------------------------------------------------------------------- |
| `value`     | `string`            | -           | Unique identifier for the item                                         |
| `id?`       | `string`            | `undefined` | Custom base ID for ARIA relationships; derives trigger and content IDs |
| `disabled?` | `boolean`           | `false`     | Disables this specific item                                            |
| `as?`       | `React.ElementType` | `"div"`     | Polymorphic component type                                             |
| `children`  | `React.ReactNode`   | -           | Accordion.Header and Accordion.Content components                      |

**Events**

| Name | Parameters | Description                                 | When Triggered |
| ---- | ---------- | ------------------------------------------- | -------------- |
| None | -          | Item manages internal state through context | -              |

**HTML Attributes**

| Attribute       | Value                | Purpose                                  |
| --------------- | -------------------- | ---------------------------------------- |
| `data-state`    | `"open" \| "closed"` | Reflects the expansion state of the item |
| `data-disabled` | `""`                 | Present when the item is disabled        |

### Accordion.Header

Semantic heading wrapper for the accordion trigger button.

**Props**

| Name       | Type                | Default | Description                                  |
| ---------- | ------------------- | ------- | -------------------------------------------- |
| `level?`   | `number`            | `3`     | Heading level (1-6) for document hierarchy   |
| `as?`      | `React.ElementType` | `"h3"`  | Polymorphic component type (heading element) |
| `children` | `React.ReactNode`   | -       | Accordion.Trigger component                  |

**Events**

| Name | Parameters | Description               | When Triggered |
| ---- | ---------- | ------------------------- | -------------- |
| None | -          | Header is purely semantic | -              |

**HTML Attributes**

| Attribute       | Value                | Purpose                                  |
| --------------- | -------------------- | ---------------------------------------- |
| `data-state`    | `"open" \| "closed"` | Reflects the expansion state of the item |
| `data-level`    | `number`             | Reflects the rendered heading level      |
| `data-disabled` | `""`                 | Present when the item is disabled        |

### Accordion.Trigger

Button that toggles the visibility of the associated content panel.

**Props**

| Name         | Type                                                                           | Default     | Description                              |
| ------------ | ------------------------------------------------------------------------------ | ----------- | ---------------------------------------- |
| `as?`        | `React.ElementType`                                                            | `"button"`  | Polymorphic component type               |
| `children`   | `React.ReactNode \| ((state: AccordionTriggerRenderProps) => React.ReactNode)` | -           | Trigger content or render props function |
| `onClick?`   | `(event: React.MouseEvent) => void`                                            | `undefined` | Custom click handler                     |
| `onKeyDown?` | `(event: React.KeyboardEvent) => void`                                         | `undefined` | Custom keydown handler                   |

**Render Props (AccordionTriggerRenderProps)**

| Property   | Type         | Description                                            |
| ---------- | ------------ | ------------------------------------------------------ |
| `isOpen`   | `boolean`    | Whether the accordion item is currently expanded       |
| `disabled` | `boolean`    | Whether the trigger is disabled                        |
| `open`     | `() => void` | Function to programmatically open the accordion item   |
| `close`    | `() => void` | Function to programmatically close the accordion item  |
| `toggle`   | `() => void` | Function to programmatically toggle the accordion item |

**Events**

| Name        | Parameters                     | Description            | When Triggered         |
| ----------- | ------------------------------ | ---------------------- | ---------------------- |
| `onClick`   | `(event: React.MouseEvent)`    | Trigger clicked        | Mouse click on trigger |
| `onKeyDown` | `(event: React.KeyboardEvent)` | Key pressed on trigger | Keyboard interaction   |

**HTML Attributes**

| Attribute                | Value                | Purpose                                                        |
| ------------------------ | -------------------- | -------------------------------------------------------------- |
| `id`                     | `string`             | Unique identifier matching the trigger element ARIA ID         |
| `aria-expanded`          | `boolean`            | Indicates whether the associated panel is expanded             |
| `aria-controls`          | `string`             | References the content panel element ID                        |
| `data-state`             | `"open" \| "closed"` | Reflects the expansion state of the item                       |
| `data-disabled`          | `""`                 | Present when the trigger is disabled                           |
| `data-accordion-trigger` | `""`                 | Always present; identifies the element as an accordion trigger |
| `data-value`             | `string`             | The value of the accordion item this trigger belongs to        |

### Accordion.Content

Collapsible panel containing the accordion item content.

**Props**

| Name             | Type                     | Default     | Description                                                   |
| ---------------- | ------------------------ | ----------- | ------------------------------------------------------------- |
| `forceMount?`    | `boolean`                | `false`     | Force content to remain mounted when collapsed                |
| `onBeforeMatch?` | `(event: Event) => void` | `undefined` | Callback fired when content is found via browser Find command |
| `as?`            | `React.ElementType`      | `"div"`     | Polymorphic component type                                    |
| `children`       | `React.ReactNode`        | -           | Panel content                                                 |

**Events**

| Name            | Parameters       | Description                                                   | When Triggered                                                                        |
| --------------- | ---------------- | ------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| `onBeforeMatch` | `(event: Event)` | Fired when hidden content is matched via browser Find command | Browser Find (`Ctrl+F`/`Cmd+F`) matches content inside a closed, `forceMount`ed panel |

**HTML Attributes**

| Attribute         | Value                   | Purpose                                                                                                |
| ----------------- | ----------------------- | ------------------------------------------------------------------------------------------------------ |
| `id`              | `string`                | Unique identifier matching the content element ARIA ID                                                 |
| `role`            | `"region"`              | Always present; marks the panel as a landmark region                                                   |
| `aria-labelledby` | `string`                | References the trigger element that labels this panel                                                  |
| `data-state`      | `"open" \| "closed"`    | Reflects the visibility state of the panel                                                             |
| `data-disabled`   | `""`                    | Present when the item is disabled                                                                      |
| `hidden`          | `true \| "until-found"` | Present when closed and `forceMount` is `true`; `"until-found"` in modern browsers, `true` as fallback |

## Keyboard Interactions

Complete keyboard behavior for the accordion component:

| Key           | Action            | Context                      | Notes                                              |
| ------------- | ----------------- | ---------------------------- | -------------------------------------------------- |
| `Tab`         | Navigate          | Always                       | Moves focus to next focusable element in DOM order |
| `Shift + Tab` | Navigate backward | Always                       | Moves focus to previous focusable element          |
| `Enter`       | Toggle panel      | Focused trigger              | Expands/collapses the associated panel             |
| `Space`       | Toggle panel      | Focused trigger              | Alternative activation method for triggers         |
| `ArrowDown`   | Next trigger      | Focused trigger (vertical)   | Moves focus to next accordion trigger              |
| `ArrowUp`     | Previous trigger  | Focused trigger (vertical)   | Moves focus to previous accordion trigger          |
| `ArrowRight`  | Next trigger      | Focused trigger (horizontal) | Moves focus to next accordion trigger              |
| `ArrowLeft`   | Previous trigger  | Focused trigger (horizontal) | Moves focus to previous accordion trigger          |
| `Home`        | First trigger     | Focused trigger              | Moves focus to first accordion trigger             |
| `End`         | Last trigger      | Focused trigger              | Moves focus to last accordion trigger              |
