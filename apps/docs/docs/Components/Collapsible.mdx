## Features

- **Controlled and uncontrolled modes** - Full control over open state or automatic management
- **Keyboard navigation** - Enter and Space key support for trigger activation
- **Focus management** - Proper focus handling and restoration
- **Screen reader support** - ARIA attributes for accessibility
- **Flexible trigger elements** - Support for button and custom elements with proper semantics
- **Force mount option** - Keep content mounted when closed for performance or search optimization
- **Browser search integration** - Content findability with `beforematch` event support
- **Animation support** - CSS custom properties for smooth transitions
- **Polymorphic components** - Render as any element using the `as` prop

### Structure

```tsx
<Collapsible>
  <CollapsibleTrigger />
  <CollapsibleContent />
</Collapsible>
```

**Data Flow:**

- `Collapsible`: Provides context and state management for the collapsible
- `CollapsibleTrigger`: Interactive element that toggles the content visibility
- `CollapsibleContent`: Container that shows/hides based on the collapsible state

## Code Examples

### Basic Usage

```tsx
import { Collapsible } from '@turkish-technology/spar';

function BasicCollapsible() {
  return (
    <CollapsibleRoot>
      <CollapsibleTrigger>Toggle Content</CollapsibleTrigger>
      <CollapsibleContent>
        <p>This content can be toggled.</p>
      </CollapsibleContent>
    </CollapsibleRoot>
  );
}
```

### Controlled State

```tsx
import { Collapsible } from '@turkish-technology/spar';
import { useState } from 'react';

function ControlledCollapsible() {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <CollapsibleRoot open={isOpen} onOpenChange={setIsOpen}>
      <CollapsibleTrigger>{isOpen ? 'Collapse' : 'Expand'}</CollapsibleTrigger>
      <CollapsibleContent>
        <div>
          <h3>Controlled Content</h3>
          <p>The parent component controls this state</p>
        </div>
      </CollapsibleContent>
    </CollapsibleRoot>
  );
}
```

### Default Open State

```tsx
import { Collapsible } from '@turkish-technology/spar';

function DefaultOpenCollapsible() {
  return (
    <CollapsibleRoot defaultOpen={true}>
      <CollapsibleTrigger>Toggle Content</CollapsibleTrigger>
      <CollapsibleContent>
        <p>This content starts expanded</p>
      </CollapsibleContent>
    </CollapsibleRoot>
  );
}
```

### Custom Trigger Element

```tsx
import { Collapsible } from '@turkish-technology/spar';

function CustomTriggerCollapsible() {
  return (
    <CollapsibleRoot>
      <CollapsibleTrigger as='div' style={{ cursor: 'pointer' }}>
        <h3>Click this heading to expand</h3>
      </CollapsibleTrigger>
      <CollapsibleContent>
        <p>Content revealed by custom trigger.</p>
      </CollapsibleContent>
    </CollapsibleRoot>
  );
}
```

### Force Mount Content

```tsx
import { Collapsible } from '@turkish-technology/spar';

function ForceMountCollapsible() {
  return (
    <CollapsibleRoot>
      <CollapsibleTrigger>Toggle (Content Always Mounted)</CollapsibleTrigger>
      <CollapsibleContent forceMount={true}>
        <p>This content stays in the DOM even when collapsed.</p>
        <p>Useful for maintaining component state or enabling browser search.</p>
      </CollapsibleContent>
    </CollapsibleRoot>
  );
}
```

### Disabled State

```tsx
import { Collapsible } from '@turkish-technology/spar';

function DisabledCollapsible() {
  return (
    <CollapsibleRoot disabled={true}>
      <CollapsibleTrigger>Disabled Trigger</CollapsibleTrigger>
      <CollapsibleContent>
        <p>This content cannot be toggled</p>
      </CollapsibleContent>
```

## API Reference

### CollapsibleRoot

The root component that provides context and state management for the collapsible.

**Props**

| Name            | Type                      | Default | Description                               |
| --------------- | ------------------------- | ------- | ----------------------------------------- |
| `as?`           | `ElementType`           | `"div"` | Polymorphic component type                |
| `open?`         | `boolean`                 | -       | Controlled open state                     |
| `defaultOpen?`  | `boolean`                 | `false` | Default open state for uncontrolled usage |
| `onOpenChange?` | `(open: boolean) => void` | -       | Callback fired when open state changes    |
| `disabled?`     | `boolean`                 | `false` | Whether the collapsible is disabled       |
| `triggerId?`    | `string`                  | -       | Unique identifier for the trigger element |
| `contentId?`    | `string`                  | -       | Unique identifier for the content element |
| `children`      | `ReactNode`               | -       | Child components                          |

**Events**

| Name           | Parameters        | Description        | When Triggered                          |
| -------------- | ----------------- | ------------------ | --------------------------------------- |
| `onOpenChange` | `(open: boolean)` | Open state changes | User interaction or programmatic change |

**HTML Attributes**

| Attribute       | Value                | Purpose                  |
| --------------- | -------------------- | ------------------------ |
| `data-state`    | `"open" \| "closed"` | Indicates current state  |
| `data-disabled` | `""` (when disabled) | Indicates disabled state |

### CollapsibleTrigger

Interactive element that toggles the content visibility with full accessibility support. Extends all `Button` component props including polymorphic rendering via the `as` prop.

**Props**

| Name               | Type                                                                 | Default     | Description                                         |
| ------------------ | -------------------------------------------------------------------- | ----------- | --------------------------------------------------- |
| `as?`              | `ElementType`                                                      | `"button"`  | Element type for polymorphic rendering              |
| `children?`        | `ReactNode \| ((state: CollapsibleTriggerRenderProps) => ReactNode)` | -           | Trigger content or render props function            |
| `disabled?`        | `boolean`                                                            | `false`     | Whether trigger is disabled                         |
| `autoFocus?` | `boolean`                                                            | `false`     | Whether the button should receive focus on mount    |
| `isLoading?`       | `boolean`                                                            | `false`     | Loading state with screen reader support            |
| `isPressed?`       | `boolean`                                                            | `undefined` | Toggle state - creates a toggle button when defined |
| `onPressedChange?` | `(pressed: boolean) => void`                                         | `undefined` | Callback fired when toggle state changes            |
| `...props`         | `ButtonProps`                                                        | -           | All standard Button component attributes            |

**Render Props (CollapsibleTriggerRenderProps)**

| Property   | Type         | Description                                          |
| ---------- | ------------ | ---------------------------------------------------- |
| `isOpen`   | `boolean`    | Whether the collapsible content is currently visible |
| `disabled` | `boolean`    | Whether the trigger is disabled                      |
| `open`     | `() => void` | Function to programmatically open the collapsible    |
| `close`    | `() => void` | Function to programmatically close the collapsible   |
| `toggle`   | `() => void` | Function to programmatically toggle the collapsible  |

**Events**

| Name        | Parameters                     | Description            | When Triggered          |
| ----------- | ------------------------------ | ---------------------- | ----------------------- |
| `onClick`   | `(event: React.MouseEvent)`    | Trigger clicked        | Mouse click interaction |
| `onKeyDown` | `(event: React.KeyboardEvent)` | Key pressed on trigger | Keyboard interaction    |

**HTML Attributes**

| Attribute       | Value                | Purpose                                     |
| --------------- | -------------------- | ------------------------------------------- |
| `disabled`      | `boolean`            | Native disabled attribute (button elements) |
| `tabIndex`      | `0 \| -1`            | Focus management (non-button elements)      |
| `data-state`    | `"open" \| "closed"` | Indicates current state                     |
| `data-disabled` | `""` (when disabled) | Indicates disabled state                    |

### CollapsibleContent

Container that shows/hides based on the collapsible state with advanced features.

**Props**

| Name             | Type                     | Default | Description                                             |
| ---------------- | ------------------------ | ------- | ------------------------------------------------------- |
| `as?`            | `ElementType`          | `"div"` | Element type for polymorphic rendering                  |
| `forceMount?`    | `boolean`                | `false` | Force content to remain mounted when closed             |
| `children?`      | `ReactNode`              | -       | Content to be shown/hidden                              |
| `onBeforeMatch?` | `(event: Event) => void` | -       | Callback fired when content is found via browser search |

**Events**

| Name            | Parameters       | Description                      | When Triggered                                   |
| --------------- | ---------------- | -------------------------------- | ------------------------------------------------ |
| `onBeforeMatch` | `(event: Event)` | Content found via browser search | Browser's "find on page" feature locates content |

**HTML Attributes**

| Attribute       | Value                   | Purpose                             |
| --------------- | ----------------------- | ----------------------------------- |
| `hidden`        | `true \| "until-found"` | Controls visibility and findability |
| `data-state`    | `"open" \| "closed"`    | Indicates current state             |
| `data-disabled` | `""` (when disabled)    | Indicates disabled state            |

**CSS Custom Properties**

| Property                            | Description                      | When Available       |
| ----------------------------------- | -------------------------------- | -------------------- |
| `--spar-collapsible-content-width`  | Current content width in pixels  | When content is open |
| `--spar-collapsible-content-height` | Current content height in pixels | When content is open |

## Keyboard Interactions

| Key           | Action                     | Context         | Notes                                      |
| ------------- | -------------------------- | --------------- | ------------------------------------------ |
| `Tab`         | Navigate to trigger        | Always          | Moves focus to the trigger element         |
| `Shift + Tab` | Navigate away from trigger | Always          | Moves focus to previous focusable element  |
| `Enter`       | Toggle content             | Trigger focused | Activates the trigger to show/hide content |
| `Space`       | Toggle content             | Trigger focused | Alternative activation method for trigger  |
