## Features

- ✅ Automatic position detection for styling hooks
- ✅ External link security (rel="noopener noreferrer")
- ✅ Polymorphic components with 'as' prop support
- ✅ Navigation integration with custom routing
- ✅ Individual and global disabled states
- ✅ Render props support for conditional rendering based on item state
- ✅ Full support for icons and custom content in links

### Structure

```tsx
<Breadcrumb.Root>
  <Breadcrumb.List>
    <Breadcrumb.Item>
      <Breadcrumb.Link />
    </Breadcrumb.Item>
    <Breadcrumb.Separator />
    <Breadcrumb.Item>
      <Breadcrumb.Page />
    </Breadcrumb.Item>
  </Breadcrumb.List>
</Breadcrumb.Root>
```

**Data Flow:**

- `Breadcrumb.Root` provides navigation context and manages shared state
- `Breadcrumb.List` calculates position data (first, middle, last) for items
- `Breadcrumb.Item` receives position information for styling hooks
- `Breadcrumb.Link` handles navigation and routing integration
- `Breadcrumb.Page` marks the current page with proper ARIA attributes
- `Breadcrumb.Separator` provides visual separation (hidden from screen readers)

### Render Props

`Breadcrumb.Item` accepts a render function as children, providing access to `position`, `isCurrent`, and `isDisabled` state. This is useful for conditionally rendering custom components like Next.js `Link` or React Router `Link` based on item state.

```tsx {8-18}
import NextLink from 'next/link';

function RenderPropsBreadcrumb() {
  return (
    <Breadcrumb.Root>
      <Breadcrumb.List>
        <Breadcrumb.Item>
          {({ isCurrent, position, isDisabled }) =>
            isCurrent ? (
              <Breadcrumb.Page>{`Current (${position})`}</Breadcrumb.Page>
            ) : (
              <Breadcrumb.Link as={NextLink} href='/home' disabled={isDisabled}>
                Home
              </Breadcrumb.Link>
            )
          }
        </Breadcrumb.Item>
        <Breadcrumb.Separator>/</Breadcrumb.Separator>
        <Breadcrumb.Item>
          {({ isCurrent }) =>
            isCurrent ? (
              <Breadcrumb.Page>Settings</Breadcrumb.Page>
            ) : (
              <Breadcrumb.Link href='/settings'>Settings</Breadcrumb.Link>
            )
          }
        </Breadcrumb.Item>
      </Breadcrumb.List>
    </Breadcrumb.Root>
  );
}
```

The render function receives the following properties:

| Property     | Type                            | Description                                         |
| ------------ | ------------------------------- | --------------------------------------------------- |
| `position`   | `'first' \| 'middle' \| 'last'` | Position of the item in the breadcrumb trail        |
| `isCurrent`  | `boolean`                       | Whether this item is the current (last) page        |
| `isDisabled` | `boolean`                       | Whether breadcrumb navigation is disabled from root |

## API Reference

### Breadcrumb.Root

Navigation landmark container that provides context and manages shared state for all breadcrumb components.

**Props**

| Name          | Type                | Default        | Description                                      |
| ------------- | ------------------- | -------------- | ------------------------------------------------ |
| `children`    | `React.ReactNode`   | -              | Breadcrumb content                               |
| `as?`         | `React.ElementType` | `'nav'`        | Polymorphic element type                         |
| `aria-label?` | `string`            | `'Breadcrumb'` | Accessible name for navigation landmark          |
| `onNavigate?` | `NavigationHandler` | `undefined`    | Navigation event handler for routing integration |
| `disabled?`   | `boolean`           | `false`        | Disable all breadcrumb navigation                |

**Events**

| Name         | Parameters                          | Description                                        | When Triggered                    |
| ------------ | ----------------------------------- | -------------------------------------------------- | --------------------------------- |
| `onNavigate` | `(href: string, event: PressEvent)` | Navigation handler called when links are activated | Link click or keyboard activation |

**HTML Attributes**

| Attribute       | Value    | Purpose                                   |
| --------------- | -------- | ----------------------------------------- |
| `aria-label`    | `string` | Value from `aria-label` prop              |
| `aria-disabled` | `"true"` | Present when `disabled` is `true`         |
| `data-disabled` | `""`     | Present when `disabled` is `true`         |

### Breadcrumb.List

Ordered list container that provides semantic structure and automatically calculates position data for child items.

**Props**

| Name       | Type                | Default | Description              |
| ---------- | ------------------- | ------- | ------------------------ |
| `children` | `React.ReactNode`   | -       | List items content       |
| `as?`      | `React.ElementType` | `'ol'`  | Polymorphic element type |

**Events**

| Name                   | Parameters | Description                   | When Triggered            |
| ---------------------- | ---------- | ----------------------------- | ------------------------- |
| _(No specific events)_ | -          | Inherits standard HTML events | Standard DOM interactions |

### Breadcrumb.Item

List item wrapper that receives position and current state from parent Breadcrumb.List for styling hooks and accessibility.

**Props**

| Name         | Type                                                                         | Default    | Description                                             |
| ------------ | ---------------------------------------------------------------------------- | ---------- | ------------------------------------------------------- |
| `children`   | `React.ReactNode \| ((props: BreadcrumbItemRenderProps) => React.ReactNode)` | -          | Item content or render function receiving item state    |
| `as?`        | `React.ElementType`                                                          | `'li'`     | Polymorphic element type                                |
| `position?`  | `BreadcrumbPosition`                                                         | `'middle'` | Position in trail (automatically calculated)            |
| `isCurrent?` | `boolean`                                                                    | `false`    | Whether this is current page (automatically calculated) |

**Events**

| Name                   | Parameters | Description                   | When Triggered            |
| ---------------------- | ---------- | ----------------------------- | ------------------------- |
| _(No specific events)_ | -          | Inherits standard HTML events | Standard DOM interactions |

**HTML Attributes**

| Attribute       | Value                           | Purpose                               |
| --------------- | ------------------------------- | ------------------------------------- |
| `data-position` | `"first" \| "middle" \| "last"` | Indicates position in breadcrumb      |
| `data-current`  | `""`                            | Present when this is the current page |

### Breadcrumb.Link

Interactive link component with accessibility features, routing integration, and security for external links.

**Props**

| Name          | Type                          | Default     | Description                                                        |
| ------------- | ----------------------------- | ----------- | ------------------------------------------------------------------ |
| `children`    | `React.ReactNode`             | -           | Link text content                                                  |
| `as?`         | `React.ElementType`           | `'a'`       | Polymorphic element type                                           |
| `href?`       | `string`                      | `undefined` | Link destination                                                   |
| `disabled?`   | `boolean`                     | `false`     | Disable this specific link                                         |
| `isExternal?` | `boolean`                     | `false`     | Indicates external link (adds security attributes)                 |
| `onPress?`    | `(event: PressEvent) => void` | `undefined` | Press event handler (overrides default navigation)                 |
| `target?`     | `string`                      | `undefined` | Link target (auto-set to '\_blank' for external links)             |
| `rel?`        | `string`                      | `undefined` | Link relationship (auto-set to 'noopener noreferrer' for external) |

**Events**

| Name        | Parameters                     | Description                                    | When Triggered                        |
| ----------- | ------------------------------ | ---------------------------------------------- | ------------------------------------- |
| `onPress`   | `(event: PressEvent)`          | Custom press handler that overrides navigation | Click, Enter, or Space key            |
| `onClick`   | `(event: React.MouseEvent)`    | Standard click handler                         | Mouse click (if onPress not provided) |
| `onKeyDown` | `(event: React.KeyboardEvent)` | Standard keyboard handler                      | Key press (if onPress not provided)   |

**HTML Attributes**

| Attribute       | Value    | Purpose                                  |
| --------------- | -------- | ---------------------------------------- |
| `aria-disabled` | `"true"` | Present when link is disabled            |
| `data-disabled` | `""`     | Present when link is disabled            |
| `data-external` | `""`     | Present when link is external            |
| `tabIndex`      | `-1`     | Set to `-1` when disabled                |

### Breadcrumb.Page

Non-interactive current page indicator with proper semantic marking for screen readers.

**Props**

| Name       | Type                | Default  | Description              |
| ---------- | ------------------- | -------- | ------------------------ |
| `children` | `React.ReactNode`   | -        | Current page name        |
| `as?`      | `React.ElementType` | `'span'` | Polymorphic element type |

**Events**

| Name                   | Parameters | Description                   | When Triggered            |
| ---------------------- | ---------- | ----------------------------- | ------------------------- |
| _(No specific events)_ | -          | Inherits standard HTML events | Standard DOM interactions |

**HTML Attributes**

| Attribute       | Value    | Purpose                                    |
| --------------- | -------- | ------------------------------------------ |
| `aria-current`  | `"page"` | Always present; marks the current page     |
| `data-current`  | `""`     | Always present on the current page element |

### Breadcrumb.Separator

Visual separator between breadcrumb items, hidden from screen readers to prevent verbose announcements.

**Props**

| Name           | Type                | Default     | Description              |
| -------------- | ------------------- | ----------- | ------------------------ |
| `children?`    | `React.ReactNode`   | `undefined` | Custom separator content |
| `as?`          | `React.ElementType` | `'li'`      | Polymorphic element type |
| `aria-hidden?` | `boolean`           | `true`      | Hide from screen readers |

**Events**

| Name                   | Parameters | Description                   | When Triggered            |
| ---------------------- | ---------- | ----------------------------- | ------------------------- |
| _(No specific events)_ | -          | Inherits standard HTML events | Standard DOM interactions |

## Keyboard Interactions

Complete keyboard behavior for the entire breadcrumb component:

| Key           | Action            | Context      | Notes                                                    |
| ------------- | ----------------- | ------------ | -------------------------------------------------------- |
| `Tab`         | Navigate forward  | Always       | Moves focus to next focusable breadcrumb link            |
| `Shift + Tab` | Navigate backward | Always       | Moves focus to previous focusable breadcrumb link        |
| `Enter`       | Activate link     | Focused link | Triggers navigation or onPress handler                   |
| `Space`       | Activate link     | Focused link | Alternative activation method for links                  |
| `Escape`      | No action         | Breadcrumb   | Breadcrumbs don't trap focus or need escape behavior     |
| `Arrow Keys`  | No action         | Breadcrumb   | Not applicable - breadcrumbs use standard tab navigation |
| `Home`        | No action         | Breadcrumb   | Not applicable - use Tab to navigate to first link       |
| `End`         | No action         | Breadcrumb   | Not applicable - use Tab to navigate to last link        |

**Note**: Disabled links are automatically skipped in the tab order and do not respond to keyboard activation. The current page element (Breadcrumb.Page) is not focusable as it represents static content.
