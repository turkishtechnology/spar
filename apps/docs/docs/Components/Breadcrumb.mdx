# Breadcrumb

A fully accessible headless breadcrumb component for displaying hierarchical navigation paths with complete keyboard support and screen reader compatibility.

![Accessibility Badge](https://img.shields.io/badge/Accessible-WCAG%202.2%20AA-green) ![Tree-shakeable Badge](https://img.shields.io/badge/Tree--shakeable-Yes-green) ![TypeScript Badge](https://img.shields.io/badge/TypeScript-Strict-blue)

<LiveCode 
  code={`function BasicBreadcrumb() {
  const [currentPath, setCurrentPath] = React.useState('/products/laptops/gaming');
  
  const handleNavigate = (href, event) => {
    event.preventDefault();
    setCurrentPath(href);
    console.log('Navigate to:', href);
  };

  // Define breadcrumb structure
  const breadcrumbs = [
    { href: '/', label: 'Home' },
    { href: '/products', label: 'Products' },
    { href: '/products/laptops', label: 'Laptops' },
    { href: '/products/laptops/gaming', label: 'Gaming Laptops' },
  ];

  return (
    <BreadcrumbRoot 
      onNavigate={handleNavigate} 
      style={{ padding: '16px', border: '1px solid #e0e0e0', borderRadius: '8px' }}
    >
      <BreadcrumbList 
        style={{ 
          display: 'flex', 
          alignItems: 'center', 
          gap: '8px', 
          listStyle: 'none',
          margin: 0,
          padding: 0
        }}
      >
        {breadcrumbs.map((item, index) => {
          const isLast = index === breadcrumbs.length - 1;
          const isCurrent = item.href === currentPath;
          
          return (
            <React.Fragment key={item.href}>
              <BreadcrumbItem style={{ margin: 0, padding: 0 }}>
                {isCurrent ? (
                  <BreadcrumbPage style={{ color: '#333', fontWeight: '500' }}>
                    {item.label}
                  </BreadcrumbPage>
                ) : (
                  <BreadcrumbLink 
                    href={item.href}
                    style={{ 
                      color: '#0066cc', 
                      textDecoration: 'none',
                      cursor: 'pointer'
                    }}
                  >
                    {item.label}
                  </BreadcrumbLink>
                )}
              </BreadcrumbItem>
              {!isLast && (
                <BreadcrumbSeparator style={{ color: '#666', margin: '0 8px' }}>›</BreadcrumbSeparator>
              )}
            </React.Fragment>
          );
        })}
      </BreadcrumbList>
    </BreadcrumbRoot>
  );
}`}

## Features

- ✅ Complete keyboard navigation (Tab, Enter, Space)
- ✅ Screen reader optimized with proper ARIA structure
- ✅ Automatic position detection for styling hooks
- ✅ External link security (rel="noopener noreferrer")
- ✅ Polymorphic components with 'as' prop support
- ✅ Navigation integration with custom routing
- ✅ Individual and global disabled states
- ✅ Current page identification with aria-current
- ✅ Separator elements hidden from assistive technology
- ✅ Full support for icons and custom content in links

## Anatomy

Visual component hierarchy showing the semantic structure and data flow:

```
BreadcrumbRoot (nav)
├── BreadcrumbList (ol)
    ├── BreadcrumbItem (li) → [position: first]
    │   └── BreadcrumbLink (a)
    ├── BreadcrumbSeparator (li) → [aria-hidden: true]
    ├── BreadcrumbItem (li) → [position: middle]
    │   └── BreadcrumbLink (a)
    ├── BreadcrumbSeparator (li) → [aria-hidden: true]
    └── BreadcrumbItem (li) → [position: last, isCurrent: true]
        └── BreadcrumbPage (span) → [aria-current: page]
```

**Data Flow**: BreadcrumbRoot provides navigation context → BreadcrumbList calculates positions → BreadcrumbItem receives position data → BreadcrumbLink/Page consume context for behavior.

## API Reference

### BreadcrumbRoot

Navigation landmark container that provides context and manages shared state for all breadcrumb components.

**Props**

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `ReactNode` | - | Breadcrumb content |
| `as?` | `ElementType` | `'nav'` | Polymorphic element type |
| `aria-label?` | `string` | `'Breadcrumb'` | Accessible name for navigation landmark |
| `onNavigate?` | `NavigationHandler` | `undefined` | Navigation event handler for routing integration |
| `isDisabled?` | `boolean` | `false` | Disable all breadcrumb navigation |

**Events**

| Name | Parameters | Description | When Triggered |
|------|------------|-------------|----------------|
| `onNavigate` | `(href: string, event: MouseEvent \| KeyboardEvent)` | Navigation handler called when links are activated | Link click or keyboard activation |

**ARIA Attributes**

| Attribute | Value | Purpose | Applied To |
|-----------|-------|---------|------------|
| `aria-label` | `string` | Provides accessible name for navigation region | Root nav element |
| `aria-disabled` | `boolean` | Indicates disabled state to assistive technology | Root nav element |

### BreadcrumbList

Ordered list container that provides semantic structure and automatically calculates position data for child items.

**Props**

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `ReactNode` | - | List items content |
| `as?` | `ElementType` | `'ol'` | Polymorphic element type |

**Events**

| Name | Parameters | Description | When Triggered |
|------|------------|-------------|----------------|
| *(No specific events)* | - | Inherits standard HTML events | Standard DOM interactions |

**ARIA Attributes**

| Attribute | Value | Purpose | Applied To |
|-----------|-------|---------|------------|
| `role` | `"list"` | Semantic list structure (implicit) | Ordered list element |

### BreadcrumbItem

List item wrapper that receives position and current state from parent BreadcrumbList for styling hooks and accessibility.

**Props**

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `ReactNode` | - | Item content (Link or Page) |
| `as?` | `ElementType` | `'li'` | Polymorphic element type |
| `position?` | `BreadcrumbPosition` | `'middle'` | Position in trail (automatically calculated) |
| `isCurrent?` | `boolean` | `false` | Whether this is current page (automatically calculated) |

**Events**

| Name | Parameters | Description | When Triggered |
|------|------------|-------------|----------------|
| *(No specific events)* | - | Inherits standard HTML events | Standard DOM interactions |

**ARIA Attributes**

| Attribute | Value | Purpose | Applied To |
|-----------|-------|---------|------------|
| `role` | `"listitem"` | Semantic list item (implicit) | List item element |

### BreadcrumbLink

Interactive link component with accessibility features, routing integration, and security for external links.

**Props**

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `ReactNode` | - | Link text content |
| `as?` | `ElementType` | `'a'` | Polymorphic element type |
| `href?` | `string` | `undefined` | Link destination |
| `isDisabled?` | `boolean` | `false` | Disable this specific link |
| `isExternal?` | `boolean` | `false` | Indicates external link (adds security attributes) |
| `onPress?` | `(event: PressEvent) => void` | `undefined` | Press event handler (overrides default navigation) |
| `target?` | `string` | `undefined` | Link target (auto-set to '_blank' for external links) |
| `rel?` | `string` | `undefined` | Link relationship (auto-set to 'noopener noreferrer' for external) |

**Events**

| Name | Parameters | Description | When Triggered |
|------|------------|-------------|----------------|
| `onPress` | `(event: MouseEvent \| KeyboardEvent)` | Custom press handler that overrides navigation | Click, Enter, or Space key |
| `onClick` | `(event: MouseEvent)` | Standard click handler | Mouse click (if onPress not provided) |
| `onKeyDown` | `(event: KeyboardEvent)` | Standard keyboard handler | Key press (if onPress not provided) |

**ARIA Attributes**

| Attribute | Value | Purpose | Applied To |
|-----------|-------|---------|------------|
| `aria-disabled` | `boolean` | Indicates disabled state | Link element |
| `tabIndex` | `number` | Controls focusability (-1 when disabled) | Link element |
| `role` | `"link"` | Semantic link role (implicit when href present) | Link element |

### BreadcrumbPage

Non-interactive current page indicator with proper semantic marking for screen readers.

**Props**

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `ReactNode` | - | Current page name |

**Events**

| Name | Parameters | Description | When Triggered |
|------|------------|-------------|----------------|

**ARIA Attributes**

| Attribute | Value | Purpose | Applied To |

| `aria-hidden?` | `boolean` | `true` | Hide from screen readers |

**Events**

| Name | Parameters | Description | When Triggered |
|------|------------|-------------|----------------|
| *(No specific events)* | - | Inherits standard HTML events | Standard DOM interactions |

**ARIA Attributes**

| Attribute | Value | Purpose | Applied To |
|-----------|-------|---------|------------|
| `aria-hidden` | `boolean` | Hides decorative separator from assistive technology | Separator element |

## Keyboard Interactions

Complete keyboard behavior for the entire breadcrumb component:

| Key | Action | Context | Notes |
|-----|--------|---------|-------|
| `Tab` | Navigate forward | Always | Moves focus to next focusable breadcrumb link |
| `Shift + Tab` | Navigate backward | Always | Moves focus to previous focusable breadcrumb link |
| `Enter` | Activate link | Focused link | Triggers navigation or onPress handler |
| `Space` | Activate link | Focused link | Alternative activation method for links |
| `Escape` | No action | Breadcrumb | Breadcrumbs don't trap focus or need escape behavior |
| `Arrow Keys` | No action | Breadcrumb | Not applicable - breadcrumbs use standard tab navigation |
| `Home` | No action | Breadcrumb | Not applicable - use Tab to navigate to first link |
| `End` | No action | Breadcrumb | Not applicable - use Tab to navigate to last link |

**Note**: Disabled links are automatically skipped in the tab order and do not respond to keyboard activation. The current page element (BreadcrumbPage) is not focusable as it represents static content.
