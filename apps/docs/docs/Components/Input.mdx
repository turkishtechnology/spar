# Input

A headless input component providing accessible form input primitives with zero styling opinions. Pair it with the [Field](./Field.mdx) primitive to get label, description, and error-message wiring with coordinated ARIA IDs.

The live demo shows the recommended pattern: a `Field` wrapper supplying label, helper text, and error message wiring around the `Input` primitive.

## Features

- ✅ Text input and textarea support via polymorphic rendering (`input` or `textarea`)
- ✅ Reads validation, disabled, required, and read-only state from a parent `Field` automatically (direct props still override)
- ✅ Focus state tracking on the input element
- ✅ Form integration with name, value, and change event support
- ✅ Works standalone or composed with `Field`, `Label`, and custom layout wrappers

## Import

```tsx
import { Field, Input } from '@turkish-technology/spar';
```

`Input` and `Input.Root` refer to the same component — the difference is only notation style. Label, description, and error message are owned by the [`Field`](./Field.mdx) primitive:

```tsx
// Dot notation
<Field.Root>
  <Field.Label />
  <Input.Root>

import {
  Field,

<Field>
  <FieldLabel />

```

### Structure

```tsx
<Field.Root>
  <Field.Label />
  <Input.Root>
    <Input.Field />
  </Input.Root>
  <Field.Description />
  <Field.ErrorMessage />
</Field.Root>
```

**Data Flow:**

- **Field.Root**: Owns coordinated IDs and the `invalid` / `disabled` / `required` / `readOnly` state, propagated via context
- **Field.Label**: Accessible `<label>` auto-linked to the input via `htmlFor`
- **Input.Root**: Provides visual-input context; inherits state from the enclosing `Field` when present
- **Input.Field**: Core input element with polymorphic support (input/textarea)
- **Field.Description**: Helper text linked via `aria-describedby`
- **Field.ErrorMessage**: Error announcement with `role="alert"`, only rendered when `invalid` is `true`

## Code Examples

### Basic Text Input

A simple text input with label and description for user guidance.

```tsx
function BasicTextInput() {
  const [value, setValue] = React.useState('');

  return (
    <Field.Root>
      <Field.Label>Email Address</Field.Label>
      <Input.Root>
        <Input.Field
          type='email'
          value={value}
          onChange={(e) => setValue(e.target.value)}
          placeholder='Enter your email'
        />
      </Input.Root>
      <Field.Description>We'll use this to send you important updates</Field.Description>
    </Field.Root>
  );
}
```

### Input with Validation

Demonstrates validation state management with conditional error message display.

```tsx {2-3,5-7,12,21-22,24}
function ValidatedInput() {
  const [email, setEmail] = React.useState('');
  const [invalid, setInvalid] = React.useState(false);

  const handleSubmit = () => {
    const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
    setInvalid(!emailRegex.test(email));
  };

  return (
    <div>
      <Field.Root invalid={invalid} required>
        <Field.Label>Email Address</Field.Label>
        <Input.Root>
          <Input.Field
            type='email'
            value={email}
            onChange={(e) => setEmail(e.target.value)}
            placeholder='user@example.com'
          />
        </Input.Root>
        <Field.Description>Enter a valid email address for account verification</Field.Description>
        <Field.ErrorMessage>Please enter a valid email address</Field.ErrorMessage>
      </Field.Root>
      <button type='button' onClick={handleSubmit}>
        Validate Email
      </button>
    </div>
  );
}
```

### Textarea Input

Shows polymorphic rendering capability for multi-line text input with proper accessibility.

```tsx {2,7-14,16}
function TextareaInput() {
  const [message, setMessage] = React.useState('');

  return (
    <Field.Root>
      <Field.Label>Message</Field.Label>
      <Input.Root>
        <Input.Field
          as='textarea'
          value={message}
          onChange={(e) => setMessage(e.target.value)}
          rows={4}
          placeholder='Enter your message here...'
        />
      </Input.Root>
      <Field.Description>Maximum 500 characters ({message.length}/500)</Field.Description>
    </Field.Root>
  );
}
```

### Form Integration

Complete form example with validation, submission, and error handling.

```tsx
function ContactForm() {
  const [formData, setFormData] = React.useState({ name: '', email: '', message: '' });
  const [errors, setErrors] = React.useState<Record<string, string>>({});

  const validateForm = () => {
    const newErrors: Record<string, string> = {};
    if (!formData.name) newErrors.name = 'Name is required';
    if (!formData.email) newErrors.email = 'Email is required';
    else if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(formData.email)) {
      newErrors.email = 'Please enter a valid email';
    }
    if (!formData.message) newErrors.message = 'Message is required';
    setErrors(newErrors);
    return Object.keys(newErrors).length === 0;
  };

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    if (validateForm()) {
      console.log('Form submitted:', formData);
    }
  };

  return (
    <form onSubmit={handleSubmit} noValidate>
      <Field.Root invalid={!!errors.name} required>
        <Field.Label>Full Name</Field.Label>
        <Input.Root>
          <Input.Field
            name='name'
            value={formData.name}
            onChange={(e) => setFormData({ ...formData, name: e.target.value })}
          />
        </Input.Root>
        <Field.ErrorMessage>{errors.name}</Field.ErrorMessage>
      </Field.Root>

      <Field.Root invalid={!!errors.email} required>
        <Field.Label>Email</Field.Label>
        <Input.Root>
          <Input.Field
            type='email'
            name='email'
            value={formData.email}
            onChange={(e) => setFormData({ ...formData, email: e.target.value })}
          />
        </Input.Root>
        <Field.ErrorMessage>{errors.email}</Field.ErrorMessage>
      </Field.Root>

      <Field.Root invalid={!!errors.message} required>
        <Field.Label>Message</Field.Label>
        <Input.Root>
          <Input.Field
            as='textarea'
            name='message'
            rows={4}
            value={formData.message}
            onChange={(e) => setFormData({ ...formData, message: e.target.value })}
          />
        </Input.Root>
        <Field.ErrorMessage>{errors.message}</Field.ErrorMessage>
      </Field.Root>

      <button type='submit'>Send Message</button>
    </form>
  );
}
```

## API Reference

### Input / Input.Root

The root context provider that wraps all compound input parts. `Input` and `Input.Root` are the same component - the difference is only import/notation style. Renders a `<div>` by default and exposes an `InputContext` that all child components consume.

**Props**

| Name         | Type                      | Default     | Description                                                          |
| ------------ | ------------------------- | ----------- | -------------------------------------------------------------------- |
| `id?`        | `string`                  | `undefined` | Base ID used to derive sub-element IDs. Auto-generated when omitted. |
| `as?`        | `React.ElementType`       | `'div'`     | Element type for the root wrapper                                    |
| `ref?`       | `React.Ref<T>`            | `undefined` | Ref for the root wrapper element                                     |
| `children`   | `React.ReactNode`         | -           | Compound input elements                                              |
| `invalid?`   | `boolean`                 | `false`     | Validation state propagated to all compound parts                    |
| `disabled?`  | `boolean`                 | `false`     | Disabled state propagated to all compound parts                      |
| `required?`  | `boolean`                 | `false`     | Required state propagated to all compound parts                      |
| `readOnly?`  | `boolean`                 | `false`     | Read-only state propagated to all compound parts                     |
| `...props`   | `React.ComponentProps<T>` | -           | All standard HTML attributes for the root element                    |

**HTML Attributes**

| Attribute       | Value               | Purpose                    |
| --------------- | ------------------- | -------------------------- |
| `data-invalid`  | `""` \| `undefined` | Indicates validation state |
| `data-disabled` | `""` \| `undefined` | Indicates disabled state   |
| `data-required` | `""` \| `undefined` | Indicates required state   |
| `data-readonly` | `""` \| `undefined` | Indicates read-only state  |

### Input.Field

The core input element with polymorphic rendering support. Handles focus states, validation attributes, and ARIA associations automatically.

**Props**

| Name         | Type                                             | Default     | Description                            |
| ------------ | ------------------------------------------------ | ----------- | -------------------------------------- |
| `as?`        | `React.ElementType`                              | `'input'`   | Element type for polymorphic rendering |
| `ref?`       | `React.ComponentPropsWithRef<T>['ref']`          | `undefined` | Ref for the input element              |
| `autoFocus?` | `boolean`                                        | `false`     | Whether to focus the input on mount    |
| `onFocus?`   | `(event: React.FocusEvent<HTMLElement>) => void` | `undefined` | Focus event handler                    |
| `onBlur?`    | `(event: React.FocusEvent<HTMLElement>) => void` | `undefined` | Blur event handler                     |

**Events**

| Name       | Parameters                                | Description         | When Triggered                           |
| ---------- | ----------------------------------------- | ------------------- | ---------------------------------------- |
| `onFocus`  | `(event: React.FocusEvent<HTMLElement>)`  | Input gains focus   | User clicks or tabs to input             |
| `onBlur`   | `(event: React.FocusEvent<HTMLElement>)`  | Input loses focus   | User clicks away or tabs to next element |
| `onChange` | `(event: React.ChangeEvent<HTMLElement>)` | Input value changes | User types or modifies input content     |

**HTML Attributes**

| Attribute        | Value               | Purpose                                                                      |
| ---------------- | ------------------- | ---------------------------------------------------------------------------- |
| `id`             | `string`            | Unique field identifier; auto-assigned from context when inside `Input.Root` |
| `data-focused`   | `""` \| `undefined` | Indicates focus state                                                        |
| `data-autofocus` | `""` \| `undefined` | Indicates auto-focus state                                                   |
| `data-disabled`  | `""` \| `undefined` | Indicates disabled state                                                     |
| `data-required`  | `""` \| `undefined` | Indicates required state                                                     |
| `data-readonly`  | `""` \| `undefined` | Indicates read-only state                                                    |

### Label, Description, and Error Message

Label, helper text, and validation messaging are not part of `Input`. Use the [`Field`](./Field.mdx) primitive — `Field.Label`, `Field.Description`, and `Field.ErrorMessage` — which share coordinated ARIA IDs and state (`invalid`, `disabled`, `required`, `readOnly`) with the enclosed `Input` via context.

## Keyboard Interactions

Complete keyboard behavior for the Input component:

| Key           | Action            | Context       | Notes                                                    |
| ------------- | ----------------- | ------------- | -------------------------------------------------------- |
| `Tab`         | Navigate forward  | Always        | Moves focus to the input field or next focusable element |
| `Shift + Tab` | Navigate backward | Always        | Moves focus to previous focusable element                |
| `Enter`       | Submit form       | Form context  | Submits parent form when input is focused                |
| `Backspace`   | Delete character  | Text input    | Removes character before cursor                          |
| `Delete`      | Delete character  | Text input    | Removes character after cursor                           |
| `Home`        | Move to start     | Text input    | Moves cursor to beginning of text                        |
| `End`         | Move to end       | Text input    | Moves cursor to end of text                              |
| `ArrowLeft`   | Move left         | Text input    | Moves cursor one character left                          |
| `ArrowRight`  | Move right        | Text input    | Moves cursor one character right                         |
| `Ctrl + A`    | Select all        | Text input    | Selects all text in input                                |
| `Ctrl + C`    | Copy              | Text selected | Copies selected text to clipboard                        |
| `Ctrl + X`    | Cut               | Text selected | Cuts selected text to clipboard                          |
| `Ctrl + V`    | Paste             | Text input    | Pastes text from clipboard                               |
| `Ctrl + Z`    | Undo              | Text input    | Undoes last edit operation                               |
