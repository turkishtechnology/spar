## Features

- ✅ Text input and textarea support via polymorphic rendering (`input` or `textarea`)
- ✅ Validation, disabled, required, and read-only states that propagate automatically to all compound parts
- ✅ Conditional error message rendering based on validation state
- ✅ Helper text support linked to the input field
- ✅ Form integration with name, value, and change event support
- ✅ Focus state tracking on the input element

## Installation

```tsx
import { Input } from '@turkish-technology/spar';
```

`Input` and `Input.Root` refer to the same component — the difference is only notation style:

```tsx
// Dot notation (sub-parts accessed via Input.*)
<Input.Root>
  <Input.Label />
  <Input.Field />
  <Input.Description />
  <Input.ErrorMessage />
</Input.Root>;

// Named import style (sub-parts imported separately)
import {
  Input,
  InputLabel,
  InputField,
  InputDescription,
  InputErrorMessage,
} from '@turkish-technology/spar';

<Input>
  <InputLabel />
  <InputField />
  <InputDescription />
  <InputErrorMessage />
</Input>;
```

### Structure

```tsx
<Input.Root>
  <Input.Label />
  <Input.Field />
  <Input.Description />
  <Input.ErrorMessage />
</Input.Root>
```

**Data Flow:**

- **Input.Root**: Context provider that manages validation, disabled, required, and read-only states
- **Input.Field**: Core input element with polymorphic support (input/textarea)
- **Input.Label**: Associated label element with automatic ID linking
- **Input.Description**: Helper text element for additional guidance
- **Input.ErrorMessage**: Error announcement element with role="alert"

## Code Examples

### Basic Text Input

A simple text input with label and description for user guidance.

```tsx
function BasicTextInput() {
  const [value, setValue] = React.useState('');

  return (
    <Input.Root>
      <Input.Label>Email Address</Input.Label>
      <Input.Field
        type='email'
        value={value}
        onChange={(e) => setValue(e.target.value)}
        placeholder='Enter your email'
      />
      <Input.Description>We'll use this to send you important updates</Input.Description>
    </Input.Root>
  );
}
```

### Input with Validation

Demonstrates validation state management with conditional error message display.

```tsx
function ValidatedInput() {
  const [email, setEmail] = React.useState('');
  const [isInvalid, setIsInvalid] = React.useState(false);

  const handleSubmit = () => {
    const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
    setIsInvalid(!emailRegex.test(email));
  };

  return (
    <div>
      <Input.Root isInvalid={isInvalid} required>
        <Input.Label>Email Address</Input.Label>
        <Input.Field
          type='email'
          value={email}
          onChange={(e) => setEmail(e.target.value)}
          placeholder='user@example.com'
        />
        <Input.Description>Enter a valid email address for account verification</Input.Description>
        <Input.ErrorMessage>Please enter a valid email address</Input.ErrorMessage>
      </Input.Root>
      <button type='button' onClick={handleSubmit}>
        Validate Email
      </button>
    </div>
  );
}
```

### Textarea Input

### Form Integration

Complete form example with validation, submission, and error handling.

```tsx
function ContactForm() {
  const [formData, setFormData] = React.useState({ name: '', email: '', message: '' });
  const [errors, setErrors] = React.useState<Record<string, string>>({});

  const validateForm = () => {
    const newErrors: Record<string, string> = {};
    if (!formData.name) newErrors.name = 'Name is required';
    if (!formData.email) newErrors.email = 'Email is required';
    else if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(formData.email)) {
      newErrors.email = 'Please enter a valid email';
    }
    if (!formData.message) newErrors.message = 'Message is required';
    setErrors(newErrors);
    return Object.keys(newErrors).length === 0;
  };

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    if (validateForm()) {
      console.log('Form submitted:', formData);
    }
  };

  return (
    <form onSubmit={handleSubmit} noValidate>
      <Input.Root isInvalid={!!errors.name} required>
        <Input.Label>Full Name</Input.Label>
        <Input.Field
          name='name'
          value={formData.name}
          onChange={(e) => setFormData({ ...formData, name: e.target.value })}
        />
        <Input.ErrorMessage>{errors.name}</Input.ErrorMessage>
      </Input.Root>

      <Input.Root isInvalid={!!errors.email} required>
        <Input.Label>Email</Input.Label>
        <Input.Field
          type='email'
          name='email'
          value={formData.email}
          onChange={(e) => setFormData({ ...formData, email: e.target.value })}
        />
        <Input.ErrorMessage>{errors.email}</Input.ErrorMessage>
      </Input.Root>

      <Input.Root isInvalid={!!errors.message} required>
        <Input.Label>Message</Input.Label>
        <Input.Field
          as='textarea'
          name='message'
          rows={4}
          value={formData.message}
          onChange={(e) => setFormData({ ...formData, message: e.target.value })}
        />
        <Input.ErrorMessage>{errors.message}</Input.ErrorMessage>
      </Input.Root>

      <button type='submit'>Send Message</button>
    </form>
  );
}
```

## API Reference

### Input / Input.Root

The root context provider that wraps all compound input parts. `Input` and `Input.Root` are the same component — the difference is only import/notation style. Renders a `<div>` by default and exposes an `InputContext` that all child components consume.

**Props**

| Name         | Type                      | Default     | Description                                                          |
| ------------ | ------------------------- | ----------- | -------------------------------------------------------------------- |
| `id?`        | `string`                  | `undefined` | Base ID used to derive sub-element IDs. Auto-generated when omitted. |
| `as?`        | `React.ElementType`       | `'div'`     | Element type for the root wrapper                                    |
| `ref?`       | `React.Ref<T>`            | `undefined` | Ref for the root wrapper element                                     |
| `children`   | `React.ReactNode`         | -           | Compound input elements                                              |
| `isInvalid?` | `boolean`                 | `false`     | Validation state propagated to all compound parts                    |
| `disabled?`  | `boolean`                 | `false`     | Disabled state propagated to all compound parts                      |
| `required?`  | `boolean`                 | `false`     | Required state propagated to all compound parts                      |
| `readOnly?`  | `boolean`                 | `false`     | Read-only state propagated to all compound parts                     |
| `...props`   | `React.ComponentProps<T>` | -           | All standard HTML attributes for the root element                    |

**HTML Attributes**

| Attribute       | Value               | Purpose                    |
| --------------- | ------------------- | -------------------------- |
| `data-invalid`  | `""` \| `undefined` | Indicates validation state |
| `data-disabled` | `""` \| `undefined` | Indicates disabled state   |
| `data-required` | `""` \| `undefined` | Indicates required state   |
| `data-readonly` | `""` \| `undefined` | Indicates read-only state  |

### Input.Field

The core input element with polymorphic rendering support. Handles focus states, validation attributes, and ARIA associations automatically.

**Props**

| Name         | Type                                             | Default     | Description                            |
| ------------ | ------------------------------------------------ | ----------- | -------------------------------------- |
| `as?`        | `React.ElementType`                              | `'input'`   | Element type for polymorphic rendering |
| `ref?`       | `React.ComponentPropsWithRef<T>['ref']`          | `undefined` | Ref for the input element              |
| `autoFocus?` | `boolean`                                        | `false`     | Whether to focus the input on mount    |
| `onFocus?`   | `(event: React.FocusEvent<HTMLElement>) => void` | `undefined` | Focus event handler                    |
| `onBlur?`    | `(event: React.FocusEvent<HTMLElement>) => void` | `undefined` | Blur event handler                     |

**Events**

| Name       | Parameters                                | Description         | When Triggered                           |
| ---------- | ----------------------------------------- | ------------------- | ---------------------------------------- |
| `onFocus`  | `(event: React.FocusEvent<HTMLElement>)`  | Input gains focus   | User clicks or tabs to input             |
| `onBlur`   | `(event: React.FocusEvent<HTMLElement>)`  | Input loses focus   | User clicks away or tabs to next element |
| `onChange` | `(event: React.ChangeEvent<HTMLElement>)` | Input value changes | User types or modifies input content     |

**HTML Attributes**

| Attribute        | Value               | Purpose                                                                      |
| ---------------- | ------------------- | ---------------------------------------------------------------------------- |
| `id`             | `string`            | Unique field identifier; auto-assigned from context when inside `Input.Root` |
| `data-focused`   | `""` \| `undefined` | Indicates focus state                                                        |
| `data-autofocus` | `""` \| `undefined` | Indicates auto-focus state                                                   |
| `data-disabled`  | `""` \| `undefined` | Indicates disabled state                                                     |
| `data-required`  | `""` \| `undefined` | Indicates required state                                                     |
| `data-readonly`  | `""` \| `undefined` | Indicates read-only state                                                    |

### Input.Label

The label element that provides accessible labeling for the input field. When used inside `Input.Root`, the `id` and `htmlFor` attributes are set automatically from context.

**Props**

| Name          | Type                          | Default     | Description                                                  |
| ------------- | ----------------------------- | ----------- | ------------------------------------------------------------ |
| `as?`         | `React.ElementType`           | `'label'`   | Polymorphic element type                                     |
| `isOptional?` | `boolean`                     | `false`     | Marks the label as optional (sets `data-optional` attribute) |
| `children`    | `React.ReactNode`             | -           | Label content                                                |
| `ref?`        | `React.Ref<HTMLLabelElement>` | `undefined` | Ref for the label element                                    |

**Auto-set from context**: When used inside `Input.Root`, the following are automatically set from context:

- `id` — set to `${rootId}-label`
- `htmlFor` — set to `${rootId}-field`, linking the label to `Input.Field`
- `disabled` — mirrors `Input.Root`'s `disabled` prop → sets `data-disabled`
- `required` — mirrors `Input.Root`'s `required` prop → sets `data-required`
- `readOnly` — mirrors `Input.Root`'s `readOnly` prop → sets `data-readonly`
- `isInvalid` — mirrors `Input.Root`'s `isInvalid` prop → sets `data-invalid`

These data attributes can be used as styling hooks without manually passing props.

### Input.Description

The description element that provides helper text for the input field. The `id` is set automatically from context and referenced by `aria-describedby` on `Input.Field`.

**Props**

| Name       | Type                        | Default     | Description                     |
| ---------- | --------------------------- | ----------- | ------------------------------- |
| `as?`      | `React.ElementType`         | `'div'`     | Polymorphic element type        |
| `children` | `React.ReactNode`           | -           | Description content             |
| `ref?`     | `React.Ref<HTMLDivElement>` | `undefined` | Ref for the description element |

### Input.ErrorMessage

The error message element. Renders `null` when the parent `Input.Root` has `isInvalid={false}`. When visible, its `id` is referenced by `aria-describedby` on `Input.Field` (replacing the description reference).

**Props**

| Name       | Type                        | Default     | Description               |
| ---------- | --------------------------- | ----------- | ------------------------- |
| `as?`      | `React.ElementType`         | `'div'`     | Polymorphic element type  |
| `children` | `React.ReactNode`           | -           | Error content             |
| `ref?`     | `React.Ref<HTMLDivElement>` | `undefined` | Ref for the error element |

**HTML Attributes**

| Attribute   | Value         | Purpose                                                 |
| ----------- | ------------- | ------------------------------------------------------- |
| `role`      | `"alert"`     | Causes screen readers to announce the error immediately |
| `aria-live` | `"assertive"` | Ensures errors are announced as they appear             |

## Keyboard Interactions

Complete keyboard behavior for the Input component:

| Key           | Action            | Context       | Notes                                                    |
| ------------- | ----------------- | ------------- | -------------------------------------------------------- |
| `Tab`         | Navigate forward  | Always        | Moves focus to the input field or next focusable element |
| `Shift + Tab` | Navigate backward | Always        | Moves focus to previous focusable element                |
| `Enter`       | Submit form       | Form context  | Submits parent form when input is focused                |
| `Backspace`   | Delete character  | Text input    | Removes character before cursor                          |
| `Delete`      | Delete character  | Text input    | Removes character after cursor                           |
| `Home`        | Move to start     | Text input    | Moves cursor to beginning of text                        |
| `End`         | Move to end       | Text input    | Moves cursor to end of text                              |
| `ArrowLeft`   | Move left         | Text input    | Moves cursor one character left                          |
| `ArrowRight`  | Move right        | Text input    | Moves cursor one character right                         |
| `Ctrl + A`    | Select all        | Text input    | Selects all text in input                                |
| `Ctrl + C`    | Copy              | Text selected | Copies selected text to clipboard                        |
| `Ctrl + X`    | Cut               | Text selected | Cuts selected text to clipboard                          |
| `Ctrl + V`    | Paste             | Text input    | Pastes text from clipboard                               |
| `Ctrl + Z`    | Undo              | Text input    | Undoes last edit operation                               |
