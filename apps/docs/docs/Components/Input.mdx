# Input

A headless input component providing accessible form input primitives with compound pattern support and zero styling opinions.

## Features

- ✅ Text input and textarea support with polymorphic rendering
- ✅ Validation states (invalid, valid) with automatic ARIA handling
- ✅ Interactive states (disabled, required, focused) with proper attributes
- ✅ Error message display with role="alert" for screen reader announcements
- ✅ Helper text support with automatic ARIA associations
- ✅ Form integration with proper name and validation attribute support
- ✅ Focus management with visual focus indicators
- ✅ Context-based state management across compound components

## Installation

```tsx
import { Input } from '@turkish-technology/glide'
```

## Anatomy

The Input component follows a compound component pattern with context-based state management:

```tsx
<Input.Root>
  <Input.Label />
  <Input.Field />
  <Input.Description />
  <Input.ErrorMessage />
</Input.Root>
```

- **Input.Root**: Context provider that manages validation, disabled, and required states
- **Input.Field**: Core input element with polymorphic support (input/textarea)
- **Input.Label**: Associated label element with automatic ID linking
- **Input.Description**: Helper text element for additional guidance
- **Input.ErrorMessage**: Error announcement element with role="alert"

### Form Integration

Complete form example with validation, submission, and error handling.

<LiveCode 
  code={`function ContactForm() {
  const [formData, setFormData] = React.useState({
    name: '',
    email: '',
    message: ''
  });
  const [errors, setErrors] = React.useState({});

  const validateForm = () => {
    const newErrors = {};
    
    if (!formData.name) newErrors.name = 'Name is required';
    if (!formData.email) newErrors.email = 'Email is required';
    else if (!/^[^\\s@]+@[^\\s@]+\\.[^\\s@]+$/.test(formData.email)) {
      newErrors.email = 'Please enter a valid email';
    }
    if (!formData.message) newErrors.message = 'Message is required';
    
    setErrors(newErrors);
    return Object.keys(newErrors).length === 0;
  };

  const handleSubmit = (e) => {
    e.preventDefault();
    if (validateForm()) {
      console.log('Form submitted:', formData);
      alert('Form submitted successfully!');
    }
  };

  const formStyle = {
    display: 'flex',
    flexDirection: 'column',
    gap: '16px',
    maxWidth: '400px'
  };

  const inputRootStyle = (hasError) => ({
    padding: '12px',
    border: \`1px solid \${hasError ? '#ff6b6b' : '#e5e5e5'}\`,
    borderRadius: '6px'
  });

  const labelStyle = {
    display: 'block',
    marginBottom: '6px',
    fontSize: '14px',
    fontWeight: '500'
  };

  const fieldStyle = (hasError) => ({
    width: '100%',
    padding: '8px 12px',
    border: \`1px solid \${hasError ? '#ff6b6b' : '#ccc'}\`,
    borderRadius: '4px',
    fontSize: '14px'
  });

  const errorStyle = {
    marginTop: '4px',
    fontSize: '12px',
    color: '#ff6b6b'
  };

  const buttonStyle = {
    padding: '12px 24px',
    backgroundColor: '#007bff',
    color: 'white',
    border: 'none',
    borderRadius: '4px',
    fontSize: '14px',
    fontWeight: '500',
    cursor: 'pointer',
    marginTop: '8px'
  };

  return (
    <form onSubmit={handleSubmit} style={formStyle} noValidate>
      <Input.Root isInvalid={!!errors.name} isRequired style={inputRootStyle(!!errors.name)}>
        <Input.Label style={labelStyle}>Full Name</Input.Label>
        <Input.Field
          name="name"
          value={formData.name}
          onChange={(e) => setFormData({...formData, name: e.target.value})}
          style={fieldStyle(!!errors.name)}
        />
        <Input.ErrorMessage style={errorStyle}>{errors.name}</Input.ErrorMessage>
      </Input.Root>

      <Input.Root isInvalid={!!errors.email} isRequired style={inputRootStyle(!!errors.email)}>
        <Input.Label style={labelStyle}>Email</Input.Label>
        <Input.Field
          type="email"
          name="email"
          value={formData.email}
          onChange={(e) => setFormData({...formData, email: e.target.value})}
          style={fieldStyle(!!errors.email)}
        />
        <Input.ErrorMessage style={errorStyle}>{errors.email}</Input.ErrorMessage>
      </Input.Root>

      <Input.Root isInvalid={!!errors.message} isRequired style={inputRootStyle(!!errors.message)}>
        <Input.Label style={labelStyle}>Message</Input.Label>
        <Input.Field
          as="textarea"
          name="message"
          rows={4}
          value={formData.message}
          onChange={(e) => setFormData({...formData, message: e.target.value})}
          style={{...fieldStyle(!!errors.message), resize: 'vertical', fontFamily: 'inherit'}}
        />
        <Input.ErrorMessage style={errorStyle}>{errors.message}</Input.ErrorMessage>
      </Input.Root>

      <button type="submit" style={buttonStyle}>Send Message</button>
    </form>
  );
}`}
/>

## API Reference

### Input.Root

The root container that provides context and state management for all input compound components. Manages validation, disabled, and required states with proper ARIA coordination.

**Props**

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `ReactNode` | - | Compound input elements |
| `isInvalid?` | `boolean` | `false` | Input validation state |
| `isDisabled?` | `boolean` | `false` | Input disabled state |
| `isRequired?` | `boolean` | `false` | Input required state |

**ARIA Attributes**

| Attribute | Value | Purpose | Applied To |
|-----------|-------|---------|------------|
| `data-glide-input` | `""` | Identifies input root container | Root element |
| `data-invalid` | `""` \| `undefined` | Indicates validation state | Root element |
| `data-disabled` | `""` \| `undefined` | Indicates disabled state | Root element |
| `data-required` | `""` \| `undefined` | Indicates required state | Root element |

### Input.Field

The core input element with polymorphic rendering support. Handles focus states, validation attributes, and ARIA associations automatically.

**Props**

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `as?` | `ElementType` | `'input'` | Element type for polymorphic rendering |
| `ref?` | `React.ComponentPropsWithRef<T>['ref']` | `undefined` | Ref for the input element |
| `onFocus?` | `(event: React.FocusEvent<HTMLElement>) => void` | `undefined` | Focus event handler |
| `onBlur?` | `(event: React.FocusEvent<HTMLElement>) => void` | `undefined` | Blur event handler |

**Events**

| Name | Parameters | Description | When Triggered |
|------|------------|-------------|----------------|
| `onFocus` | `(event: React.FocusEvent<HTMLElement>)` | Input gains focus | User clicks or tabs to input |
| `onBlur` | `(event: React.FocusEvent<HTMLElement>)` | Input loses focus | User clicks away or tabs to next element |
| `onChange` | `(event: React.ChangeEvent<HTMLElement>)` | Input value changes | User types or modifies input content |

**ARIA Attributes**

| Attribute | Value | Purpose | Applied To |
|-----------|-------|---------|------------|
| `id` | `string` | Unique field identifier | Field element |
| `aria-labelledby` | `string` | References associated label | Field element |
| `aria-describedby` | `string` | References description or error | Field element |
| `aria-required` | `boolean` | Indicates required state | Field element |
| `aria-invalid` | `boolean` | Indicates validation state | Field element |
| `data-glide-input-field` | `""` | Identifies input field element | Field element |
| `data-focused` | `""` \| `undefined` | Indicates focus state | Field element |

### Input.Label

The label element that provides accessible labeling for the input field. Automatically associates with the input field via ARIA.

**Props**

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `ReactNode` | - | Label content |
| `ref?` | `React.Ref<HTMLLabelElement>` | `undefined` | Ref for the label element |

**ARIA Attributes**

| Attribute | Value | Purpose | Applied To |
|-----------|-------|---------|------------|
| `id` | `string` | Unique label identifier | Label element |
| `htmlFor` | `string` | Associates with input field | Label element |
| `data-glide-input-label` | `""` | Identifies input label element | Label element |

### Input.Description

The description element that provides helper text for the input field. Automatically linked to the input field via aria-describedby.

**Props**

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `ReactNode` | - | Description content |
| `ref?` | `React.Ref<HTMLDivElement>` | `undefined` | Ref for the description element |

**ARIA Attributes**

| Attribute | Value | Purpose | Applied To |
|-----------|-------|---------|------------|
| `id` | `string` | Unique description identifier | Description element |
| `data-glide-input-description` | `""` | Identifies input description element | Description element |

### Input.ErrorMessage

The error message element that announces validation errors to screen readers. Uses role="alert" for immediate announcement and is automatically linked to the input field.

**Props**

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `ReactNode` | - | Error content |
| `ref?` | `React.Ref<HTMLDivElement>` | `undefined` | Ref for the error element |

**Events**

| Name | Parameters | Description | When Triggered |
|------|------------|-------------|----------------|
| `onMount` | `()` | Error message becomes visible | Input becomes invalid |
| `onUnmount` | `()` | Error message becomes hidden | Input becomes valid |

**ARIA Attributes**

| Attribute | Value | Purpose | Applied To |
|-----------|-------|---------|------------|
| `id` | `string` | Unique error identifier | Error element |
| `role` | `"alert"` | Announces errors immediately | Error element |
| `aria-live` | `"assertive"` | Forces screen reader announcement | Error element |
| `data-glide-input-error` | `""` | Identifies input error element | Error element |

## Keyboard Interactions

Complete keyboard behavior for the Input component:

| Key | Action | Context | Notes |
|-----|--------|---------|-------|
| `Tab` | Navigate forward | Always | Moves focus to the input field or next focusable element |
| `Shift + Tab` | Navigate backward | Always | Moves focus to previous focusable element |
| `Enter` | Submit form | Form context | Submits parent form when input is focused |
| `Backspace` | Delete character | Text input | Removes character before cursor |
| `Delete` | Delete character | Text input | Removes character after cursor |
| `Home` | Move to start | Text input | Moves cursor to beginning of text |
| `End` | Move to end | Text input | Moves cursor to end of text |
| `ArrowLeft` | Move left | Text input | Moves cursor one character left |
| `ArrowRight` | Move right | Text input | Moves cursor one character right |
| `Ctrl + A` | Select all | Text input | Selects all text in input |
| `Ctrl + C` | Copy | Text selected | Copies selected text to clipboard |
| `Ctrl + X` | Cut | Text selected | Cuts selected text to clipboard |
| `Ctrl + V` | Paste | Text input | Pastes text from clipboard |
| `Ctrl + Z` | Undo | Text input | Undoes last edit operation |
