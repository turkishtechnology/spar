# Checkbox

Headless checkbox component providing accessible form input primitives with zero styling opinions. Pair it with the [Field](./Field.mdx) primitive to get label, description, and error-message wiring with coordinated ARIA IDs.

The live demo shows the recommended pattern: a `Field` wrapper supplying label, helper text, and error message wiring around the `Checkbox` primitive.

## Features

- ✅ **Field integration** - Inherits `invalid`, `disabled`, `required`, `readOnly` from parent `<Field>`
- ✅ **Dual-state and tri-state support** - Boolean checked/unchecked and indeterminate states
- ✅ **Form integration** - Hidden input for native form submission with name/value attributes
- ✅ **Controlled and uncontrolled modes** - Works with or without external state management
- ✅ **Render props pattern** - Access to internal state via children function
- ✅ **Polymorphic rendering** - Customizable root element via `as` prop
- ✅ **Interaction states** - Focus, hover, pressed, and disabled state tracking
- ✅ **Auto-focus support** - Focus on mount capability
- ✅ **Coordinated ARIA IDs** - Automatic `aria-labelledby`, `aria-describedby` wiring with Field

### Structure

```tsx
<Checkbox>
  {({ checked }) => (
    <span className='indicator'>{checked && '✓'}</span>
  )}
</Checkbox>
```

**With Field:**

```tsx
<Field.Root required invalid>
  <div className='checkbox-row'>
    <Checkbox name="fieldName">
      {({ checked }) => (
        <span className='indicator'>{checked && '✓'}</span>
      )}
    </Checkbox>
    <Field.Label>Label text</Field.Label>
  </div>
  <Field.Description>Description text</Field.Description>
  <Field.ErrorMessage>Error text</Field.ErrorMessage>
</Field.Root>
```

**Data Flow:**

- User interaction (click/keyboard) → State change → ARIA updates → Form submission (if form context)
- Checkbox manages internal checked state (controlled or uncontrolled)
- When inside a Field, Checkbox inherits `invalid`, `disabled`, `required`, `readOnly` automatically
- Hidden input synchronizes with checkbox state for native form integration
- ARIA attributes (`aria-labelledby`, `aria-describedby`) are automatically wired from Field's coordinated IDs

## Code Examples

### Basic Usage

Use a render function when you want the visual checkmark to appear only in the checked state.

```tsx
function BasicCheckbox() {
  return (
    <Checkbox>
      {({ checked }) => (
        <span className='indicator'>{checked ? '✓' : ''}</span>
      )}
    </Checkbox>
  );
}
```

### Controlled State

Manage the checked value in parent state when the checkbox needs to stay in sync with other UI.

```tsx {2,6-11}
function ControlledCheckbox() {
  const [isChecked, setIsChecked] = useState<boolean>(false);

  return (
    <Field.Root>
      <div className='checkbox-row'>
        <Checkbox checked={isChecked} onChange={setIsChecked}>
          {({ checked }) => <span className='indicator'>{checked ? '✓' : ''}</span>}
        </Checkbox>
        <Field.Label>Subscribe to newsletter</Field.Label>
      </div>
    </Field.Root>
  );
}
```

### Indeterminate State

Use the indeterminate state for mixed selections, such as a parent checkbox that represents partially selected children.

```tsx {2,4-12}
function IndeterminateCheckbox() {
  const [checked, setChecked] = useState<CheckedState>('indeterminate');

  const handleChange = (newChecked: CheckedState) => {
    if (newChecked === true) {
      setChecked(false);
    } else if (newChecked === false) {
      setChecked('indeterminate');
    } else {
      setChecked(true);
    }
  };

  return (
    <Field.Root>
      <div className='checkbox-row'>
        <Checkbox checked={checked} onChange={handleChange}>
          {({ checked }) => (
            <span className='indicator'>
              {checked === true && '✓'}
              {checked === 'indeterminate' && '−'}
            </span>
          )}
        </Checkbox>
        <Field.Label>Select all items</Field.Label>
      </div>
    </Field.Root>
  );
}
```

### Form Integration

Provide `name` and `value` when the checkbox should participate in native form submission.

```tsx {3-4,8-9}
function FormCheckbox() {
  return (
    <form>
      <Field.Root required>
        <div className='checkbox-row'>
          <Checkbox name='terms' value='accepted'>
            {({ checked }) => <span className='indicator'>{checked ? '✓' : ''}</span>}
          </Checkbox>
          <Field.Label>I agree to the terms</Field.Label>
        </div>
      </Field.Root>

      <Field.Root>
        <div className='checkbox-row'>
          <Checkbox name='newsletter' value='subscribed' defaultChecked={true}>
            {({ checked }) => <span className='indicator'>{checked ? '✓' : ''}</span>}
          </Checkbox>
          <Field.Label>Subscribe to newsletter</Field.Label>
        </div>
      </Field.Root>

      <button type='submit'>Submit</button>
    </form>
  );
}
```

### Field Integration

Wrap a Checkbox in a `<Field.Root>` to automatically inherit validation state and wire ARIA relationships.

```tsx {4-5,11-12}
function FieldCheckbox() {
  const [accepted, setAccepted] = useState(false);

  return (
    <div>
      <Field.Root required invalid={!accepted}>
        <div className='checkbox-row'>
          <Checkbox name='terms' checked={accepted} onChange={setAccepted}>
            {({ checked }) => <span className='indicator'>{checked ? '✓' : ''}</span>}
          </Checkbox>
          <Field.Label>Terms & Conditions</Field.Label>
        </div>
        <Field.Description>You must accept to proceed.</Field.Description>
        <Field.ErrorMessage>Please accept the terms.</Field.ErrorMessage>
      </Field.Root>

      <Field.Root disabled>
        <div className='checkbox-row'>
          <Checkbox name='archive'>
            {({ checked }) => <span className='indicator'>{checked ? '✓' : ''}</span>}
          </Checkbox>
          <Field.Label>Archived Option</Field.Label>
        </div>
        <Field.Description>This option is currently unavailable.</Field.Description>
      </Field.Root>
    </div>
  );
}
```

### Render Props Pattern

The render-props API exposes interaction state so you can build custom visuals without reimplementing behavior.

```tsx {3-8}
function RenderPropsCheckbox() {
  return (
    <Checkbox defaultChecked={false}>
      {({ checked, disabled, invalid, required, isFocused, isHovered, isPressed }) => (
        <div>
          <span>{checked ? '✓' : '☐'}</span>
          <span>Invalid: {invalid ? 'Yes' : 'No'}</span>
          <span>Focused: {isFocused ? 'Yes' : 'No'}</span>
          <span>Hovered: {isHovered ? 'Yes' : 'No'}</span>
          <span>Pressed: {isPressed ? 'Yes' : 'No'}</span>
        </div>
      )}
    </Checkbox>
  );
}
```

### Disabled State

Disabled checkboxes remain readable but do not respond to pointer or keyboard input.

```tsx {2,6,10}
function DisabledCheckbox() {
  return (
    <div>
      <Checkbox disabled>
        {({ checked }) => <span className='indicator'>{checked ? '✓' : ''}</span>}
      </Checkbox>
      <Checkbox disabled defaultChecked={true}>
        {({ checked }) => <span className='indicator'>{checked ? '✓' : ''}</span>}
      </Checkbox>
      <Checkbox disabled checked='indeterminate'>
        {({ checked }) => <span className='indicator'>{checked === 'indeterminate' ? '−' : ''}</span>}
      </Checkbox>
    </div>
  );
}
```

### Custom Element with Polymorphic Rendering

Render the checkbox as another element when your layout needs a custom wrapper.

```tsx {3}
function CustomElementCheckbox() {
  return (
    <Checkbox as='button'>
      {({ checked }) => <span className='indicator'>{checked ? '✓' : ''}</span>}
    </Checkbox>
  );
}
```

### Accessibility Enhanced with Field

Combine Field integration for automatic ARIA wiring with validation feedback.

```tsx {2,6-12}
function AccessibleCheckbox() {
  const [hasError, setHasError] = useState(true);

  return (
    <Field.Root required invalid={hasError}>
      <div className='checkbox-row'>
        <Checkbox onChange={(checked) => setHasError(!checked)}>
          {({ checked }) => <span className='indicator'>{checked ? '✓' : ''}</span>}
        </Checkbox>
        <Field.Label>Agreement</Field.Label>
      </div>
      <Field.Description>This field is required to continue.</Field.Description>
      <Field.ErrorMessage>⚠️ This field is required</Field.ErrorMessage>
    </Field.Root>
  );
}
```

## API Reference

### Checkbox

A self-contained headless checkbox component with full accessibility and Field integration. When nested inside a `<Field>`, it reads the Field's state automatically.

**Props**

| Name              | Type                                                                   | Default          | Description                                                                       |
| ----------------- | ---------------------------------------------------------------------- | ---------------- | --------------------------------------------------------------------------------- |
| `as?`             | `React.ElementType`                                                    | `'span'`         | The element or component to render as                                             |
| `ref?`            | `React.Ref<HTMLElement>`                                               | `undefined`      | Ref to the underlying DOM element                                                 |
| `checked?`        | `CheckedState`                                                         | `undefined`      | Controlled checked state. When provided, component operates in controlled mode    |
| `defaultChecked?` | `CheckedState`                                                         | `false`          | Default checked state for uncontrolled usage                                      |
| `onChange?`       | `(checked: CheckedState) => void`                                      | `undefined`      | Callback fired when the checked state changes                                     |
| `disabled?`       | `boolean`                                                              | `false`          | Disabled state - prevents interaction and is properly announced to screen readers |
| `name?`           | `string`                                                               | `undefined`      | Name attribute for form submission                                                |
| `value?`          | `string`                                                               | `'on'`           | Value sent in form data when checked                                              |
| `form?`           | `string`                                                               | `undefined`      | ID of the form this checkbox belongs to                                           |
| `required?`       | `boolean`                                                              | `false`          | Required state for form validation                                                |
| `readOnly?`       | `boolean`                                                              | `false`          | Read-only state - prevents interaction                                            |
| `invalid?`      | `boolean`                                                              | `false`          | Invalid/error state. Inherited from Field unless explicitly overridden            |
| `autoFocus?`      | `boolean`                                                              | `false`          | Auto-focus on mount                                                               |
| `children?`       | `React.ReactNode \| ((state: CheckboxRenderProps) => React.ReactNode)` | `undefined`      | Content to display, or render props function                                      |
| `id?`             | `string`                                                               | `auto-generated` | Unique identifier for the checkbox                                                |
| `className?`      | `string`                                                               | `undefined`      | CSS class name                                                                    |
| `style?`          | `React.CSSProperties`                                                  | `undefined`      | Inline styles                                                                     |
| `tabIndex?`       | `number`                                                               | `0`              | Tab index for keyboard navigation                                                 |

#### CheckboxRenderProps

When using the render props pattern, the following state properties are passed to the children function:

| Property     | Type                              | Description                                                   |
| ------------ | --------------------------------- | ------------------------------------------------------------- |
| `checked`    | `CheckedState`                    | Current checked state (`true`, `false`, or `'indeterminate'`) |
| `setChecked` | `(checked: CheckedState) => void` | Function to programmatically set the checked state            |
| `disabled`   | `boolean`                         | Whether the checkbox is disabled                              |
| `readOnly`   | `boolean`                         | Whether the checkbox is read-only                             |
| `required`   | `boolean`                         | Whether the checkbox is required                              |
| `invalid`  | `boolean`                         | Whether the checkbox is in an invalid/error state             |
| `isFocused`  | `boolean`                         | Whether the checkbox currently has focus                      |
| `isHovered`  | `boolean`                         | Whether the checkbox is being hovered                         |
| `isPressed`  | `boolean`                         | Whether the checkbox is being pressed                         |

**Events**

| Name        | Parameters                     | Description           | When Triggered                                     |
| ----------- | ------------------------------ | --------------------- | -------------------------------------------------- |
| `onChange`  | `(checked: CheckedState)`      | Checked state changes | User clicks, presses Space, or programmatic change |
| `onClick`   | `(event: React.MouseEvent)`    | Element clicked       | Mouse click on checkbox                            |
| `onKeyDown` | `(event: React.KeyboardEvent)` | Key pressed           | Keyboard interaction (Space toggles)               |
| `onFocus`   | `(event: React.FocusEvent)`    | Element gains focus   | Focus enters checkbox                              |
| `onBlur`    | `(event: React.FocusEvent)`    | Element loses focus   | Focus leaves checkbox                              |

**Data Attributes**

| Attribute            | Value | Purpose                                     |
| -------------------- | ----- | ------------------------------------------- |
| `data-checked`       | `""`  | Present when `checked` is `true`            |
| `data-indeterminate` | `""`  | Present when `checked` is `'indeterminate'` |
| `data-disabled`      | `""`  | Present when `disabled` is `true`           |
| `data-readonly`      | `""`  | Present when `readOnly` is `true`           |
| `data-required`      | `""`  | Present when `required` is `true`           |
| `data-invalid`       | `""`  | Present when `invalid` is `true`          |
| `data-focus`         | `""`  | Present when the checkbox has focus         |
| `data-hover`         | `""`  | Present when the checkbox is hovered        |
| `data-active`        | `""`  | Present when the checkbox is being pressed  |

## Keyboard Interactions

| Key           | Action               | Context         | Notes                                        |
| ------------- | -------------------- | --------------- | -------------------------------------------- |
| `Tab`         | Navigate to checkbox | Always          | Moves focus to the checkbox                  |
| `Shift + Tab` | Navigate backward    | Always          | Moves focus away from checkbox               |
| `Space`       | Toggle checked state | Focused         | Primary activation method for checkboxes     |
| `Enter`       | Submit form          | In form context | Does not toggle state, submits parent form   |

**Note**: The checkbox follows WCAG guidelines where Space is the primary toggle key, while Enter submits forms without changing checkbox state.
