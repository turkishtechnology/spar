# Checkbox

Headless checkbox component providing accessibility and behavior without styling. Supports dual-state and tri-state functionality with complete ARIA compliance.

## Features

- ✅ **Dual-state and tri-state support** - Boolean checked/unchecked and indeterminate states
- ✅ **Form integration** - Hidden input for native form submission with name/value attributes
- ✅ **Controlled and uncontrolled modes** - Works with or without external state management
- ✅ **Render props pattern** - Access to internal state via children function
- ✅ **Polymorphic rendering** - Customizable root element via `as` prop
- ✅ **Interaction states** - Focus, hover, pressed, and disabled state tracking
- ✅ **Auto-focus support** - Focus on mount capability
- ✅ **Screen reader announcements** - Proper ARIA labels and state communication

## Installation

## Anatomy

The Checkbox component is a single, self-contained element that manages its own state and accessibility:

```tsx
<Checkbox>
  {/* Optional children content or render function */}
</Checkbox>
```

**Data Flow:**
- User interaction (click/keyboard) → State change → ARIA updates → Form submission (if form context)

### Indeterminate State

```tsx
function IndeterminateCheckbox() {
  const [checked, setChecked] = useState('indeterminate');
  
  const handleChange = (newChecked) => {
    // Cycle: indeterminate → true → false → indeterminate
    if (newChecked === true) {
      setChecked(false);
    } else if (newChecked === false) {
      setChecked('indeterminate');
    } else {
      setChecked(true);
    }
  };
  
  const getIcon = () => {
    if (checked === true) return '✓';
    if (checked === 'indeterminate') return '−';
    return '';
  };
  
  return (
    <div style={{ display: 'flex', alignItems: 'center', gap: '8px', padding: '16px' }}>
      <Checkbox 
        checked={checked}
        onChange={handleChange}
        style={{
          width: '16px',
          height: '16px',
          border: '2px solid #007acc',
          borderRadius: '2px',
          backgroundColor: checked === false ? 'transparent' : '#007acc',
          cursor: 'pointer',
          display: 'inline-flex',
          alignItems: 'center',
          justifyContent: 'center'
        }}
      >
        <span style={{ color: 'white', fontSize: '12px', lineHeight: 1 }}>
          {getIcon()}
        </span>
      </Checkbox>
      <label 
        style={{ cursor: 'pointer', userSelect: 'none' }}
        onClick={() => handleChange(checked)}
      >
        Select all items (Click to cycle states)
      </label>
    </div>
  );
}
```

## API Reference

### Checkbox

A headless checkbox component that provides complete accessibility and behavior without any styling opinions. Supports both controlled and uncontrolled usage patterns with optional tri-state functionality.

**Props**

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `as?` | `ElementType` | `'span'` | The element or component to render as |
| `ref?` | `React.Ref<HTMLElement>` | `undefined` | Ref to the underlying DOM element |
| `checked?` | `CheckedState` | `undefined` | Controlled checked state. When provided, component becomes controlled |
| `defaultChecked?` | `CheckedState` | `false` | Default checked state for uncontrolled usage |
| `onChange?` | `(checked: CheckedState) => void` | `undefined` | Callback fired when checked state changes |
| `isDisabled?` | `boolean` | `false` | Whether the checkbox is disabled |
| `isReadOnly?` | `boolean` | `false` | Whether the checkbox is read-only |
| `isRequired?` | `boolean` | `false` | Whether the checkbox is required in forms |
| `name?` | `string` | `undefined` | Name attribute for form submission |
| `value?` | `string` | `'on'` | Value sent in form data when checked |
| `form?` | `string` | `undefined` | ID of the form this checkbox belongs to |
| `shouldAutoFocus?` | `boolean` | `false` | Whether to focus the checkbox on mount |
| `children?` | `ReactNode \| ((state: CheckboxRenderProps) => ReactNode)` | `undefined` | Children content or render function |
| `id?` | `string` | `auto-generated` | Unique identifier for the checkbox |
| `className?` | `string` | `undefined` | CSS class name |
| `style?` | `React.CSSProperties` | `undefined` | Inline styles |
| `tabIndex?` | `number` | `0` | Tab index for keyboard navigation |

**Events**

| Name | Parameters | Description | When Triggered |
|------|------------|-------------|----------------|
| `onChange` | `(checked: CheckedState)` | Checked state changes | User clicks, presses Space, or programmatic change |
| `onClick` | `(event: MouseEvent)` | Element clicked | Mouse click on checkbox |
| `onKeyDown` | `(event: KeyboardEvent)` | Key pressed | Keyboard interaction (Space toggles) |
| `onFocus` | `(event: FocusEvent)` | Element gains focus | Focus enters checkbox |
| `onBlur` | `(event: FocusEvent)` | Element loses focus | Focus leaves checkbox |

**ARIA Attributes**

| Attribute | Value | Purpose | Applied To |
|-----------|-------|---------|------------|
| `role` | `"checkbox"` | Identifies element as checkbox | Root element |
| `aria-checked` | `boolean \| "mixed"` | Indicates checked state (mixed for indeterminate) | Root element |
| `aria-disabled` | `"true" \| undefined` | Indicates disabled state | Root element |
| `aria-invalid` | `"true" \| undefined` | Indicates validation error state | Root element |
| `aria-required` | `"true" \| undefined` | Indicates required field | Root element |
| `tabindex` | `number` | Controls keyboard focus (-1 when disabled) | Root element |

## Keyboard Interactions

Complete keyboard behavior for the Checkbox component:

| Key | Action | Context | Notes |
|-----|--------|---------|-------|
| `Tab` | Navigate to checkbox | Always | Moves focus to the checkbox |
| `Shift + Tab` | Navigate backward | Always | Moves focus away from checkbox |
| `Space` | Toggle checked state | Focused | Primary activation method for checkboxes |
| `Enter` | Submit form | In form context | Does not toggle state, submits parent form |

**Note**: The checkbox follows WCAG guidelines where Space is the primary toggle key, while Enter submits forms without changing checkbox state.
