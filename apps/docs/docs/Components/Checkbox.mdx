## Features

- ✅ **Dual-state and tri-state support** - Boolean checked/unchecked and indeterminate states
- ✅ **Form integration** - Hidden input for native form submission with name/value attributes
- ✅ **Controlled and uncontrolled modes** - Works with or without external state management
- ✅ **Render props pattern** - Access to internal state via children function
- ✅ **Polymorphic rendering** - Customizable root element via `as` prop
- ✅ **Interaction states** - Focus, hover, pressed, and disabled state tracking
- ✅ **Auto-focus support** - Focus on mount capability

### Structure

```tsx
<Checkbox>{/* Optional children content or render function */}</Checkbox>
```

**Data Flow:**

- User interaction (click/keyboard) → State change → ARIA updates → Form submission (if form context)
- Checkbox manages internal checked state (controlled or uncontrolled)
- Hidden input synchronizes with checkbox state for native form integration
- ARIA attributes automatically update to reflect current state

## Code Examples

### Basic Usage

```tsx
function BasicCheckbox() {
  return (
    <div>
      <Checkbox>{({ checked }) => checked && <span>✓</span>}</Checkbox>
      <label>Accept terms</label>
    </div>
  );
}
```

### Controlled State

```tsx
function ControlledCheckbox() {
  const [isChecked, setIsChecked] = useState<boolean>(false);

  return (
    <div>
      <Checkbox checked={isChecked} onChange={setIsChecked}>
        {isChecked && <span>✓</span>}
      </Checkbox>
      <label onClick={() => setIsChecked(!isChecked)}>Subscribe to newsletter</label>
    </div>
  );
}
```

### Indeterminate State

```tsx
function IndeterminateCheckbox() {
  const [checked, setChecked] = useState<CheckedState>('indeterminate');

  const handleChange = (newChecked: CheckedState) => {
    // Cycle: indeterminate → true → false → indeterminate
    if (newChecked === true) {
      setChecked(false);
    } else if (newChecked === false) {
      setChecked('indeterminate');
    } else {
      setChecked(true);
    }
  };

  const getIcon = () => {
    if (checked === true) return '✓';
    if (checked === 'indeterminate') return '−';
    return '';
  };

  return (
    <div>
      <Checkbox checked={checked} onChange={handleChange}>
        <span>{getIcon()}</span>
      </Checkbox>
      <label onClick={() => handleChange(checked)}>Select all items (Click to cycle states)</label>
    </div>
  );
}
```

### Accessibility Enhanced

```tsx
function AccessibleCheckbox() {
  const [hasError, setHasError] = useState(false);

  return (
    <div>
      <div>
        <Checkbox
          required
          aria-describedby={hasError ? 'error-message' : undefined}
          aria-invalid={hasError}
          onChange={(checked) => {
            setHasError(!checked);
          }}
        >
          {({ checked }) => checked && <span>✓</span>}
        </Checkbox>
        <label>Required field *</label>
      </div>

      {hasError && (
        <div id='error-message' role='alert'>
          ⚠️ This field is required
        </div>
      )}
    </div>
  );
}
```

## API Reference

### Checkbox

A headless checkbox component that provides complete accessibility and behavior without any styling opinions. Supports both controlled and uncontrolled usage patterns with optional tri-state functionality.

**Props**

| Name                | Type                                                                   | Default          | Description                                                                       |
| ------------------- | ---------------------------------------------------------------------- | ---------------- | --------------------------------------------------------------------------------- |
| `as?`               | `React.ElementType`                                                    | `'span'`         | The element or component to render as                                             |
| `ref?`              | `React.Ref<HTMLElement>`                                               | `undefined`      | Ref to the underlying DOM element                                                 |
| `checked?`          | `CheckedState`                                                         | `undefined`      | Controlled checked state. When provided, component operates in controlled mode    |
| `defaultChecked?`   | `CheckedState`                                                         | `false`          | Default checked state for uncontrolled usage                                      |
| `onChange?`         | `(checked: CheckedState) => void`                                      | `undefined`      | Callback fired when the checked state changes                                     |
| `disabled?`         | `boolean`                                                              | `false`          | Disabled state - prevents interaction and is properly announced to screen readers |
| `name?`             | `string`                                                               | `undefined`      | Name attribute for form submission                                                |
| `value?`            | `string`                                                               | `'on'`           | Value sent in form data when checked                                              |
| `form?`             | `string`                                                               | `undefined`      | ID of the form this checkbox belongs to                                           |
| `required?`         | `boolean`                                                              | `false`          | Required state for form validation                                                |
| `readOnly?`         | `boolean`                                                              | `false`          | Read-only state - prevents interaction                                            |
| `autoFocus?`        | `boolean`                                                              | `false`          | Auto-focus on mount                                                               |
| `aria-label?`       | `string`                                                               | `undefined`      | Accessible name for the checkbox. Required when checkbox has no visible label     |
| `aria-labelledby?`  | `string`                                                               | `undefined`      | ID of element that labels the checkbox                                            |
| `aria-describedby?` | `string`                                                               | `undefined`      | ID of element that describes the checkbox                                         |
| `children?`         | `React.ReactNode \| ((state: CheckboxRenderProps) => React.ReactNode)` | `undefined`      | Content to display inside the checkbox, or render props function                  |
| `id?`               | `string`                                                               | `auto-generated` | Unique identifier for the checkbox                                                |
| `className?`        | `string`                                                               | `undefined`      | CSS class name                                                                    |
| `style?`            | `React.CSSProperties`                                                  | `undefined`      | Inline styles                                                                     |
| `tabIndex?`         | `number`                                                               | `0`              | Tab index for keyboard navigation                                                 |

#### CheckboxRenderProps

When using the render props pattern, the following state properties are passed to the children function:

| Property     | Type                              | Description                                                   |
| ------------ | --------------------------------- | ------------------------------------------------------------- |
| `checked`    | `CheckedState`                    | Current checked state (`true`, `false`, or `'indeterminate'`) |
| `setChecked` | `(checked: CheckedState) => void` | Function to programmatically set the checked state            |
| `disabled`   | `boolean`                         | Whether the checkbox is disabled                              |
| `readOnly`   | `boolean`                         | Whether the checkbox is read-only                             |
| `isFocused`  | `boolean`                         | Whether the checkbox currently has focus                      |
| `isHovered`  | `boolean`                         | Whether the checkbox is being hovered                         |
| `isPressed`  | `boolean`                         | Whether the checkbox is being pressed                         |

**Events**

| Name        | Parameters                     | Description           | When Triggered                                     |
| ----------- | ------------------------------ | --------------------- | -------------------------------------------------- |
| `onChange`  | `(checked: CheckedState)`      | Checked state changes | User clicks, presses Space, or programmatic change |
| `onClick`   | `(event: React.MouseEvent)`    | Element clicked       | Mouse click on checkbox                            |
| `onKeyDown` | `(event: React.KeyboardEvent)` | Key pressed           | Keyboard interaction (Space toggles)               |
| `onFocus`   | `(event: React.FocusEvent)`    | Element gains focus   | Focus enters checkbox                              |
| `onBlur`    | `(event: React.FocusEvent)`    | Element loses focus   | Focus leaves checkbox                              |

**HTML Attributes**

| Attribute          | Value  | Purpose                                        |
| ------------------ | ------ | ---------------------------------------------- |
| `data-checked`     | `""`   | Present when `checked` is `true`               |
| `data-indeterminate` | `""` | Present when `checked` is `'indeterminate'`    |
| `data-disabled`    | `""`   | Present when `disabled` is `true`              |
| `data-readonly`    | `""`   | Present when `readOnly` is `true`              |
| `data-required`    | `""`   | Present when `required` is `true`              |
| `data-focus`       | `""`   | Present when the checkbox has focus            |
| `data-hover`       | `""`   | Present when the checkbox is hovered           |
| `data-active`      | `""`   | Present when the checkbox is being pressed     |

## Keyboard Interactions

Complete keyboard behavior for the Checkbox component:

| Key           | Action               | Context         | Notes                                      |
| ------------- | -------------------- | --------------- | ------------------------------------------ |
| `Tab`         | Navigate to checkbox | Always          | Moves focus to the checkbox                |
| `Shift + Tab` | Navigate backward    | Always          | Moves focus away from checkbox             |
| `Space`       | Toggle checked state | Focused         | Primary activation method for checkboxes   |
| `Enter`       | Submit form          | In form context | Does not toggle state, submits parent form |

**Note**: The checkbox follows WCAG guidelines where Space is the primary toggle key, while Enter submits forms without changing checkbox state.
