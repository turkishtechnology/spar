## Features

- ✅ **Explicit Association**: Links labels to form controls via `htmlFor` attribute
- ✅ **Implicit Association**: Supports wrapping controls for automatic association
- ✅ **State Indicators**: Built-in support for required, optional, and disabled states via data attributes
- ✅ **Polymorphic Rendering**: Render as any HTML element while maintaining label semantics
- ✅ **Ref Forwarding**: Direct access to the underlying DOM element
- ✅ **Type-Safe**: Full TypeScript support with strict typing

## Installation

```tsx
import { Label } from '@turkish-technology/spar';
```

### Structure

```tsx
<Label htmlFor='input-id'>Label Text</Label>
```

**Data Flow:**

- `Label` creates a semantic association with the form control via `htmlFor` attribute
- Clicking the label automatically focuses the associated input
- Screen readers announce the label text when the control receives focus
- State indicators (`required`, `isOptional`, `disabled`) are exposed as data attributes for styling

## Code Examples

### Basic Label with Form Control

The most common usage pattern with explicit association using `htmlFor`:

```tsx
function BasicExample() {
  return (
    <div>
      <Label htmlFor='email'>Email Address</Label>
      <input id='email' type='email' />
    </div>
  );
}
```

### Required Field Indicator

Use `required` to mark fields as required. The label exposes a `data-required` attribute for styling hooks:

```tsx
function RequiredFieldExample() {
  return (
    <div>
      <Label htmlFor='password' required>
        Password
      </Label>
      <input id='password' type='password' required aria-required='true' />
    </div>
  );
}
```

**Note**: The `required` prop only adds a data attribute for styling. You must set the `required` attribute on the input itself for actual validation.

### Optional Field Indicator

Mark fields as optional with `isOptional`:

```tsx
function OptionalFieldExample() {
  return (
    <div>
      <Label htmlFor='middle-name' isOptional>
        Middle Name
      </Label>
      <input id='middle-name' type='text' />
    </div>
  );
}
```

### Disabled State

Use `disabled` to visually indicate disabled controls:

```tsx
function DisabledFieldExample() {
  return (
    <div>
      <Label htmlFor='locked-field' disabled>
        Locked Field
      </Label>
      <input id='locked-field' type='text' disabled aria-disabled='true' />
    </div>
  );
}
```

**Note**: The `disabled` prop only adds a data attribute. You must set the `disabled` attribute on the control itself.

### Implicit Association (Wrapping)

Wrap the form control inside the label for implicit association:

```tsx
function ImplicitAssociationExample() {
  return (
    <Label>
      Accept Terms
      <input type='checkbox' />
    </Label>
  );
}
```

### Polymorphic Rendering

Render as different elements using the `as` prop:

```tsx
function PolymorphicExample() {
  return (
    <div>
      <Label as='span' htmlFor='custom-field'>
        Custom Label Element
      </Label>
      <input id='custom-field' type='text' />
    </div>
  );
}
```

**Warning**: When using non-label elements, native form association may break. Use `aria-labelledby` on the control to maintain accessibility.

### Complex Label Content

Labels can contain rich content like icons, badges, or help text:

```tsx
function ComplexLabelExample() {
  return (
    <div>
      <Label htmlFor='username' required>
        <span style={{ display: 'flex', alignItems: 'center', gap: '8px' }}>
          <span>Username</span>
          <span style={{ fontSize: '12px', color: '#666' }}>(must be unique)</span>
        </span>
      </Label>
      <input id='username' type='text' required />
    </div>
  );
}
```

### Multiple State Indicators

Combine multiple state indicators:

```tsx
function MultipleStatesExample() {
  const [disabled, setDisabled] = React.useState(false);

  return (
    <div>
      <Label htmlFor='conditional-field' required disabled={disabled}>
        Conditional Field
      </Label>
      <input id='conditional-field' type='text' required disabled={disabled} />
      <button onClick={() => setDisabled(!disabled)}>Toggle Disabled</button>
    </div>
  );
}
```

### Form Group Pattern

Complete form field pattern with label, input, and error message:

```tsx
function FormGroupExample() {
  const [value, setValue] = React.useState('');
  const [error, setError] = React.useState('');

  const handleChange = (e: React.ChangeEvent<HTMLInputElement>) => {
    setValue(e.target.value);
    setError(e.target.value.length < 3 ? 'Minimum 3 characters' : '');
  };

  return (
    <div>
      <Label htmlFor='validated-input' required>
        Username
      </Label>
      <input
        id='validated-input'
        type='text'
        value={value}
        onChange={handleChange}
        required
        aria-required='true'
        aria-invalid={!!error}
        aria-describedby={error ? 'error-message' : undefined}
      />
      {error && (
        <span id='error-message' role='alert' style={{ color: 'red' }}>
          {error}
        </span>
      )}
    </div>
  );
}
```

### Radio Group Labeling

Use Label with radio button groups:

```tsx
function RadioGroupLabelExample() {
  const [selected, setSelected] = React.useState('option1');

  return (
    <fieldset>
      <legend>Choose an option</legend>

      <Label htmlFor='option1'>
        <input
          id='option1'
          type='radio'
          name='options'
          value='option1'
          checked={selected === 'option1'}
          onChange={(e) => setSelected(e.target.value)}
        />
        Option 1
      </Label>

      <Label htmlFor='option2'>
        <input
          id='option2'
          type='radio'
          name='options'
          value='option2'
          checked={selected === 'option2'}
          onChange={(e) => setSelected(e.target.value)}
        />
        Option 2
      </Label>
    </fieldset>
  );
}
```

## API Reference

### Label

The Label component creates accessible labels for form controls with support for explicit and implicit associations.

**Props**

| Name          | Type          | Default     | Description                                                                                                                                          |
| ------------- | ------------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `required?`   | `boolean`     | `false`     | Marks label for a required field (exposed via `data-required` attribute). Does NOT add required functionality - set `required` on the control itself |
| `isOptional?` | `boolean`     | `false`     | Marks label for an optional field (exposed via `data-optional` attribute for styling)                                                                |
| `disabled?`   | `boolean`     | `false`     | Marks label for a disabled field (exposed via `data-disabled` attribute). Does NOT disable the control - set `disabled` on the control itself        |
| `as?`         | `ElementType` | `'label'`   | Polymorphic element type to render as. Using non-label elements breaks native association - use `aria-labelledby` on control                         |
| `children?`   | `ReactNode`   | `undefined` | Label content (text, icons, or form controls for implicit association)                                                                               |

**Note**: All standard HTML label attributes (`htmlFor`, `className`, `style`, `ref`, etc.) are supported via `React.LabelHTMLAttributes<HTMLLabelElement>`.

**Events**

| Name            | Parameters                              | Description          | When Triggered                                           |
| --------------- | --------------------------------------- | -------------------- | -------------------------------------------------------- |
| `onClick?`      | `(event: MouseEvent<HTMLLabelElement>)` | Label clicked        | User clicks the label                                    |
| `onMouseEnter?` | `(event: MouseEvent<HTMLLabelElement>)` | Mouse enters label   | Mouse pointer enters label area                          |
| `onMouseLeave?` | `(event: MouseEvent<HTMLLabelElement>)` | Mouse leaves label   | Mouse pointer leaves label area                          |
| `onFocus?`      | `(event: FocusEvent<HTMLLabelElement>)` | Label receives focus | Label gains focus (rare, usually controls receive focus) |
| `onBlur?`       | `(event: FocusEvent<HTMLLabelElement>)` | Label loses focus    | Label loses focus                                        |

**Note**: All standard HTML label element events are supported via `React.LabelHTMLAttributes<HTMLLabelElement>`.

**Data Attributes**

| Attribute       | Value            | Purpose                                    | Applied To                              |
| --------------- | ---------------- | ------------------------------------------ | --------------------------------------- |
| `data-required` | `""`             | Indicates the associated field is required | Root element (when `required={true}`)   |
| `data-optional` | `""`             | Indicates the associated field is optional | Root element (when `isOptional={true}`) |
| `data-disabled` | `""`             | Indicates the associated field is disabled | Root element (when `disabled={true}`)   |

**Accessibility Attributes**

The Label component uses native HTML `<label>` semantics by default, which provides:

- Implicit ARIA `role="label"` (via native `<label>` element)
- Native form association via `for` attribute (rendered as `htmlFor` in React)
- Click-to-focus behavior (clicking label focuses associated control)
- Screen reader announcements (label text is announced when control receives focus)

**When using `as` prop with non-label elements:**

- Native association breaks
- Add `aria-labelledby` on the form control pointing to the label's `id`
- Consider using `role="label"` on the custom element

## Keyboard Interactions

The Label component does not have specific keyboard interactions. Keyboard behavior is handled by the associated form control:

| Key           | Action            | Context         | Notes                                                                |
| ------------- | ----------------- | --------------- | -------------------------------------------------------------------- |
| `Click`       | Focus control     | Label clicked   | Clicking label focuses the associated form control (native behavior) |
| `Tab`         | Navigate          | Form navigation | Moves focus to the associated form control, not the label            |
| `Shift + Tab` | Navigate backward | Form navigation | Moves focus backward through form controls                           |

**Important**: Labels themselves are not focusable. Focus moves directly to the associated form control. All keyboard interactions occur on the control, not the label.
