# Toast

Toast provides a headless notification controller and compound parts for rendering transient feedback. Spar owns the queue, timers, pause and resume behavior, promise updates, and live-region semantics; you bring the visual design.

The live demo creates a toast through the controller and renders every visible item through the `Toaster` render prop.

## Features

- ✅ Headless queue controller via `createToaster`
- ✅ Visible queue limiting with `maxVisibleToasts` and `queued` status
- ✅ Auto-dismiss timers with pause and resume on hover or focus
- ✅ Promise lifecycle updates through `toaster.promise`
- ✅ Accessible live-region behavior with `announcement: 'polite' | 'assertive'`
- ✅ Compound anatomy with `Toast.Root`, `Toast.Title`, `Toast.Description`, `Toast.Action`, and `Toast.Close`
- ✅ Polymorphic rendering support via `as`

### Structure

```tsx
const toaster = createToaster();

<Toaster toaster={toaster}>
  {(toast) => (
    <Toast.Root toast={toast} toaster={toaster}>
      <Toast.Title />
      <Toast.Description />
      <Toast.Action />
      <Toast.Close />
    </Toast.Root>
  )}
</Toaster>;
```

**Data Flow:**

- `createToaster`: Creates the controller that owns queue state, timers, and updates
- `Toaster`: Subscribes to the controller and renders the visible toast list
- `Toast.Root`: Provides toast context and live-region attributes for one item
- `Toast.Title`: Renders `toast.title` when children are omitted
- `Toast.Description`: Renders `toast.description` when children are omitted
- `Toast.Action`: Renders `toast.action.label`, calls `toast.action.onClick`, then dismisses
- `Toast.Close`: Dismisses the toast

## Code Examples

### Basic Toast

```tsx
const toaster = createToaster({ placement: 'bottom-end' });

function App() {
  return (
    <>
      <button
        type='button'
        onClick={() =>
          toaster.success({
            title: 'Booking saved',
            description: 'Passenger details were updated successfully.',
          })
        }
      >
        Save
      </button>

      <Toaster toaster={toaster}>
        {(toast) => (
          <Toast.Root key={toast.id} toast={toast} toaster={toaster}>
            <Toast.Title />
            <Toast.Description />
            <Toast.Close />
          </Toast.Root>
        )}
      </Toaster>
    </>
  );
}
```

### Toast Types

```tsx
toaster.success({ title: 'Saved' });
toaster.info({ title: 'Gate updated' });
toaster.warning({ title: 'Seat selection pending' });
toaster.error({ title: 'Payment failed' });
toaster.loading({ title: 'Uploading', duration: null });
```

`ToastType` is intentionally limited to semantic notification states:

```ts
type ToastType = 'success' | 'error' | 'warning' | 'info' | 'loading';
```

When `toaster.create(...)` is called without a type, Spar uses `info`.

### Promise Toast

```tsx
await toaster.promise(saveBooking(), {
  loading: {
    title: 'Saving booking',
    description: 'Passenger details are being updated.',
  },
  success: (booking) => ({
    title: 'Booking saved',
    description: `PNR ${booking.pnr} is ready.`,
  }),
  error: {
    title: 'Booking could not be saved',
    description: 'Please try again.',
  },
});
```

Promise toasts automatically map lifecycle states to toast types: loading to `loading`, resolved to `success`, and rejected to `error`. Passing an explicit `type` overrides the default.

### Custom Action

```tsx
toaster.warning({
  title: 'Booking changed',
  description: 'The selected seat was released.',
  action: {
    label: 'Undo',
    altText: 'Undo seat release',
    onClick: (toast) => {
      console.log('Undo clicked for', toast.id);
    },
  },
});
```

### Announcement Priority

```tsx
toaster.error({
  title: 'Payment failed',
  announcement: 'assertive',
});

toaster.info({
  title: 'Gate updated',
  announcement: 'polite',
});
```

Errors and warnings default to `assertive`; success, info, and loading toasts default to `polite`.

### Hotkey

The toaster region can be focused with a keyboard shortcut. By default, Spar uses `F8`.

```tsx
<Toaster toaster={toaster} hotkey={['F8']}>
  {(toast) => <Toast.Root toast={toast} toaster={toaster} />}
</Toaster>
```

Use an empty array to disable the shortcut.

```tsx
<Toaster toaster={toaster} hotkey={[]}>
  {(toast) => <Toast.Root toast={toast} toaster={toaster} />}
</Toaster>
```

## API Reference

Toast separates controller behavior from rendering concerns:

- `CreateToasterOptions` configures queue and timer behavior.
- `ToasterController` exposes the imperative API returned by `createToaster`.
- `Toaster` props cover DOM, render, label, and hotkey behavior.
- `ToastOptions` describes a single toast item.

### `createToaster(options)`

| Option             | Type                                                                              | Default          | Description                                                                                           |
| ------------------ | --------------------------------------------------------------------------------- | ---------------- | ----------------------------------------------------------------------------------------------------- |
| `placement`        | `'top-start' \| 'top' \| 'top-end' \| 'bottom-start' \| 'bottom' \| 'bottom-end'` | `'bottom-end'`   | Placement reflected on `data-placement`.                                                              |
| `duration`         | `number`                                                                          | `5000`           | Default auto-dismiss duration in milliseconds. Use item-level `duration: null` for persistent toasts. |
| `maxVisibleToasts` | `number`                                                                          | `3`              | Maximum number of toasts to display at once. Extra items are `queued`.                                |
| `pauseOnPageIdle`  | `boolean`                                                                         | `false`          | Pauses timers while the document is hidden.                                                           |
| `removeDelay`      | `number`                                                                          | `200`            | Delay before a dismissing toast is removed.                                                           |
| `idFactory`        | `() => string`                                                                    | internal counter | Custom id generator.                                                                                  |
| `onCreate`         | `(toast: ToastData) => void`                                                      | -                | Called when a toast is created.                                                                       |
| `onUpdate`         | `(toast: ToastData) => void`                                                      | -                | Called when a toast is updated.                                                                       |
| `onDismiss`        | `(toast: ToastData) => void`                                                      | -                | Called when a toast enters `dismissing`.                                                              |
| `onRemove`         | `(toast: ToastData) => void`                                                      | -                | Called when a toast is removed.                                                                       |
| `onPause`          | `(toast: ToastData) => void`                                                      | -                | Called when a visible timer pauses.                                                                   |
| `onResume`         | `(toast: ToastData) => void`                                                      | -                | Called when a visible timer resumes.                                                                  |

### Controller Methods

| Method                      | Description                                                                                              |
| --------------------------- | -------------------------------------------------------------------------------------------------------- |
| `create(options)`           | Creates a `default` toast unless `options.type` is provided.                                             |
| `success(options)`          | Creates a success toast.                                                                                 |
| `error(options)`            | Creates an error toast.                                                                                  |
| `warning(options)`          | Creates a warning toast.                                                                                 |
| `info(options)`             | Creates an info toast.                                                                                   |
| `loading(options)`          | Creates a loading toast with `duration: null` by default so it stays visible until updated or dismissed. |
| `update(id, options)`       | Updates an existing toast.                                                                               |
| `dismiss(id?)`              | Gracefully dismisses one toast, or all toasts when no id is provided. `removeDelay` still applies.       |
| `pause(id?)`                | Pauses one visible toast timer or all visible timers.                                                    |
| `resume(id?)`               | Resumes one visible toast timer or all visible timers.                                                   |
| `clear()`                   | Removes every toast immediately without waiting for `removeDelay`.                                       |
| `promise(promise, options)` | Creates a loading toast and updates it after resolution or rejection.                                    |
| `subscribe(listener)`       | Subscribes to controller changes.                                                                        |
| `getSnapshot()`             | Returns the current toast list.                                                                          |

### Types

```ts
type ToastStatus = 'queued' | 'visible' | 'dismissing';
type ToastAnnouncement = 'polite' | 'assertive';
type ToastType = 'default' | 'success' | 'error' | 'warning' | 'info' | 'loading';
```

### Data Attributes

| Attribute        | Element      | Description                                        |
| ---------------- | ------------ | -------------------------------------------------- |
| `data-toaster`   | `Toaster`    | Marks the toast viewport.                          |
| `data-placement` | `Toaster`    | Reflects the configured placement.                 |
| `data-toast`     | `Toast.Root` | Marks an individual toast item.                    |
| `data-toast-id`  | `Toast.Root` | Stable item id used by the headless layout motion. |
| `data-status`    | `Toast.Root` | Reflects `queued`, `visible`, or `dismissing`.     |
| `data-type`      | `Toast.Root` | Reflects the toast type.                           |

```ts
interface ToastOptions {
  id?: string;
  title?: React.ReactNode;
  description?: React.ReactNode;
  type?: ToastType;
  duration?: number | null;
  announcement?: ToastAnnouncement;
  action?: ToastActionOptions;
  dismissible?: boolean;
  data?: unknown;
}
```

```ts
interface ToastActionOptions {
  label: React.ReactNode;
  altText: string;
  onClick?: (toast: ToastData) => void;
}
```

```ts
interface ToastPromiseOptions<TData> {
  loading: ToastOptions;
  success: ToastOptions | ((value: TData) => ToastOptions);
  error: ToastOptions | ((error: unknown) => ToastOptions);
}
```

```ts
interface ToasterController {
  placement: ToastPlacement;
  maxVisibleToasts: number;
  create: (options: ToastOptions) => string;
  success: (options: ToastOptions) => string;
  error: (options: ToastOptions) => string;
  warning: (options: ToastOptions) => string;
  info: (options: ToastOptions) => string;
  loading: (options: ToastOptions) => string;
  update: (id: string, options: ToastUpdateOptions) => void;
  dismiss: (id?: string) => void;
  pause: (id?: string) => void;
  resume: (id?: string) => void;
  clear: () => void;
  promise: <TData>(promise: Promise<TData>, options: ToastPromiseOptions<TData>) => Promise<TData>;
  subscribe: (listener: () => void) => () => void;
  getSnapshot: () => ToastData[];
}
```
