# Toast

A headless toast notification system for displaying temporary messages with accessibility, state management, and flexible positioning.

![Accessibility Badge](https://img.shields.io/badge/Accessibility-WCAG%202.2%20AA-green) ![Tree-shakeable Badge](https://img.shields.io/badge/Tree--shakeable-Yes-blue) ![TypeScript Badge](https://img.shields.io/badge/TypeScript-Strict-blue)

:::warning Provider Required
All Toast components **must** be wrapped within `ToastProvider`. Without the provider, Toast components will throw an error as they depend on React Context for state management.
:::

## Features

- ✅ Controlled and uncontrolled open state management
- ✅ Auto-dismiss with configurable duration
- ✅ Priority-based queueing system 
- ✅ Swipe gesture support for dismissal
- ✅ Pause on hover and focus interactions
- ✅ Loading states with progress indicators
- ✅ Multiple semantic variants (success, error, warning, info, loading)
- ✅ Flexible positioning options
- ✅ Polymorphic component support
- ✅ Action buttons and custom content
- ✅ Persistent notifications option

> **⚠️ Important**: All Toast components must be wrapped within `ToastProvider`. The provider manages global state, positioning, and configuration for all toasts.

## Installation

```tsx
import { Toast, ToastProvider } from '@turkish-technology/glide'
// or
import { 
  ToastProvider, 
  ToastRoot, 
  ToastContent, 
  ToastTitle, 
  ToastDescription,
  ToastAction,
  ToastClose,
  ToastIcon,
  ToastProgress
} from '@turkish-technology/glide'
```

**Required Setup**: Wrap your application with `ToastProvider` at the root level:

```tsx
function App() {
  return (
    <ToastProvider>
      {/* Your app content */}
    </ToastProvider>
  );
}
```

### Loading Toast with Progress

```tsx
function LoadingToastExample() {
  const [open, setOpen] = React.useState(false);
  const [progress, setProgress] = React.useState(0);

  const handleClose = () => {
    setOpen(false);
    setProgress(0);
  };

  const startUpload = () => {
    setOpen(true);
    setProgress(0);
  };

  React.useEffect(() => {
    if (!open) return;

    const interval = setInterval(() => {
      setProgress(prev => {
        if (prev >= 100) {
          setOpen(false);
          return 0;
        }
        return prev + 10;
      });
    }, 500);

    return () => clearInterval(interval);
  }, [open]);

  return (
    <ToastProvider>
      <div style={{ padding: '20px' }}>
        <button 
          onClick={startUpload}
          style={{ padding: '8px 16px', border: '1px solid #ccc', borderRadius: '4px' }}
        >
          Start Upload
        </button>
        
        {open && (
          <Toast.Root 
            open={open} 
            onOpenChange={setOpen}
            variant="loading"
            loading={true}
            progress={progress}
            style={{ 
              border: '1px solid #2196f3', 
              borderRadius: '4px', 
              padding: '12px', 
              marginTop: '10px',
              backgroundColor: '#e3f2fd'
            }}
          >
            <Toast.Content>
              <Toast.Title style={{ margin: 0, fontWeight: 'bold', color: '#1976d2' }}>Uploading file...</Toast.Title>
              <Toast.Description style={{ margin: '4px 0 8px 0' }}>
                Please wait while we upload your file.
              </Toast.Description>
              
              <div style={{ marginBottom: '8px' }}>
                <Toast.Progress 
                  value={progress}
                  aria-label={`Upload progress: ${progress}%`}
                  style={{ 
                    width: '100%', 
                    height: '8px', 
                    backgroundColor: '#ccc', 
                    borderRadius: '4px',
                    overflow: 'hidden'

                  Cancel
```

### Advanced Provider Configuration

```tsx
function AdvancedProviderExample() {
  const [notifications, setNotifications] = React.useState([]);

  const addNotification = (message) => {
    const id = Date.now().toString();
    setNotifications(prev => [...prev, { id, message }]);
  };

  const removeNotification = (id) => {
    setNotifications(prev => prev.filter(n => n.id !== id));
  };

  return (
    <ToastProvider
      maxToasts={5}
      position="bottom-right"
      duration={4000}
      shouldPauseOnHover={true}
      shouldPauseOnFocus={true}
      swipeDirection="right"
      shouldCloseOnSwipeEnd={true}
    >
      <div style={{ padding: '20px' }}>
        <h3>Advanced Provider Configuration</h3>
        
        <button 
          onClick={() => addNotification('New notification!')}
          style={{ padding: '8px 16px', border: '1px solid #ccc', borderRadius: '4px' }}
        >
          Add Notification
        </button>

        {notifications.map(notification => (
          <Toast.Root
            key={notification.id}
            open={true}
            onOpenChange={(open) => {
              if (!open) removeNotification(notification.id);
            }}
            variant="info"
            style={{ 
              border: '1px solid #2196f3', 
              borderRadius: '4px', 
              padding: '12px', 
              marginTop: '10px',
              backgroundColor: '#e3f2fd',
              display: 'flex',
              alignItems: 'flex-start',
              gap: '8px'
            }}
          >
            <Toast.Content style={{ flex: 1 }}>
              <Toast.Title style={{ margin: 0, fontWeight: 'bold', color: '#1976d2' }}>Notification</Toast.Title>
              <Toast.Description style={{ margin: '4px 0 0 0' }}>{notification.message}</Toast.Description>
            </Toast.Content>
            <Toast.Close 
              onClick={() => removeNotification(notification.id)}
              style={{ padding: '4px 8px', border: '1px solid #ccc', borderRadius: '4px' }}

              ×
            </Toast.Close>
          </Toast.Root>

}
```

### Multiple Variants with Priority

```tsx
function MultipleVariantsExample() {
  const [toasts, setToasts] = React.useState([]);

  const addToast = (variant, priority) => {
    const id = Math.random().toString(36);
    setToasts(prev => [...prev, { id, variant, priority }]);
  };

  const removeToast = (id) => {
    setToasts(prev => prev.filter(t => t.id !== id));
  };

  const getVariantColor = (variant) => {
    switch(variant) {
      case 'success': return { border: '#4caf50', background: '#e8f5e8', color: '#2e7d32' };
      case 'error': return { border: '#f44336', background: '#ffebee', color: '#c62828' };
      case 'warning': return { border: '#ff9800', background: '#fff3e0', color: '#f57c00' };
      case 'info': return { border: '#2196f3', background: '#e3f2fd', color: '#1976d2' };
      default: return { border: '#ccc', background: '#f9f9f9', color: '#333' };
    }
  };

  return (
    <ToastProvider maxToasts={5} position="top-right">
      <div style={{ padding: '20px' }}>
        <h3>Multiple Variants with Priority</h3>
        
        <div style={{ marginBottom: '16px' }}>
          <button 
            onClick={() => addToast('info', 'low')}
            style={{ margin: '4px', padding: '6px 12px', border: '1px solid #ccc', borderRadius: '4px' }}
          >
            Low Priority Info
          </button>
          <button 
            onClick={() => addToast('warning', 'normal')}
            style={{ margin: '4px', padding: '6px 12px', border: '1px solid #ccc', borderRadius: '4px' }}
          >
            Normal Warning  
          </button>
          <button 
            onClick={() => addToast('error', 'high')}
            style={{ margin: '4px', padding: '6px 12px', border: '1px solid #ccc', borderRadius: '4px' }}
          >
            High Priority Error
          </button>
        </div>

        {toasts.map(toast => {
          const colors = getVariantColor(toast.variant);
          return (
            <Toast.Root 
              key={toast.id}
              open={true}
              variant={toast.variant}
              priority={toast.priority}
              onOpenChange={(open) => {
                if (!open) {
                  removeToast(toast.id);
                }
              }}
              style={{ 
                border: `1px solid ${colors.border}`, 
                borderRadius: '4px', 
                padding: '12px', 
                marginTop: '8px',
                backgroundColor: colors.background,
                display: 'flex',
                alignItems: 'flex-start',
                gap: '8px'
              }}
            >
              <Toast.Content style={{ flex: 1 }}>
                <Toast.Title style={{ margin: 0, fontWeight: 'bold', color: colors.color }}>
                  {toast.priority.toUpperCase()} {toast.variant}
                </Toast.Title>
              </Toast.Content>
              <Toast.Close 
                onClick={() => removeToast(toast.id)}
                style={{ padding: '4px 8px', border: '1px solid #ccc', borderRadius: '4px' }}
              >
                ×
              </Toast.Close>
            </Toast.Root>
          );
        })}
      </div>
    </ToastProvider>
  );
}
```

## API Reference

### ToastProvider

Root provider component that manages global toast state and configuration.

**⚠️ Required Component**: All Toast components must be descendants of `ToastProvider`. The provider manages context, state, and configuration for all toasts in your application.

**Props**

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `ReactNode` | - | Provider content |
| `maxToasts?` | `number` | `5` | Maximum number of toasts visible at once |
| `position?` | `ToastPosition` | `'top-right'` | Global positioning for toast container |
| `duration?` | `number` | `5000` | Default auto-dismiss timeout in ms (0 disables) |
| `shouldPauseOnHover?` | `boolean` | `true` | Pause auto-dismiss when hovering |
| `shouldPauseOnFocus?` | `boolean` | `true` | Pause auto-dismiss when focused |
| `swipeDirection?` | `SwipeDirection` | `'right'` | Swipe direction for dismissal |
| `shouldCloseOnSwipeEnd?` | `boolean` | `true` | Auto-close when swipe gesture completes |

**Events**

| Name | Parameters | Description | When Triggered |
|------|------------|-------------|----------------|
| *None* | - | Provider manages state internally | - |

**ARIA Attributes**

| Attribute | Value | Purpose | Applied To |
|-----------|-------|---------|------------|
| `role` | `"region"` | Identifies toast container region | Provider element |
| `aria-label` | `"Notifications"` | Labels notification region | Provider element |

### Toast.Root

Core toast container component with state management and accessibility features.

**Props**

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `children?` | `ReactNode` | - | Root content |
| `as?` | `ElementType` | `'div'` | Polymorphic element type |
| `variant?` | `ToastVariant` | `'info'` | Toast semantic variant |
| `size?` | `ToastSize` | `'medium'` | Toast size variant |
| `open?` | `boolean` | `undefined` | Controlled open state |
| `defaultOpen?` | `boolean` | `false` | Uncontrolled default open state |
| `onOpenChange?` | `(open: boolean) => void` | `undefined` | Open state change handler |
| `duration?` | `number` | `undefined` | Override provider duration |
| `onDurationEnd?` | `() => void` | `undefined` | Called when duration expires |
| `priority?` | `ToastPriority` | `'normal'` | Queue priority level |
| `persistent?` | `boolean` | `false` | Prevents auto-dismiss |
| `loading?` | `boolean` | `false` | Shows loading state with progress |
| `progress?` | `number` | `undefined` | Loading progress (0-100) |
| `onSwipeStart?` | `(direction: SwipeDirection) => void` | `undefined` | Swipe gesture start handler |
| `onSwipeEnd?` | `(direction: SwipeDirection) => void` | `undefined` | Swipe gesture end handler |
| `role?` | `AriaRole` | `undefined` | ARIA role for the toast element |
| `aria-live?` | `AriaAttributes['aria-live']` | `undefined` | Live region politeness setting |
| `aria-atomic?` | `AriaAttributes['aria-atomic']` | `undefined` | Whether screen readers should read the entire region |
| `aria-label?` | `AriaAttributes['aria-label']` | `undefined` | Accessible label for the toast |
| `aria-labelledby?` | `AriaAttributes['aria-labelledby']` | `undefined` | Associated label element ID |
| `aria-describedby?` | `AriaAttributes['aria-describedby']` | `undefined` | Associated description element ID |

**Events**

| Name | Parameters | Description | When Triggered |
|------|------------|-------------|----------------|
| `onOpenChange` | `(open: boolean)` | Open state changes | User interaction, auto-dismiss, or programmatic change |
| `onDurationEnd` | `()` | Duration timer expires | Auto-dismiss timeout completes |
| `onSwipeStart` | `(direction: SwipeDirection)` | Swipe gesture begins | User starts swiping the toast |
| `onSwipeEnd` | `(direction: SwipeDirection)` | Swipe gesture completes | User completes swipe gesture |

**ARIA Attributes**

| Attribute | Value | Purpose | Applied To |
|-----------|-------|---------|------------|
| `role` | `"alert" \| "status" \| "log"` | Indicates importance level based on variant | Root element |
| `aria-live` | `"assertive" \| "polite"` | Controls screen reader announcement | Root element |
| `aria-atomic` | `"true"` | Ensures entire toast is read | Root element |
| `aria-hidden` | `"true"` | Hides closed toasts from screen readers | Root element when closed |

### Toast.Close

Close/dismiss button component.

> **Note**: `Toast.Close` is a headless component. You must provide your own `onClick` handler to close the toast by calling the `onOpenChange` prop of `Toast.Root`.

**Props**

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `children?` | `ReactNode` | - | Close button content |
| `as?` | `ElementType` | `'button'` | Polymorphic element type |
| `onClick?` | `(event: MouseEvent<HTMLButtonElement>) => void` | `undefined` | Click handler for close action - **Required for functionality** |
| `aria-label?` | `AriaAttributes['aria-label']` | `undefined` | Accessible label |

**Events**

| Name | Parameters | Description | When Triggered |
|------|------------|-------------|----------------|
| `onClick` | `(event: MouseEvent)` | Close button clicked | User clicks close button |
| `onKeyDown` | `(event: KeyboardEvent)` | Key pressed on close button | User presses key while focused |

**ARIA Attributes**

| Attribute | Value | Purpose | Applied To |
|-----------|-------|---------|------------|
| `aria-label` | `"Close notification"` | Default accessible close label | Close button |
| `role` | `"button"` | Identifies as interactive button | Close button |
| `tabindex` | `"0"` | Makes focusable | Close button |

### Toast.Progress

Progress indicator component for loading states.

**Props**

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `children?` | `ReactNode` | - | Progress content |
| `as?` | `ElementType` | `'div'` | Polymorphic element type |
| `value?` | `number` | `undefined` | Progress value (0-100) |
| `max?` | `number` | `100` | Maximum progress value |
| `aria-label?` | `AriaAttributes['aria-label']` | `undefined` | Accessible label for progress bar |
| `aria-describedby?` | `AriaAttributes['aria-describedby']` | `undefined` | Element ID describing the progress |
| `aria-valuenow?` | `AriaAttributes['aria-valuenow']` | `undefined` | Current progress value for screen readers |
| `aria-valuemin?` | `AriaAttributes['aria-valuemin']` | `undefined` | Minimum progress value |
| `aria-valuemax?` | `AriaAttributes['aria-valuemax']` | `undefined` | Maximum progress value |

**Events**

| Name | Parameters | Description | When Triggered |
|------|------------|-------------|----------------|
| *None* | - | Static progress indicator | - |

**ARIA Attributes**

| Attribute | Value | Purpose | Applied To |
|-----------|-------|---------|------------|
| `role` | `"progressbar"` | Identifies as progress indicator | Progress element |
| `aria-valuenow` | `number` | Current progress value | Progress element |
| `aria-valuemin` | `"0"` | Minimum progress value | Progress element |
| `aria-valuemax` | `"100"` | Maximum progress value | Progress element |
| `aria-label` | `"Loading progress"` | Default progress label | Progress element |

## Keyboard Interactions

| Key | Action | Context | Notes |
|-----|--------|---------|-------|
| `Tab` | Navigate | Always | Moves focus through interactive elements (actions, close) |
| `Shift + Tab` | Navigate backward | Always | Moves focus backward through interactive elements |
| `Enter` | Activate | Focused buttons | Triggers action or close button |
| `Space` | Activate | Focused buttons | Alternative activation for action and close buttons |
| `Escape` | Close toast | Toast focused | Dismisses the current toast |
| `ArrowRight` | Next toast | Multiple toasts | Moves focus to next toast in queue |
| `ArrowLeft` | Previous toast | Multiple toasts | Moves focus to previous toast in queue |
| `Home` | First toast | Multiple toasts | Moves focus to first toast in queue |
| `End` | Last toast | Multiple toasts | Moves focus to last toast in queue |
