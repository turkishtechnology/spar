# Switch

Headless switch primitives for creating accessible on/off settings with custom track, thumb, label, and hint parts. Pair it with the [Field](./Field.mdx) primitive to get label, description, and error-message wiring with coordinated ARIA IDs.

## Features

- ✅ **Field integration** - Inherits `invalid`, `disabled`, `required`, `readOnly` from parent `<Field>`
- ✅ Compound parts for root, control, track, and thumb
- ✅ Supports both controlled (`checked`) and uncontrolled (`defaultChecked`) state
- ✅ Integrates with native forms through a hidden checkbox input (`name`, `value`, `form`, `required`)
- ✅ Supports render-prop children for programmatic state updates
- ✅ Supports disabled and read-only interaction modes
- ✅ Supports polymorphic rendering via the `as` prop
- ✅ **Coordinated ARIA IDs** - Automatic `aria-labelledby`, `aria-describedby` wiring with Field

import { Switch, Field } from '@turkish-technology/spar';

## Anatomy

The Switch component is built as a compound component. `Switch.Root` owns state and context, while `Switch.Control` carries the interactive switch semantics. When wrapped in a `Field`, the switch inherits validation state and ARIA relationships automatically.

### Structure

```tsx
<Field.Root>
  <Field.Label />
  <Switch.Root>
    <Switch.Control>
      <Switch.Track>
        <Switch.Thumb />
      </Switch.Track>
    </Switch.Control>
  </Switch.Root>
  <Field.Description />
  <Field.ErrorMessage />
</Field.Root>
```

**With Field:**

```tsx
<Field.Root required invalid>
  <Field.Label>Label text</Field.Label>
  <Switch.Root name='fieldName'>
    <Switch.Control>
      <Switch.Track>
        <Switch.Thumb />
      </Switch.Track>
    </Switch.Control>
  </Switch.Root>
  <Field.Description>Description text</Field.Description>
  <Field.ErrorMessage>Error text</Field.ErrorMessage>
</Field.Root>
```

**Data Flow:**

- **Field.Root**: Owns coordinated IDs and the `invalid` / `disabled` / `required` / `readOnly` state, propagated via context
- **Field.Label**: Accessible label auto-linked to the switch control via `aria-labelledby`
- **Switch.Root**: Manages controlled or uncontrolled checked state and provides context
- **Switch.Control**: Receives switch ARIA attributes and toggles state on click, `Space`, and `Enter`
- **Field.Description**: Helper text linked via `aria-describedby`
- **Field.ErrorMessage**: Error announcement with `role="alert"`, only rendered when `invalid` is `true`
- When `name` is provided on `Switch.Root`, `Switch.Control` renders a synchronized hidden checkbox input
- When inside a Field, Switch inherits `invalid`, `disabled`, `required`, `readOnly` automatically

## Code Examples

### Basic Usage

Use the compound parts with a Field wrapper for an accessible switch with label.

```tsx
function BasicSwitch() {
  return (
    <Field.Root>
      <Field.Label>Enable notifications</Field.Label>
      <Switch.Root defaultChecked>
        <Switch.Control>
          <Switch.Track>
            <Switch.Thumb />
          </Switch.Track>
        </Switch.Control>
      </Switch.Root>
    </Field.Root>
  );
}
```

### Controlled Switch

Control the checked value from parent state when the setting needs to stay in sync with other UI.

```tsx {2,5-6}
function ControlledSwitch() {
  const [enabled, setEnabled] = React.useState(false);

  return (
    <Field.Root>
      <Field.Label>Dark mode</Field.Label>
      <Switch.Root checked={enabled} onChange={setEnabled}>
        <Switch.Control>
          <Switch.Track>
            <Switch.Thumb />
          </Switch.Track>
        </Switch.Control>
      </Switch.Root>
      <Field.Description>{enabled ? 'Theme is dark' : 'Theme is light'}</Field.Description>
    </Field.Root>
  );
}
```

### Uncontrolled Switch

Use `defaultChecked` for simple cases where the switch can manage its own state internally.

```tsx {3}
function UncontrolledSwitch() {
  return (
    <Field.Root>
      <Field.Label>Auto-managed switch</Field.Label>
      <Switch.Root defaultChecked={false} onChange={(checked) => console.log('Changed to:', checked)}>
        <Switch.Control>
          <Switch.Track>
            <Switch.Thumb />
          </Switch.Track>
        </Switch.Control>
      </Switch.Root>
    </Field.Root>
  );
}
```

### Form Integration

Provide `name` and optional `value` on `Switch.Root` when the switch should submit as part of a native form.

```tsx {2-3,7-10,13,22}
function FormExample() {
  const [notifications, setNotifications] = React.useState(false);
  const [darkMode, setDarkMode] = React.useState(true);

  return (
    <form
      onSubmit={(event) => {
        event.preventDefault();
        const formData = new FormData(event.currentTarget);
        console.log(formData.get('notifications'), formData.get('darkMode'));
      }}
    >
      <Field.Root>
        <Field.Label>Notifications</Field.Label>
        <Switch.Root name='notifications' checked={notifications} onChange={setNotifications}>
          <Switch.Control>
            <Switch.Track>
              <Switch.Thumb />
            </Switch.Track>
          </Switch.Control>
        </Switch.Root>
      </Field.Root>

      <Field.Root>
        <Field.Label>Dark mode</Field.Label>
        <Switch.Root name='darkMode' checked={darkMode} onChange={setDarkMode} value='enabled'>
          <Switch.Control>
            <Switch.Track>
              <Switch.Thumb />
            </Switch.Track>
          </Switch.Control>
        </Switch.Root>
      </Field.Root>

      <button type='submit'>Save</button>
    </form>
  );
}
```

### Accessibility with Field

Use `Field.Label` and `Field.Description` when the control should expose visible text as its accessible name and description.

```tsx {6-15}
function AccessibleSwitch() {
  const [isOn, setIsOn] = React.useState(false);

  return (
    <Field.Root required>
      <Field.Label>Wi-Fi connection</Field.Label>
      <Switch.Root checked={isOn} onChange={setIsOn}>
        <Switch.Control>
          <Switch.Track>
            <Switch.Thumb />
          </Switch.Track>
        </Switch.Control>
      </Switch.Root>
      <Field.Description>{isOn ? 'Connected to Wi-Fi' : 'Disconnected from Wi-Fi'}</Field.Description>
    </Field.Root>
  );
}
```

### Disabled and Read-only States

Use `disabled` to block interaction entirely, or `readOnly` when users may inspect the value but should not change it. State is set on `Field.Root` and inherited by Switch automatically.

```tsx {2,13,24}
function StateVariations() {
  const [enabled, setEnabled] = React.useState(true);

  return (
    <div>
      <Field.Root>
        <Field.Label>Normal switch</Field.Label>
        <Switch.Root checked={enabled} onChange={setEnabled}>
          <Switch.Control>
            <Switch.Track>
              <Switch.Thumb />
            </Switch.Track>
          </Switch.Control>
        </Switch.Root>
      </Field.Root>

      <Field.Root disabled>
        <Field.Label>Disabled on</Field.Label>
        <Switch.Root defaultChecked>
          <Switch.Control>
            <Switch.Track>
              <Switch.Thumb />
            </Switch.Track>
          </Switch.Control>
        </Switch.Root>
      </Field.Root>

      <Field.Root readOnly>
        <Field.Label>Read-only on</Field.Label>
        <Switch.Root defaultChecked>
          <Switch.Control>
            <Switch.Track>
              <Switch.Thumb />
            </Switch.Track>
          </Switch.Control>
        </Switch.Root>
      </Field.Root>
    </div>
  );
}
```

### Custom Element Rendering

The `as` prop lets you choose custom elements while preserving the same state and accessibility model.

```tsx {2,5}
function CustomElement() {
  return (
    <Field.Root>
      <Field.Label>Custom element switch</Field.Label>
      <Switch.Root as='section' defaultChecked>
        <Switch.Control as='div'>
          <Switch.Track>
            <Switch.Thumb />
          </Switch.Track>
        </Switch.Control>
      </Switch.Root>
    </Field.Root>
  );
}
```

### Standalone Shortcut

The standalone `<Switch>` component remains available for simple single-element usage. Use the compound parts when you need separate track and thumb elements.

```tsx
function StandaloneSwitch() {
  const [enabled, setEnabled] = React.useState(false);

  return (
    <Switch checked={enabled} onChange={setEnabled}>
      {enabled ? 'On' : 'Off'}
    </Switch>
  );
}
```

## API Reference

### Switch.Root

State provider and layout wrapper for compound switch parts.

| Name              | Type                                                                 | Default     | Description                                         |
| ----------------- | -------------------------------------------------------------------- | ----------- | --------------------------------------------------- |
| `as?`             | `React.ElementType`                                                  | `"div"`     | Element or component to render as                   |
| `checked?`        | `boolean`                                                            | `undefined` | Controlled checked state                            |
| `defaultChecked?` | `boolean`                                                            | `false`     | Initial checked state in uncontrolled mode          |
| `onChange?`       | `(checked: boolean) => void`                                         | `undefined` | Called when checked state changes                   |
| `disabled?`       | `boolean`                                                            | `false`     | Prevents interaction                                |
| `name?`           | `string`                                                             | `undefined` | Hidden input name for form submission               |
| `value?`          | `string`                                                             | `"on"`      | Hidden input value when checked                     |
| `form?`           | `string`                                                             | `undefined` | Form id used by hidden input                        |
| `required?`       | `boolean`                                                            | `false`     | Marks hidden input and switch semantics as required |
| `readOnly?`       | `boolean`                                                            | `false`     | Prevents state changes while keeping focus behavior |
| `id?`             | `string`                                                             | generated   | Used to derive the default control id               |
| `children?`       | `React.ReactNode \| ((state: SwitchRenderProps) => React.ReactNode)` | `undefined` | Static content or render-prop function              |
| `...props`        | `ComponentPropsWithRef<"div">`                                       | `-`         | Other native props for the polymorphic root element |

### Switch.Control

Interactive element that receives `role="switch"` and toggles the root checked state.

| Name                | Type                              | Default     | Description                                    |
| ------------------- | --------------------------------- | ----------- | ---------------------------------------------- |
| `as?`               | `React.ElementType`               | `"button"`  | Element or component to render as              |
| `id?`               | `string`                          | generated   | Overrides the generated control id             |
| `type?`             | `button` attributes               | `"button"`  | Native button type when rendered as a button   |
| `aria-label?`       | `string`                          | `undefined` | Accessible name override                       |
| `aria-labelledby?`  | `string`                          | `undefined` | Explicit accessible label id override          |
| `aria-describedby?` | `string`                          | `undefined` | Explicit accessible description id override    |
| `children?`         | `React.ReactNode`                 | `undefined` | Visual switch content, usually track and thumb |
| `...props`          | `ComponentPropsWithRef<"button">` | `-`         | Other native props for the polymorphic control |

When `Switch.Root` has a `name`, `Switch.Control` also renders a hidden synchronized `input[type="checkbox"]` for native form submission.

### Switch.Track

Visual track part. It is marked `aria-hidden="true"` and mirrors root state with data attributes.

| Name        | Type                            | Default     | Description                              |
| ----------- | ------------------------------- | ----------- | ---------------------------------------- |
| `as?`       | `React.ElementType`             | `"span"`    | Element or component to render as        |
| `children?` | `React.ReactNode`               | `undefined` | Usually contains `Switch.Thumb`          |
| `...props`  | `ComponentPropsWithRef<"span">` | `-`         | Other native props for the track element |

### Switch.Thumb

Visual thumb part. It is marked `aria-hidden="true"` and mirrors root state with data attributes.

| Name        | Type                            | Default     | Description                              |
| ----------- | ------------------------------- | ----------- | ---------------------------------------- |
| `as?`       | `React.ElementType`             | `"span"`    | Element or component to render as        |
| `children?` | `React.ReactNode`               | `undefined` | Optional visual content                  |
| `...props`  | `ComponentPropsWithRef<"span">` | `-`         | Other native props for the thumb element |

### Standalone Switch

The standalone `Switch` export is a single interactive element for compatibility and compact use cases. It supports the same state, form, render-prop, disabled, read-only, and polymorphic props as the previous single-part API.

**Render Props (SwitchRenderProps)**

| Property     | Type                         | Description                                        |
| ------------ | ---------------------------- | -------------------------------------------------- |
| `checked`    | `boolean`                    | Whether the switch is currently checked            |
| `setChecked` | `(checked: boolean) => void` | Function to programmatically set the checked state |
| `disabled`   | `boolean`                    | Whether the switch is disabled                     |
| `readOnly`   | `boolean`                    | Whether the switch is read-only                    |
| `isFocused`  | `boolean`                    | Whether the switch currently has focus             |
| `isHovered`  | `boolean`                    | Whether the switch is being hovered                |
| `isPressed`  | `boolean`                    | Whether the switch is being pressed                |

| Part              | Attribute          | Value                      | Purpose                                      |
| ----------------- | ------------------ | -------------------------- | -------------------------------------------- |
| `Switch.Root`     | `data-switch-root` | `""`                       | Root marker attribute                        |
| `Switch.Root`     | `data-state`       | `"checked" \| "unchecked"` | Checked state token                          |

| `Switch.Control`  | `aria-readonly`    | `true`                     | Present when `readOnly` is `true`            |

| `Switch.Control`  | `data-switch`      | `""`                       | Control marker attribute                     |
| `Switch.Control`  | `data-state`       | `"checked" \| "unchecked"` | Checked state token                          |

| `Switch.Thumb`    | `aria-hidden`      | `"true"`                   | Keeps decorative thumb out of the AT tree    |

Stateful parts also expose `data-checked`, `data-disabled`, `data-readonly`, `data-required`, `data-focus`, `data-hover`, and `data-active` when those states apply.

## Hidden Input

`Switch.Control` renders a hidden input only when `name` is provided on `Switch.Root`.

| Attribute     | Value        | Purpose                                  |
| ------------- | ------------ | ---------------------------------------- |
| `type`        | `"checkbox"` | Enables native form submission semantics |
| `name`        | `string`     | Form field name                          |
| `value`       | `string`     | Submitted value when checked             |
| `form`        | `string`     | Associates input to external form id     |
| `required`    | `boolean`    | Participates in native form validation   |
| `checked`     | `boolean`    | Mirrors switch checked state             |
| `disabled`    | `boolean`    | Mirrors disabled state                   |
| `tabIndex`    | `-1`         | Keeps hidden input out of tab sequence   |
| `aria-hidden` | `true`       | Hides input from assistive tech tree     |

## Keyboard Interactions

| Key           | Action                | Context          | Notes                                                   |
| ------------- | --------------------- | ---------------- | ------------------------------------------------------- |
| `Tab`         | Moves focus to switch | Focus management | Available when switch is not disabled                   |
| `Shift + Tab` | Moves focus backward  | Focus management | Standard reverse tab navigation                         |
| `Space`       | Toggles checked state | Switch focused   | No state change when `disabled` or `readOnly` is `true` |
| `Enter`       | Toggles checked state | Switch focused   | No state change when `disabled` or `readOnly` is `true` |
