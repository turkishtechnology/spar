# Switch

A headless boolean toggle control that provides switch-specific ARIA semantics and behavior for on/off states.

## Features

- ✅ Supports both controlled (`checked`) and uncontrolled (`defaultChecked`) state
- ✅ Integrates with native forms through hidden checkbox input (`name`, `value`, `form`, `required`)
- ✅ Supports render-prop children for programmatic state updates
- ✅ Supports disabled and read-only interaction modes
- ✅ Supports polymorphic rendering via the `as` prop
- ✅ Supports optional auto focus on mount

## Installation

```tsx

```

**Data Flow:**

- User interaction updates internal or controlled checked state
- `onChange` receives the next boolean checked value
- When `name` is provided, a hidden checkbox input is rendered and synchronized

## Code Examples

### Basic Usage

```tsx
function BasicSwitch() {
  const [enabled, setEnabled] = React.useState(false);

  return (
    <Switch checked={enabled} onChange={setEnabled}>
      Toggle Setting
    </Switch>
  );
}
```

### Uncontrolled Switch

```tsx
function UncontrolledSwitch() {
  return (
    <Switch defaultChecked={false} onChange={(checked) => console.log('Changed to:', checked)}>
      Auto-managed Switch
    </Switch>
  );
}
```

### Form Integration

```tsx
function FormExample() {
  const [notifications, setNotifications] = React.useState(false);
  const [darkMode, setDarkMode] = React.useState(true);

  return (
    <form
      onSubmit={(event) => {
        event.preventDefault();
        const formData = new FormData(event.currentTarget);
        console.log(formData.get('notifications'), formData.get('darkMode'));
      }}
    >
      <Switch name='notifications' checked={notifications} onChange={setNotifications}>
        Notifications
      </Switch>

      <Switch name='darkMode' checked={darkMode} onChange={setDarkMode} value='enabled'>
        Dark mode
      </Switch>

      <button type='submit'>Save</button>
    </form>
  );
}
```

### Accessibility with Labels

```tsx
function AccessibleSwitch() {
  const [isOn, setIsOn] = React.useState(false);

  return (
    <div>
      <label id='wifi-label' htmlFor='wifi-switch'>
        Wi-Fi Connection
      </label>
      <p id='wifi-desc'>Toggle to enable or disable Wi-Fi connectivity</p>
      <Switch
        id='wifi-switch'
        checked={isOn}
        onChange={setIsOn}
        aria-labelledby='wifi-label'
        aria-describedby='wifi-desc'
      >
        {isOn ? 'Connected' : 'Disconnected'}
      </Switch>
    </div>
  );
}
```

### Disabled and Read-only States

```tsx
function StateVariations() {
  const [enabled, setEnabled] = React.useState(true);

  return (
    <div>
      <Switch checked={enabled} onChange={setEnabled}>
        Normal Switch
      </Switch>

      <Switch checked={true} disabled>
        Disabled (On)
      </Switch>

      <Switch checked={false} disabled>
        Disabled (Off)
      </Switch>

      <Switch checked={true} readOnly>
        Read-only (On)
      </Switch>
    </div>
  );
}
```

### Custom Element Rendering

```tsx
function CustomElement() {
  const [active, setActive] = React.useState(false);

  return (
    <Switch as='div' checked={active} onChange={setActive}>
      Custom Div Switch
    </Switch>
  );
}
```

## API Reference

### Switch

A headless boolean toggle control. It extends `Button` props and renders a switch role by default.

**Props**

| Name                | Type                                                                 | Default             | Description                                                                   |
| ------------------- | -------------------------------------------------------------------- | ------------------- | ----------------------------------------------------------------------------- |
| `as?`               | `React.ElementType`                                                  | `"button"`          | Element or component to render as                                             |
| `checked?`          | `boolean`                                                            | `undefined`         | Controlled checked state                                                      |
| `defaultChecked?`   | `boolean`                                                            | `false`             | Initial checked state in uncontrolled mode                                    |
| `onChange?`         | `(checked: boolean) => void`                                         | `undefined`         | Called when checked state changes                                             |
| `disabled?`         | `boolean`                                                            | `false`             | Prevents interaction                                                          |
| `name?`             | `string`                                                             | `undefined`         | Hidden input name for form submission                                         |
| `value?`            | `string`                                                             | `"on"`              | Hidden input value when checked                                               |
| `form?`             | `string`                                                             | `undefined`         | Form id used by hidden input                                                  |
| `required?`         | `boolean`                                                            | `false`             | Marks hidden input as required                                                |
| `readOnly?`         | `boolean`                                                            | `false`             | Prevents state changes while keeping focus behavior                           |
| `autoFocus?`        | `boolean`                                                            | `false`             | Focuses the switch on mount                                                   |
| `id?`               | `string`                                                             | `useId()` generated | Uses provided id or an auto-generated id                                      |
| `isLoading?`        | `boolean`                                                            | `false`             | Inherited from `Button`; marks element as loading                             |
| `isPressed?`        | `boolean`                                                            | `undefined`         | Inherited toggle state from `Button`                                          |
| `onPressedChange?`  | `(pressed: boolean) => void`                                         | `undefined`         | Inherited callback for `isPressed` toggle state                               |
| `aria-label?`       | `string`                                                             | `undefined`         | Accessible name override                                                      |
| `aria-labelledby?`  | `string`                                                             | `undefined`         | Id of labeling element                                                        |
| `aria-describedby?` | `string`                                                             | `undefined`         | Id of descriptive element                                                     |
| `children?`         | `React.ReactNode \| ((state: SwitchRenderProps) => React.ReactNode)` | `undefined`         | Static content or render-prop function                                        |
| `...props`          | `ComponentPropsWithRef<"button">`                                    | `-`                 | Other native button props (polymorphic target props when `as` is provided)   |

**Render Props (SwitchRenderProps)**

| Property     | Type                         | Description                                        |
| ------------ | ---------------------------- | -------------------------------------------------- |
| `checked`    | `boolean`                    | Whether the switch is currently checked            |
| `setChecked` | `(checked: boolean) => void` | Function to programmatically set the checked state |
| `disabled`   | `boolean`                    | Whether the switch is disabled                     |
| `readOnly`   | `boolean`                    | Whether the switch is read-only                    |
| `isFocused`  | `boolean`                    | Whether the switch currently has focus             |
| `isHovered`  | `boolean`                    | Whether the switch is being hovered                |
| `isPressed`  | `boolean`                    | Whether the switch is being pressed                |

**Events**

| Name              | Parameters                                    | Description                                      | When Triggered                                                      |
| ----------------- | --------------------------------------------- | ------------------------------------------------ | ------------------------------------------------------------------- |
| `onChange`        | `(checked: boolean)`                          | Reports checked state changes                    | Click, `Space`, `Enter`, or render-prop `setChecked` updates state |
| `onPressedChange` | `(pressed: boolean)`                          | Inherited `Button` toggle callback               | Activation when `isPressed` is used                                 |
| `onClick`         | `(event: React.MouseEvent<HTMLButtonElement>)` | Inherited click handler from underlying `Button` | On pointer click and keyboard activation                            |
| `onKeyDown`       | `(event: React.KeyboardEvent<HTMLButtonElement>)` | Inherited keydown handler                        | On keydown events on the switch element                             |
| `onFocus`         | `(event: React.FocusEvent<HTMLButtonElement>)` | Inherited focus handler                          | When switch receives focus                                           |
| `onBlur`          | `(event: React.FocusEvent<HTMLButtonElement>)` | Inherited blur handler                           | When switch loses focus                                              |
| `onPointerEnter`  | `(event: React.PointerEvent<HTMLButtonElement>)` | Inherited pointer enter handler                  | Pointer enters switch area                                           |
| `onPointerLeave`  | `(event: React.PointerEvent<HTMLButtonElement>)` | Inherited pointer leave handler                  | Pointer leaves switch area                                           |
| `onPointerDown`   | `(event: React.PointerEvent<HTMLButtonElement>)` | Inherited pointer down handler                   | Pointer press starts                                                 |
| `onPointerUp`     | `(event: React.PointerEvent<HTMLButtonElement>)` | Inherited pointer up handler                     | Pointer press ends                                                   |
| `onPointerCancel` | `(event: React.PointerEvent<HTMLButtonElement>)` | Inherited pointer cancel handler                 | Pointer interaction is canceled                                      |

**HTML Attributes**

| Attribute          | Value                      | Purpose                                                   |
| ------------------ | -------------------------- | --------------------------------------------------------- |
| `role`             | `"switch"`                 | Applies switch semantics                                  |
| `aria-checked`     | `boolean`                  | Reflects checked state                                    |
| `aria-label`       | `string`                   | Optional accessible name                                  |
| `aria-labelledby`  | `string`                   | Optional accessible name reference                        |
| `aria-describedby` | `string`                   | Optional description reference                            |
| `aria-readonly`    | `true`                     | Present when `readOnly` is `true`                         |
| `aria-required`    | `true`                     | Present when `required` is `true`                         |
| `data-switch`      | `""`                       | Switch marker attribute                                   |
| `data-state`       | `"checked" \| "unchecked"` | Checked state token                                       |
| `data-checked`     | `""`                       | Present when checked                                      |
| `data-readonly`    | `""`                       | Present when read-only                                    |
| `data-required`    | `""`                       | Present when required                                     |
| `data-focus`       | `""`                       | Present while focused                                     |
| `data-hover`       | `""`                       | Present while hovered                                     |
| `data-active`      | `""`                       | Present while pressed                                     |
| `data-disabled`    | `""`                       | Present when disabled (from inherited `Button` behavior)  |
| `data-loading`     | `""`                       | Present when `isLoading` is `true`                        |
| `data-autofocus`   | `""`                       | Present when `autoFocus` is `true`                        |
| `data-pressed`     | `""`                       | Present when inherited `isPressed` toggle state is active |

**Hidden Input (rendered only when `name` is provided)**

| Attribute     | Value      | Purpose                                  |
| ------------- | ---------- | ---------------------------------------- |
| `type`        | `"checkbox"` | Enables native form submission semantics |
| `name`        | `string`   | Form field name                          |
| `value`       | `string`   | Submitted value when checked             |
| `form`        | `string`   | Associates input to external form id     |
| `required`    | `boolean`  | Participates in native form validation   |
| `checked`     | `boolean`  | Mirrors switch checked state             |
| `tabIndex`    | `-1`       | Keeps hidden input out of tab sequence   |
| `aria-hidden` | `true`     | Hides input from assistive tech tree     |

## Keyboard Interactions

| Key           | Action                    | Context          | Notes                                                    |
| ------------- | ------------------------- | ---------------- | -------------------------------------------------------- |
| `Tab`         | Moves focus to switch     | Focus management | Available when switch is not disabled                    |
| `Shift + Tab` | Moves focus backward      | Focus management | Standard reverse tab navigation                          |
| `Space`       | Toggles checked state     | Switch focused   | No state change when `disabled` or `readOnly` is `true` |
| `Enter`       | Toggles checked state     | Switch focused   | No state change when `disabled` or `readOnly` is `true` |
