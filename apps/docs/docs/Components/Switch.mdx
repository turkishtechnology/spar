## Features

- ✅ Full switch ARIA semantics with `role="switch"`
- ✅ Controlled and uncontrolled modes
- ✅ Comprehensive keyboard navigation (Space, Enter)
- ✅ Form integration with hidden input
- ✅ State management (focus, hover, active tracking)
- ✅ Disabled and read-only states
- ✅ Auto-focus support
- ✅ Custom element rendering with `as` prop
- ✅ Rich data attributes for styling hooks

## Code Examples

### Basic Usage

```tsx
function BasicSwitch() {
  const [enabled, setEnabled] = useState(false);

  return (
    <Switch checked={enabled} onChange={setEnabled}>
      Toggle Setting
    </Switch>
  );
}
```

### Uncontrolled Switch

```tsx
function UncontrolledSwitch() {
  return (
    <Switch defaultChecked={false} onChange={(checked) => console.log('Changed to:', checked)}>
      Auto-managed Switch
    </Switch>
  );
}
```

### Form Integration

```tsx
function FormExample() {
  const [settings, setSettings] = useState({
    notifications: false,
    darkMode: true,
    autoSave: false,
  });

  return (
    <form onSubmit={(e) => e.preventDefault()}>
      <fieldset>
        <legend>User Preferences</legend>

        <Switch
          name='notifications'
          checked={settings.notifications}
          onChange={(checked) => setSettings((prev) => ({ ...prev, notifications: checked }))}
          aria-label='Enable notifications'
        >
          Notifications
        </Switch>

        <Switch
          name='darkMode'
          checked={settings.darkMode}
          onChange={(checked) => setSettings((prev) => ({ ...prev, darkMode: checked }))}
          aria-label='Enable dark mode'
        >
          Dark Mode
        </Switch>

        <Switch
          name='autoSave'
          checked={settings.autoSave}
          onChange={(checked) => setSettings((prev) => ({ ...prev, autoSave: checked }))}
          required
          aria-label='Enable auto-save'
        >
          Auto-save (Required)
        </Switch>
      </fieldset>
    </form>
  );
}
```

### Accessibility with Labels

```tsx
function AccessibleSwitch() {
  const [isOn, setIsOn] = useState(false);

  return (
    <div>
      <label id='wifi-label' htmlFor='wifi-switch'>
        Wi-Fi Connection
      </label>
      <p id='wifi-desc'>Toggle to enable or disable Wi-Fi connectivity</p>
      <Switch
        id='wifi-switch'
        checked={isOn}
        onChange={setIsOn}
        aria-labelledby='wifi-label'
        aria-describedby='wifi-desc'
      >
        {isOn ? 'Connected' : 'Disconnected'}
      </Switch>
    </div>
  );
}
```

### Disabled and Read-only States

```tsx
function StateVariations() {
  const [enabled, setEnabled] = useState(true);

  return (
    <div>
      <Switch checked={enabled} onChange={setEnabled}>
        Normal Switch
      </Switch>

      <Switch checked={true} disabled>
        Disabled (On)
      </Switch>

      <Switch checked={false} disabled>
        Disabled (Off)
      </Switch>

      <Switch checked={true} readOnly>
        Read-only (On)
      </Switch>
    </div>
  );
}
```

### Custom Element Rendering

```tsx
function CustomElement() {
  const [active, setActive] = useState(false);

  return (
    <Switch
      as='div'
      checked={active}
      onChange={setActive}
      role='switch' // Required when using non-button elements
      tabIndex={0} // Required for keyboard navigation
    >
      Custom Div Switch
    </Switch>
  );
}
```

## API Reference

### Switch

A headless boolean toggle control that provides switch-specific ARIA semantics and comprehensive accessibility features.

**Props**

| Name                | Type                         | Default     | Description                                                                    |
| ------------------- | ---------------------------- | ----------- | ------------------------------------------------------------------------------ |
| `as?`               | `PolymorphicAs`                | `'button'`  | The element or component to render as                                          |
| `checked?`          | `boolean`                    | `undefined` | Controlled checked state. When provided, component operates in controlled mode |
| `defaultChecked?`   | `boolean`                    | `false`     | Default checked state for uncontrolled usage                                   |
| `onChange?`         | `(checked: boolean) => void` | `undefined` | Callback fired when the checked state changes                                  |
| `disabled?`       | `boolean`                    | `false`     | Disabled state - prevents interaction and is properly announced to screen readers                          |
| `name?`             | `string`                     | `undefined` | Name attribute for form submission                                           |
| `value?`            | `string`                     | `'on'`      | Value sent in form data when checked                                                  |
| `form?`             | `string`                     | `undefined` | ID of the form this switch belongs to                                                      |
| `required?`       | `boolean`                    | `false`     | Required state for form validation                                             |
| `readOnly?`       | `boolean`                    | `false`     | Read-only state - prevents interaction                                         |
| `shouldAutoFocus?`  | `boolean`                    | `false`     | Auto-focus on mount                                                            |
| `aria-label?`       | `string`                     | `undefined` | Accessible name for the switch. Required when switch has no visible label      |
| `aria-labelledby?`  | `string`                     | `undefined` | ID of element that labels the switch                                           |
| `aria-describedby?` | `string`                     | `undefined` | ID of element that describes the switch                                        |
| `children?`         | `ReactNode \| ((state: SwitchRenderProps) => ReactNode)` | `undefined` | Content to display inside the switch, or render props function |

**Render Props (SwitchRenderProps)**

| Property    | Type                          | Description                                        |
| ----------- | ----------------------------- | -------------------------------------------------- |
| `checked`   | `boolean`                     | Whether the switch is currently checked            |
| `setChecked`| `(checked: boolean) => void`  | Function to programmatically set the checked state |
| `disabled`  | `boolean`                     | Whether the switch is disabled                     |
| `readOnly`  | `boolean`                     | Whether the switch is read-only                    |
| `isFocused` | `boolean`                     | Whether the switch currently has focus             |
| `isHovered` | `boolean`                     | Whether the switch is being hovered                |
| `isPressed` | `boolean`                     | Whether the switch is being pressed                |

**Events**

| Name           | Parameters               | Description               | When Triggered                                                  |
| -------------- | ------------------------ | ------------------------- | --------------------------------------------------------------- |
| `onChange`     | `(checked: boolean)`     | Switch state changes      | User toggles switch via click, keyboard, or programmatic change |
| `onClick`      | `(event: MouseEvent)`    | Mouse click on switch     | User clicks the switch element                                  |
| `onKeyDown`    | `(event: KeyboardEvent)` | Key pressed while focused | User presses Space or Enter keys                                |
| `onFocus`      | `(event: FocusEvent)`    | Switch receives focus     | Focus moves to switch via Tab navigation or programmatically    |
| `onBlur`       | `(event: FocusEvent)`    | Switch loses focus        | Focus moves away from switch                                    |
| `onMouseEnter` | `(event: MouseEvent)`    | Mouse enters switch area  | Cursor moves over switch (unless disabled)                      |
| `onMouseLeave` | `(event: MouseEvent)`    | Mouse leaves switch area  | Cursor moves away from switch                                   |
| `onMouseDown`  | `(event: MouseEvent)`    | Mouse button pressed      | User starts clicking switch (unless disabled or read-only)      |
| `onMouseUp`    | `(event: MouseEvent)`    | Mouse button released     | User releases click on switch                                   |

**HTML Attributes**

| Attribute       | Value                      | Purpose                                             |
| --------------- | -------------------------- | --------------------------------------------------- |
| `data-switch`   | `""`                       | Identifies the element as a switch                  |
| `data-state`    | `"checked" \| "unchecked"` | Indicates current checked state                     |
| `data-checked`  | `""`                       | Present when switch is checked                      |
| `data-disabled` | `""`                       | Present when switch is disabled                     |
| `data-readonly` | `""`                       | Present when switch is read-only                    |
| `data-focus`    | `""`                       | Present when switch has focus                       |
| `data-hover`    | `""`                       | Present when switch is hovered (unless disabled)    |
| `data-active`   | `""`                       | Present when switch is being pressed                |
| `data-required` | `""`                       | Present when switch is required for form validation |

## Keyboard Interactions

Complete keyboard behavior for the Switch component:

| Key           | Action                    | Context          | Notes                                                             |
| ------------- | ------------------------- | ---------------- | ----------------------------------------------------------------- |
| `Tab`         | Navigate to switch        | Focus management | Moves focus to the switch if not disabled                         |
| `Shift + Tab` | Navigate away from switch | Focus management | Moves focus to previous focusable element                         |
| `Space`       | Toggle switch             | Switch focused   | Toggles checked state, prevented if disabled or read-only         |
| `Enter`       | Toggle switch             | Switch focused   | Alternative activation method, prevented if disabled or read-only |

**Focus Management:**

- Switch receives focus via Tab navigation when `tabIndex={0}` (default)
- Disabled switches are excluded from tab order (`tabIndex={-1}`)
- Focus is visually indicated through `data-focus` attribute
- Focus state is properly managed during mouse interactions

**Screen Reader Behavior:**

- Switch is announced as "switch" due to `role="switch"`
- Current state is announced as "checked" or "not checked"
- Disabled state is announced when `aria-disabled="true"`
- Read-only state is announced when `aria-readonly="true"`
- Label and description are properly associated via ARIA attributes
